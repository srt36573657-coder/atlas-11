[6 · 숫자의 뜻(식)]
1. 실전 방향 = 가장 높은 확률(같으면 보합→상승→하락)
2. 실제 방향 = 출발 종가 대비 ±0.1% 밖이면 상승·하락
3. 방향 맞음 = 실전 방향과 실제 방향이 같음
4. 오차율 = |예측 가격(p50) − 실제 종가| ÷ 실제 종가
5. 폭 맞음 = 오차율 ≤ 1.5%(1거래일)
6. 확률 차 = P(하락) − P(상승)
7. 무게 0 칸 = 기본값·F35·F11 세 항이 모두 0.00%로 적힌 칸(합만 0.00%인 칸은 넣지 않는다)
8. 종가 그대로 = 출발 종가를 예측 가격으로 둔 것
9. 놓친 것 = 전망 전에 알 수 있던 기업 일정이 있는 칸(공시·기사는 넣지 않는다)

[7 · 공차 · 얼마나 같아야 같은가]
1. 정수: 정확히 같아야 한다.
2. 퍼센트: 소수 둘째 자리 반올림 값이 같아야 한다.
3. 확률: 차이 ≤ 3 × √(p(1−p) ÷ 경로 수)
4. 파일: sha256이 같아야 한다.
5. 시각: KST, 분 단위
