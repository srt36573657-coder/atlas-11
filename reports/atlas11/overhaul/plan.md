### 0.4 후향 판정 규칙(모든 후향 비교에 똑같이)
- 판정 숫자는 **방향 맞음률**. 오차율(ape1·ape20)은 함께 적되 판정에 쓰지 않는다.

- 「X가 낫다」 = P(평균 d > 0) ≥ 0.80 **그리고** 고정 6블록 중 X의 블록 평균이 더 높은 블록 ≥ 4. 거울로 「Y가 낫다」. 둘 다 아니면 「가려지지 않음」.
- 판정 말: 원인이다 / 아니다 / 모른다. 부품마다 아래에 어떤 결과가 어떤 말인지 미리 적었다. 규칙이 가리지 못하면 **모른다**.

## ⑤ 모의 계산·방향 고르기

- 대상: 9/29 atlas11 발행본(9/30 목표)의 무게 0 종목 32개. 9/28 rolling20도 입력이 되살아나면 같은 표를 따로 낸다(판정은 9/29 atlas11로).

- (b) T14 직접 셈: 모의 계산 없이 잔차 표로 1일 확률을 센다 — 공유 날짜 K개 각각에서 `expm1(μ + √h·z_k)`의 방향 비율. 발행본과 차이 ≤ 3·√(p(1−p)/20000)(p = 직접 센 값)이면 통과. 52종목 모두.
- (c) 잔차 모양: 종목마다 평균을 빼고 표준편차로 나눈 잔차(`simulate.mjs:52`)의 중앙값, 평균보다 작은 잔차 비율.
- (d) 바꾸는 것 하나씩(시험 사본, `simulate.mjs`는 그대로):
  - 변형 A = 잔차 중심을 평균 대신 중앙값으로(척도는 원래 그대로).
  - 변형 B = 잔차 표를 ±로 대칭(z와 −z를 모두 넣어 2K개, 52종목이 같은 부호·날짜).
  - 시험 사본을 「평균 중심」으로 두면 운영 결과와 한 자리도 다르지 않아야 한다(사본 검증).
- 표: 원래·A·B마다 32종목 확률 차 평균, 「하락」 고른 수, 표준오차. 표준오차는 종목마다 SE_i = √((p상승 + p하락 − (p하락 − p상승)²)/20000)이고 32종목 평균의 SE는 보수적으로 SE_i의 평균(종목끼리 완전히 같이 움직인다고 본 위 한계), 독립 가정 값 √ΣSE_i²/32도 함께 적는다. 잔차 표 직접 셈 값도 함께.
- 판정: 원인이다 = 변형 A나 B가 32종목 확률 차 평균을 3×SE(보수적) 넘게 바꾼다 · 결정표 후보 A·B. 아니다 = 둘 다 3×SE 이하. 모른다 = T12 또는 T14 실패.
- 맞다면 나올 숫자: (c) 32종목 중 24개 이상에서 중앙값 < 0, 평균보다 작은 비율 > 50%(대략 51~53%). (d) 원래 확률 차 평균 약 +5%p, A·B는 |평균| ≤ 1%p, 변화 ≥ 3×SE(약 2%p), 「하락」 수 약 29/32 → 14~18/32. T12 차이 0, T14 52/52 공차 안.
- 보조(판정에 안 씀, 시간이 남을 때만): A·B 변형을 0.3 후향 방법으로 돌려 `dir1sel`을 0.4 규칙으로 견준 값.
