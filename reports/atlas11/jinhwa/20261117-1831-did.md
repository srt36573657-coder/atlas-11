# 이번 회차 한 일 (막힘)
- 막힌 단계: 0 작업 폴더 · 자기 시험(--selftest). 통과 25 · 실패 14.
- 까닭: 본질 문서 이름이 「수르_본질」에서 「손자병법_본질」로 바뀌었는데, 진화 회차의 지시문 첫 줄과 본질 잠금 검사(⑬ · ⑰)가 아직 옛 이름 · 옛 글을 본다. 그래서 begin 이 「본질 잠금이 맞지 않음」으로 멈춘다(E1 ~ E13 모두 같은 까닭).
- 한 일: 없음. 얕은 복제를 풀어(unshallow) 다시 시험했으나 같은 실패.
- 넣은 것 0 · 되돌린 것 0 · 새 대안 0 · 고친 고장 0.
- 필요한 것: 사장님 말씀으로 지시문 첫 줄과 본질 잠금을 새 이름에 맞춰 고쳐 주셔야 한다(이 회차는 본질 · 잠금 · 도구를 스스로 고치지 않음).
