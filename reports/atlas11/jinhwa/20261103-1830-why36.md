# 20261103-1830 「왜?」 줄 — 대안 1 (꽃 될 회사 쪽 지난 기록 줄을 맨 위로)

왜 이걸 고치나? 꽃 될 회사 쪽에서 지난 기록이 맨 아래에 있어서요. → 처음 보는 사람이 회사 목록만 보고 판단해서요. → 견줄 기준이 없으면 목록이 맞다고 믿기 쉬워서요. → 기준은 「아무거나 고른 회사」 수라서요. → 그 수가 기록 줄에 같이 있어서요. → 줄을 위로 올리면 목록보다 먼저 보여서요. → 먼저 보면 한 번 더 따져 보게 돼서요. → 그게 수르의 멈춤 일이라서요. → 멈춤은 사고팔기를 권하지 않는 길이라서요. → 길이 짧아야 세 번~다섯 번 눌러 알 수 있어서요. → 지난 기록이 맨 위면 누르기 없이 보여서요. → 왕초보도 어린이도 한눈에 닿아서요. → 전문가도 근거를 바로 확인해서요. → 근거가 자료와 같은 숫자라서요. → 숫자가 같으면 사실 잣대를 안 비틀어서요. → 잣대를 지켜야 진화가 믿을 만해서요. → 믿을 만해야 사장님 확인을 받아서요. → 확인 없이는 넣지 않아서요. → 파일 하나만 바뀌어 되돌리기 쉬워서요. → 되돌리기 쉬우면 크게 시험해 볼 수 있어서요. → 시험 결과는 지난 기록으로 잴 수 있어서요. → 지난 기록만 보여 주는 게 수르 약속이라서요. → 앞날을 맞히지 않아서요. → 그래서 기준을 먼저 보여 주는 것이 맞아서요. → 오늘 고른 회사가 0곳인 날도 같은 줄이 위에 있어서요. → 빈 날에도 근거를 보여 주면 헷갈림이 줄어서요. → 헷갈림이 줄면 싹 찾기 길이 끝까지 가서요. → 끝까지 가야 꽃 될 회사를 찾아서요. → 찾는 일이 수르의 중심이라서요. → 중심은 싹에서 꽃이 되는 종목 찾기라서요. → 그 일은 지난 기록으로 엄선해야 해서요. → 엄선의 증거가 기록 줄이라서요. → 증거를 맨 위에 두는 게 정직해서요. → 정직이 수르의 바탕이라서요. → 바탕은 본질 1번이라서요. → 36번째: 싹에서 꽃이 되는 종목을 지난 기록으로 엄선해 찾아 주는 본질 1번에 닿아요.
