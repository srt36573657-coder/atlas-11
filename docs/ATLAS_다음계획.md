- 만들 때 사장님이 정할 것(Claude 가 정하지 않음):
  1. 등수를 무엇으로 매기나 — 예: 한 달 동안 가상 돈이 불어난 비율.
  2. 상품권 1,000장을 1~100등에 나누는 비율표.

  4. 상품권을 보내는 길(문자 · 이메일).
- 지금 사이트와 다른 점: 지금 ATLAS 는 파일만 올리는 사이트(서버 없음)라 회원 · 가상 돈 기록을 담을 곳(서버 · 저장소)이 새로 필요하다.
