# 기준 동양 수채화 — 그림 공부 100가지(주문 1119-1623)

## 가. 한눈에 본 구도
1. 세로로 긴 한 폭이에요 → 휴대폰에서 위에서 아래로 읽는 세로 두루마리로 그렸어요
2. 정자가 왼쪽 위 3분의 1 자리에 있어요 → 꾀를 고르는 정자를 같은 자리에 두었어요
3. 눈길이 정자에서 오른쪽 연꽃, 왼쪽 아래 연꽃으로 굽이쳐요 → 여섯 걸음 길을 같은 굽이로 놓았어요
4. 가운데가 비어 숨을 쉬어요 → 글 칸은 가장자리에만 두었어요
5. 왼쪽이 무겁고 오른쪽이 가벼워요 → 정자와 대나무는 왼쪽, 글 칸은 오른쪽에 두어 무게를 맞췄어요
6. 먼 곳, 가운데, 가까운 곳 세 켜예요 → 먼 산(시장), 정자(꾀), 연꽃과 돌(회사와 질문) 세 켜로 나눴어요
7. 물가 선이 위에서 3분의 1쯤에 있어요 → 물가 선을 같은 높이에 두었어요
8. 세로선과 가로선이 엇갈려요 → 세로는 대나무와 휘장, 가로는 물결로 썼어요
9. 아래쪽이 하얗게 사라져요 → 맨 아래 하얀 곳에 약속 글을 두었어요
10. 휘장이 위에 드리워 액자 같아요 → 위 양쪽에 얇은 휘장을 그렸어요

## 나. 비워 둔 곳
11. 그림의 절반 가까이가 비어 있어요 → 글 칸은 작게, 빈 곳은 넓게 남겼어요
12. 빈 곳이 물이 되고 하늘이 돼요 → 빈 곳을 물과 안개로 읽히게 했어요
13. 안개가 산 아래를 끊어 줘요 → 산 이름 밑에 안개 띠를 깔아 글이 잘 보이게 했어요
14. 빈 곳 덕분에 붉은 점이 돋보여요 → 등불과 연꽃만 따뜻한 빛으로 칠했어요
15. 사물 사이가 넉넉해 겹치지 않아요 → 글 칸끼리 넉넉히 떼었어요
16. 아래로 갈수록 비어요 → 정산과 약속 글을 아래 빈 곳에 두었어요
17. 하늘에 새 몇 마리만 있어요 → 새 여섯 마리만 작게 그렸어요
18. 물 위 빈 곳에 그림자가 비쳐요 → 정자 그림자를 물에 흐리게 거꾸로 그렸어요
19. 빈 곳에도 종이 결이 있어요 → 바탕 전체에 옅은 종이 결을 깔았어요
20. 빈 곳이 고요함을 만들어요 → 잔무늬와 굵은 테두리를 쓰지 않았어요

## 다. 빛깔
21. 바탕은 아주 옅은 푸른 흰빛이에요 → 종이색을 푸른 기 도는 흰빛으로 했어요
22. 큰 빛깔은 옥빛과 물빛이에요 → 물과 하늘을 옥빛 두 단계로 칠했어요
23. 산은 푸른 잿빛이에요 → 산 다섯을 같은 빛깔에서 밝기만 달리했어요
24. 대나무와 지붕이 가장 어두워요 → 가장 진한 먹빛은 대나무와 지붕에만 썼어요
25. 따뜻한 빛은 등불과 연꽃뿐이에요 → 등불 여섯과 연꽃만 따뜻하게 칠했어요
26. 따뜻한 점이 세모 꼴로 흩어져요 → 등불(왼쪽 위), 큰 연꽃(오른쪽), 작은 연꽃(왼쪽 아래)으로 세모를 만들었어요
27. 연잎은 푸른 초록이에요 → 연잎을 청록 두 가지로 칠했어요
28. 꽃술은 노란빛이에요 → 연꽃 가운데에 옅은 노랑을 찍었어요
29. 빛깔이 흐려 눈이 편해요 → 모든 빛깔을 맑고 흐리게 눌렀어요
30. 글씨가 먹빛이에요 → 글은 짙은 먹빛, 걸음 번호만 주홍 도장으로 했어요

## 라. 빛과 안개
31. 해가 안 보이고 빛이 고루 퍼져요 → 짙은 그림자를 넣지 않았어요
32. 멀수록 흐리고 옅어요 → 먼 산 뒤에 더 옅은 산줄기를 한 겹 더 넣었어요
33. 산 아래가 안개에 잠겨요 → 산 발치에 흰 안개 띠를 둘렀어요
34. 물과 하늘의 경계가 녹아 있어요 → 물가 선을 흐리게 번지게 했어요
35. 휘장 너머로 보는 듯 아련해요 → 휘장을 비치는 흰빛으로 했어요
36. 위는 조금 푸르고 아래는 하얘요 → 하늘을 위에서 아래로 옅어지게 했어요
37. 등불이 물에 붉은 줄로 비쳐요 → 등불 아래 물에 따뜻한 세로 줄을 흐리게 그렸어요
38. 연꽃 둘레가 밝아요 → 꽃 둘레를 비워 밝게 남겼어요
39. 아침처럼 맑아요 → 어두운 하늘빛은 쓰지 않았어요
40. 안개가 겹겹이라 깊어 보여요 → 하늘, 산, 물에 안개를 세 번 나눠 얹었어요

## 마. 붓질
41. 젖은 종이에 번진 자국이 있어요 → 넓은 면은 가장자리가 번지게 했어요
42. 마르며 가장자리가 진해져요 → 산과 연잎, 돌 가장자리를 살짝 진하게 했어요
43. 대나무 잎은 한 번에 그은 붓이에요 → 잎을 끝이 뾰족한 한 획 모양으로 그렸어요
44. 지붕은 가는 선으로 또렷해요 → 정자만 선을 또렷하게 남겼어요
45. 마른 나무는 마른 붓이에요 → 나뭇가지를 가늘고 옅게 그었어요
46. 같은 빛을 여러 번 얇게 겹쳐요 → 물을 여러 겹 얇은 칠로 쌓았어요
47. 흰 곳은 칠하지 않고 남겨요 → 흰빛은 물감이 아니라 빈 종이로 냈어요
48. 선 굵기가 살아 움직여요 → 선 가장자리를 조금씩 흔들었어요
49. 붓 방향이 사물 결을 따라요 → 물은 가로로, 대나무는 세로로 그었어요
50. 물감 알갱이 결이 보여요 → 종이 결 위에 칠이 앉은 느낌을 냈어요

## 바. 물
51. 물이 그림의 가운데 절반을 차지해요 → 걷는 길 대부분을 물 위에 놓았어요
52. 물은 잔잔하고 평평해요 → 물결은 가로로 짧게 몇 줄만 그었어요
53. 정자가 물에 거꾸로 비쳐요 → 정자 그림자를 거꾸로, 흐리게 그렸어요
54. 가까운 물이 더 진해요 → 정자 아래 물은 진하게, 아래로 갈수록 옅게 했어요
55. 물 위에 연잎이 떠 길처럼 이어져요 → 연잎과 징검돌을 이어 걷는 길로 만들었어요
56. 물이 아래로 흘러 사라져요 → 정산 선을 아래로 흐르는 물 위에 그렸어요
57. 물가에 흰 집이 작게 있어요 → 먼 물가에 작은 집을 하나 두었어요
58. 물 위에 흰 안개가 떠 있어요 → 물 위 몇 곳을 하얗게 비웠어요
59. 물은 시간이 흐르는 느낌이에요 → 흐르는 물을 날마다 쌓이는 정산으로 정했어요
60. 비친 것은 흐려요 → 그림자는 흐리게, 실물은 또렷하게 그렸어요

## 사. 산과 하늘
61. 양 끝 산이 안쪽으로 기울어요 → 양 끝 산을 오르는 산과 내리는 산으로 마주 보게 했어요
62. 산마다 꼴이 달라요 → 산 다섯을 시장 모습 다섯 꼴로 그렸어요
63. 가장 높은 봉우리가 하나 있어요 → 가운데 우뚝한 봉우리를 쏠린 시장으로 썼어요
64. 들쭉날쭉한 산줄기가 있어요 → 톱니 같은 산을 흔들리는 시장으로 썼어요
65. 낮고 둥근 언덕이 있어요 → 둥근 언덕을 잔잔한 시장으로 썼어요
66. 하늘에 새가 날아요 → 새 떼로 하늘이 넓어 보이게 했어요
67. 산은 멀어서 작고 흐려요 → 산은 작고 옅게, 이름만 또렷하게 달았어요
68. 하늘과 산이 같은 푸른 빛이에요 → 하늘과 산을 같은 물빛 집안으로 칠했어요
69. 산에 바위 결 선이 있어요 → 봉우리 몇 곳에 가는 바위 결을 그었어요
70. 하늘이 맨 처음 눈에 들어와요 → 하늘과 먼 산을 첫 걸음(오늘 시장)으로 정했어요

## 아. 정자와 대나무
71. 지붕 끝이 하늘로 휘어 올라가요 → 지붕 양 끝을 위로 들어 올렸어요
72. 정자에 붉은 등불이 달려 있어요 → 등불 여섯을 달아 꾀 묶음 여섯을 뜻하게 했어요
73. 정자가 물 위 기둥에 서 있어요 → 정자를 물 위 기둥 위에 세웠어요
74. 정자 벽이 흰 창이에요 → 벽에 창 칸 서른여섯을 그려 꾀 서른여섯을 뜻하게 했어요
75. 등불 아래마다 창이 있어요 → 등불 하나 아래 창 여섯 칸, 묶음 하나에 꾀 여섯이 보여요
76. 대나무가 정자 뒤에서 솟아요 → 대나무를 정자 뒤 왼쪽에 세웠어요
77. 대나무가 가장 진한 곳이에요 → 진한 대나무로 눈길을 정자에 붙잡았어요
78. 대나무 잎이 아래로 늘어져요 → 잎을 아래로 처지게 그렸어요
79. 정자 옆에 마른 나무가 있어요 → 정자 오른쪽에 옅은 나무 두 그루를 두었어요
80. 정자는 앉아서 생각하는 곳이에요 → 꾀를 고르는 자리로 정자를 골랐어요

## 자. 연꽃과 연잎
81. 연꽃이 두 곳에 크게 피어요 → 큰 연꽃은 오른쪽, 작은 연꽃은 왼쪽 아래에 두었어요
82. 봉오리도 하나 있어요 → 아직 안 핀 봉오리를 하나 그렸어요
83. 꽃잎 끝이 진하고 안쪽이 옅어요 → 꽃잎을 끝으로 갈수록 진하게 칠했어요
84. 꽃대가 가늘고 길어요 → 꽃대를 가늘게 물속까지 내렸어요
85. 연잎은 둥글고 한쪽이 패여요 → 연잎마다 작은 홈을 냈어요
86. 연잎이 비스듬히 줄지어 떠요 → 연잎을 걷는 길 쪽으로 흩었어요
87. 연꽃은 흙탕물에서 맑게 피어요 → 꾀가 고른 회사를 연꽃으로 그렸어요
88. 연꽃 크기가 서로 달라요 → 꽃 크기를 세 가지로 나눴어요
89. 연꽃이 따뜻한 점이에요 → 꽃은 회사만 뜻하게 따뜻한 빛으로만 칠했어요
90. 꽃과 잎 사이가 성겨요 → 꽃을 몰아 그리지 않고 띄엄띄엄 두었어요

## 차. 뜻과 마음
91. 그림 전체가 고요해요 → 서두르게 하는 말과 움직임을 넣지 않았어요
92. 천천히 걸어 들어가는 그림이에요 → 걸음 번호 여섯을 붙여 차례대로 걷게 했어요
93. 그림에 글이 거의 없어요 → 글은 걸음마다 세 줄 안으로 줄였어요
94. 옛 그림처럼 제목이 세로로 있어요 → 제목을 오른쪽 위에 세로로 쓰고 도장을 찍었어요
95. 아무것도 다그치지 않아요 → 사라, 팔라는 말을 넣지 않았어요
96. 시간이 멈춘 듯해요 → 한 번 적으면 고치지 않는 정산 기록을 물에 맡겼어요
97. 멀리서는 그림, 가까이서는 길이에요 → 그림 위에 번호와 짧은 이름만 얹었어요
98. 처음 봐도 알 수 있어야 해요 → 그림 하나에 뜻 하나만 짝지었어요
99. 빛깔이 부드러워 오래 봐도 편해요 → 글씨는 크게, 바탕은 밝게 했어요
100. 아름다움과 쓸모가 함께 있어요 → 그림의 자리 하나하나가 손자병법 쪽 하나와 이어져요
