# S12 글씨 · 간격 — [10] 5 ~ 10

## 모두 쓰는 이름(app.css 맨 위 :root · 00:50 부터 있음)

글씨 크기 여섯(17px 아래 없음 — 한 화면 여섯 가지까지):
| 이름 | 값 | 쓰는 곳 |
|---|---|---|
| `--fs-1` | 17px | 작은 글 — 설명 · 날짜 · 꼬리표 · 칩 · 단추 글 · 그림 눈금 · 회색 글 |
| `--fs-2` | 19px | 본문 — 기본 글(body) · 줄 이름 · 목록 |
| `--fs-3` | 21px | 칸 제목(h2) · 카드 제목 · 강조 한 줄 |
| `--fs-4` | 24px | 화면 제목(h1) · 카드 속 큰 글 |
| `--fs-5` | 30px | 칸 머리 큰 숫자 |
| `--fs-6` | 48px | 한 화면 하나뿐인 가장 큰 숫자(시황 큰 숫자 · 숫자 그림) |

옮기는 잣대: 13 ~ 16px → `--fs-1` · 17 → `--fs-1` · 18 → 회색 · 보조 글이면 `--fs-1`, 본문이면 `--fs-2` · 19 → `--fs-2` · 20 ~ 22 → `--fs-3` · 23 ~ 26 → `--fs-4` · 27 ~ 36 → `--fs-5` · 38 이상 → `--fs-6` · 첫 화면 rem(html 21px): 1rem · 1.048rem → `--fs-3` · 1.143rem → `--fs-4` · 1.43rem → `--fs-5`.

간격 셋(음수 없음): `--sp-1` 8px · `--sp-2` 16px · `--sp-3` 24px (그 밖은 0 만). 옮기는 잣대: 1 ~ 3 → 0 · 4 ~ 11 → `--sp-1` · 12 ~ 19 → `--sp-2` · 20 이상 → `--sp-3` · 음수 margin(겹침)은 지우고 자리로 맞춤 · 더 넓은 자리가 꼭 필요하면 calc(var(--sp-3) * n) 말고 칸 짜임(grid · flex 열)으로.

노란 경고 글 두 줄까지 — 새 파일 `site/next/warn.js`:
```js
import {warn} from '/next/warn.js';      // 쪽 모듈 맨 위(같은 주소 · CSP 그대로) — app.js 에서는 NX.warn(처음 import 뒤)
node.append(warn('긴 경고 글 …'));        // 짧으면(두 줄 안) 금빛 한 문단 · 길면 「? 조심할 것 — 누르면 펼쳐요」 한 줄 → 누르면 펼침(<details>)
node.append(warn('긴 글 …', {short: '? 장 중 값이에요'}));  // 접힌 한 줄 글을 직접 줄 때(「?」로 시작)
```
모양은 `site/next/warn.css`(warn.js 가 처음 부를 때 한 번 붙임 · 글 17px · 금빛 · 누르는 자리 44px).
