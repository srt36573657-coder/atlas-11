## kakao.js 가 하는 일(요청은 아래뿐)
- 스위치 `SWITCH`(false) · 켜지 않으면 서버 요청 0 · 카카오 도구 0 · 카카오 주소 0 · 보안 머리말 그대로. 시험 서버(127.0.0.1)에서만 `globalThis.__GODORI_KAKAO_TEST__` 나 `?kakaodev=1` 로 켠 것으로 봄(실제 사이트에는 심을 길이 없음).
- 서버를 묻는 때: 종목 보내기 글상자를 열 때 · 매매일지를 끝낼 때 · 앞서 가입한 기기(`atlas:kakao:member`) · 카카오 동의 화면에서 막 돌아온 쪽(`?kakao=ok|none`). 이 탭에서 한 번(`sessionStorage atlas:kakao:status` 10분). 처음 온 사람에게는 첫 화면에서 묻지 않음.
- 부르는 길: `GET /api/kakao/me` · (회원) `GET/PUT /api/kakao/data` `{data:{기록 넷}[, off]}` · `POST /api/kakao/withdraw` · 이동 `/api/kakao/start?to=&ref=&prompt=none`. 기록 넷 = `atlas:godori-why` · `atlas:new:sub` · `atlas:new:later` · `atlas:godori-hold`(합쳐 올림 · 이 기기 기록은 줄지 않음) · 내 돈 칸(`atlas:godori-money`) · 본 기록(`atlas:new:hist`)은 읽지도 올리지도 않음.
- 이 기기에 두는 것: localStorage `atlas:kakao:member` · `atlas:kakao:offered` · `atlas:kakao:base` / sessionStorage `atlas:kakao:status` · `atlas:kakao:silent`. 로그인 증표는 서버의 HttpOnly 쿠키뿐(화면에서 못 읽음 — 끝에서 끝까지에서 `document.cookie` 가 빈 글).
- 카카오 도구(SDK): 카드 보내기에만 씀 · `SDK.src` · `SDK.integrity` · `SDK.key` 가 모두 채워져야만 받음(지금 비어 있음) · 가입 자체는 도구 없이 주소 이동만.

## p-share 가 NX.kakao 에서 읽는 것(없으면 꺼진 길)
`on === true`(아니면 한 줄도 안 돎) · `sdkReady()`(글상자를 열 때 · 카드 미리보기를 그릴지) · `canSend()`(누른 손길 안에서 동기) · `sendCard(card)`(누른 손길 안 · 실패하면 공유 창으로) · `ref()` · `startUrl(보낸 쪽, {ref})` · 권유 칸 = `offerBox({start})` 는 kakao.js 가 매매일지 결과 칸 밑에 붙임.

- p-why.js `offerOnce()` → `NX.kakao.offer('journal')` 한 번(일꾼 S1c) · p-hold.js → `NX.kakao.withdraw()`(true/false) · `exportFile()`(정확히 false 가 아니면 됐음) · `'nx:kakao'` 알림(일꾼 S5h) · 서버 → 위 「부르는 길」(일꾼 K1c · 끝에서 끝까지 맞음) · 처리방침 → 위 「이 기기에 두는 것」(일꾼 K2p).

## 못 한 것 · 몫이 아닌 것(여쭐 것은 본 일꾼 경유)
- 켜기: `SWITCH=true` + `config/atlas11/kakao.json "on":true`(단위 시험 ⑯ 이 같은지 봄) + 넷리파이 열쇠 넷 + `SDK` 세 값 + 보안 머리말에 카카오 도구 주소(도구를 쓸 때만) — 한꺼번에. 서버 함수가 안 올라간 채 `SWITCH=true` 로 두지 말 것(404 한 줄이 콘솔에 남음).
- 「그냥 보기」 쪽 주소에는 보낸 사람 표가 없어, 그냥 본 뒤 일지를 끝내고 권유로 가입한 친구는 보낸 사람 몫으로 안 셈(카드 단추 1 로 들어온 친구만 셈). 바꾸려면 주소에 표를 싣는 일(처리방침 · 서버 규칙)이라 사장님 결정.
- 진짜 카카오 도구로 카드가 친구 대화창에 어떻게 보이는지는 못 봄(열쇠가 없음) — 가짜 도구로 보내는 값(feed · 단추 둘 · 주소)만 맞댐.
- 카드 그림은 지금 소개 그림(`/og-makbi.jpg` 1200×630). 종목별 그림은 안 만듦.
- 탈퇴 때 로그인이 이미 풀려 있으면(서버 401) `withdraw()` 는 false 를 주고 회원이 아닌 것으로 바뀜(서버 사본은 그대로 · 이 기기 가입 표시는 남김) → 탈퇴 단추가 사라지고, 다시 카카오로 시작한 뒤에야 탈퇴할 수 있음. 그때 보유종목 화면(S5h)이 무슨 길을 보일지는 본 일꾼 결정.
- 바뀐 쪽만 고르는 도구 `scripts/atlas11/next/check_changed.mjs` 의 `checksFor` 는 `site/next/kakao.js` 와 `tests/atlas11/kakao-client.test.mjs` 를 모름 — 그 파일만 고치면 짝 검사(`check_share` + 단위 시험)가 안 뜸(리드 파일이라 안 고침 · 한 줄 더하면 됨). `quick.mjs` 는 `kakao.js` 를 이미 앎.
- `p-share.css` 의 글씨 · 간격은 `var(--fs-n, 뒤 값)` · `var(--sp-n, 뒤 값)` 꼴(소개 · 편지 쪽이 app.css 없이 불러서 뒤 값이 필요). 다른 쪽의 엄한 글 검사(`page_rules.cssRules` = `var(--fs-n)` 만 됨)를 이 파일에 걸면 걸림 — 지금은 걸려 있지 않고, 이 일꾼 검사는 뒤 값 꼴도 받음.
- 편지 쪽(`site/letter.js` · S7l 몫): 사장님 열쇠 기기가 열 때 `/api/kakao/me` 를 한 번 물음 → 카톡이 꺼져 있으면(지금) 콘솔에 404 한 줄. 열쇠 없는 기기는 카카오 길 0(검사가 따로 잼).
