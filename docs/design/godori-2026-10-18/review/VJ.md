## 다시 재는 법
```
node scripts/atlas11/next/verify/vj.mjs --out <결과.json>          # 전체 · 약 2.5분
node scripts/atlas11/next/verify/vj.mjs --only 7,10 --out <결과.json>  # 항목만(7 · 10 은 영어 길 포함)
node scripts/atlas11/next/verify/vj.mjs --no-en                     # 영어 판 빼고
```
실패가 하나라도 있으면 끝낼 때 종료 코드 1. 기본 서버 `http://127.0.0.1:8826` · 다르면 `--base`.
