위에서부터 한 줄씩 하시면 됩니다. 한 줄에 한 가지예요.
이 장은 법 풀이가 아니에요. 법은 변호사에게 확인받습니다.
열쇠를 넣기 전에는 카카오 기능이 모두 꺼져 있어요.
카카오 메뉴 이름은 2025년 12월에 바뀐 새 화면 기준이에요.

## 가. 카카오 개발자 앱 만들기

1. `https://developers.kakao.com` 에 사장님 카카오 계정으로 들어갑니다.
2. 「내 애플리케이션」에서 새 앱을 만듭니다.
3. 앱 이름은 「고도리」로 적습니다.
4. 회사 이름은 사업자 등록증과 같게 적습니다.

## 나. 비즈 앱으로 바꾸기

5. 앱에 사업자 정보를 넣어 비즈 앱으로 바꿉니다. 따로 심사는 없어요.

## 다. 카카오톡 채널 만들고 심사받기

6. `https://business.kakao.com` 에서 카카오톡 채널을 만듭니다.
7. 채널 이름은 「고도리」로 합니다.
8. 채널의 사업자 번호를 앱과 같게 넣습니다.
9. 비즈니스 채널 심사를 신청합니다.
10. 채널 설정에서 「1:1 채팅」을 끕니다.
11. 채널은 사이트 알림에만 씁니다. 종목 이야기는 보내지 않습니다.

## 라. 앱과 채널 잇기

12. 개발자 앱의 「카카오톡 채널」 메뉴에서 채널을 잇습니다.
13. 「대표 채널」로는 정하지 않습니다. 그래야 동의 화면에 채널 추가 칸이 안 나와요.
14. 「추가 기능 신청」에서 「비즈니스 정보」를 신청합니다. 채널이 이어져 있으면 바로 승인돼요.

## 마. 카카오 로그인과 간편가입 켜기

15. 「카카오 로그인」의 「사용 설정」을 켭니다.
16. 「동의항목」은 모두 「사용 안 함」으로 둡니다. 닉네임과 사진도 끕니다.
17. 회원 번호는 동의항목이 아니어서 따로 켤 것이 없어요.
18. 「간편가입」에서 「서비스 약관 추가」를 누릅니다.
19. 약관은 하나만 넣습니다. 이름은 「개인정보 수집·이용 동의」예요.
20. 그 약관의 동의 단계는 「필수」로 둡니다.
21. 약관 주소에 `https://aaa7377.com/privacy.html#kakao` 를 넣습니다.
22. 약관 태그에는 `privacy` 를 적습니다. 우리 서버는 태그를 읽지 않아요.
23. 약관을 켜고, 간편가입도 켭니다.
24. 광고 받기 동의 약관은 넣지 않습니다.

## 바. 사이트 주소와 돌아올 주소 넣기

25. 「플랫폼 키」에서 `REST API 키` 화면을 엽니다.
26. 「리다이렉트 URI」 칸에 돌아올 주소를 넣습니다. `https://aaa7377.com/api/kakao/callback`
27. 같은 화면에서 「클라이언트 시크릿」 코드를 만들고 켭니다.
28. 「플랫폼 키」의 `JavaScript 키` 화면을 엽니다.
29. 「JavaScript SDK 도메인」에 사이트 주소를 넣습니다. `https://aaa7377.com`
30. 「제품 링크 관리」의 「웹 도메인」에도 같은 주소를 넣습니다.
31. 「웹훅」의 「연결 해제 웹훅」에 이 주소를 넣습니다. `https://aaa7377.com/api/kakao/unlinked`

## 사. 열쇠 넣는 곳

32. 넷리파이에서 이 사이트의 환경 변수 화면을 엽니다. `Environment variables`
33. `ATLAS_KAKAO_REST_KEY` 에 `REST API 키` 를 넣습니다.
34. `ATLAS_KAKAO_CLIENT_SECRET` 에 클라이언트 시크릿을 넣습니다.
35. `ATLAS_KAKAO_ADMIN_KEY` 에 대표 어드민 키를 넣습니다. 연결 해제 웹훅이 이 열쇠로 확인돼요.
36. `ATLAS_KAKAO_HASH_SECRET` 에는 사장님이 만든 긴 글자를 넣습니다. 40자쯤이면 돼요.
37. 이 넷의 값은 저장소와 채팅 어디에도 적지 않습니다.
38. `JavaScript 키` 는 공개해도 되는 열쇠예요. Claude에게 주시면 `config/atlas11/invite.json` 에 넣어요.
