## 81. 쪽 사이 — 오늘(첫 화면) · 꾀 모음 겹침
(사진 today.png 는 너무 작아 칸 표 길이로 판단했고, 줄 모양은 같다고 가정함 — 확인 필요)
- 지움: 오늘 sj-sun.sj-nosun「서른여섯 꾀」(175px) — 바로 아래 sj-s36 도 제목이 같은 「서른여섯 꾀」라 머리말이 두 번 나옴
- 지움: 꾀 모음 sj-ph「삼십육계 · 요즘 많이 오른 차례」(779px)와 sj-krank 의 머리 — 쪽 제목 「병법 서른여섯 가지」와 같은 말을 되풀이함. 한 머리로 줄임
- 합침: 오늘 sj-s36(5351px) + 꾀 모음 sj-krank(14872px) → 한 곳(#/k)에 전체 36줄, 오늘에는 위 7줄 + 「서른여섯 모두 보기」 단추 하나. 같은 36줄이 두 쪽에 있어 길이가 겹침(오늘이 5351 → 약 1400px)
- 단순하게: 꾀 모음 sj-krank 14872px — 위 7줄 + 「8등부터 36등까지 더 보기」 서랍(known.md 의 틀 그대로). 서랍 글은 「8등」 말고 「여덟째부터」로(「1위」 말 안 씀)
- 단순하게: 오늘 sj-hero「딴 데 쳐서 구하기」(302px)와 sj-coday「오늘의 기업」(238px) — 둘 다 오늘의 회사 이야기라 한 칸으로 붙이면 첫 화면 위쪽이 한 번에 읽힘
- 꼭 남김: sj-cover(표지) · sj-mind(격언, 맨 위) · 오늘의 꾀 칸 — 사장님이 직접 시키신 것, 지우지 않고 자리만 정해야 함
- 꼭 남김: sj-safe(가짜 돈 · 지난 기록 문구)와 sj-pkin — 본질
- 사장님께 여쭐 것: 오늘 쪽의 36줄을 7줄로 줄여도 되는지(오늘의 꾀 칸으로 사장님이 시키신 것이라)
