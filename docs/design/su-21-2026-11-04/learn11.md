# 시안 열하나 → 하나(주문 2044 [8] 5~9)

시안은 따로 만든 판(scratchpad art2/b01~b11) · 장점은 한 줄씩 · 하나로 모을 때 가져간 것은 ✓ · 못 가져간 것은 ✗

|---|---|---|---|
| 1 | 21곳 한눈에 | 첫 화면 세 띠에 21칸이 다 보이고, 겹친 3곳은 금빛 쌍고리로 이어 보인다 | ✓ 셋 × 일곱 이름 칸(su-21g) |
| 2 | 별자리 21 | 21곳을 별자리 셋으로, 겹친 3곳은 두 별자리가 함께 쓰는 별 하나 | ✗ |
| 3 | 용이 이끄는 길 | 용 머리가 여덟 진주를 따라 옮겨 가며 몇 번째 걸음인지 보여 줌 | ✗ 걸음 표시는 지금 막대 · 용은 뒷배경에만 |
| 4 | 앵무새 안내 | 앵무새가 앞 쪽의 물음을 들고 와 다음 쪽이 답한다 | ✓ 다음 단추에 앵무새 · 물음 꼴 이름 |
| 5 | 땅 지도 세 번 | 땅 → 업종 → 회사가 세 번에 열린다 | ✓ #/m → #/m/<땅> → #/c/<번호> |
