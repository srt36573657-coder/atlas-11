## 확인하지 못해 뺀 말(널리 돌지만 출처가 흐림)
- 다빈치 「지혜는 겪어 본 것의 딸」 — 공책 쪽 번호를 확인 못 함 → 「딱따구리」 메모로 바꿈
- 정약용 초서(가려 뽑아 적기)를 말한 편지 원문 — 원문 글자를 확인 못 함 → 방법은 본문에만 · 남긴 말은 『목민심서』 머리말
- 이순신 「물때를 미리 익혀 이겼다」 — 사료로 확인 어려움 → 「좁은 울돌목을 골랐다」만
- 원효 「해골 물」 — 뒷날 덧붙은 이야기 → 『송고승전』의 무덤 이야기만
- 뉴턴 「사람의 광기는 셀 수 없다」(남해 회사) — 뒷날 붙은 말 → 안 씀
- 갈릴레이 「잴 수 있는 것은 재고, 잴 수 없는 것은 잴 수 있게」 — 출처 없음 → 안 씀
- 퀴리 「삶에서 두려워할 것은 없다, 이해할 것뿐」 — 출처 흐림 → 안 씀
- 잡스 「천 가지에 아니오」 — 1997 애플 개발자 회의의 「좋은 아이디어 백 가지에 아니오」로 적음(ideas-36.md)
