주문 1126-2137 — 사장님 2026-11-26(서울) 21:37

원문
총 매수 금액은 표기 되어 있는대 퐁 보유 금액은 표기가 되어 있지 않아 그리고 몇종목 보유하고 있는지 수자가 나타나지 읺고 있고 날짜별 표기와 기타등등은 에이전트 50개 가동해서 뭐가 더 필요한지 찾아내서 더 채워라

알아들은 것
- 곳 = 아래 탭 「기록」(#/l/a 「한눈에」 · 자산 포트폴리오 칸)
- 「총 매수 금액」 = 지금 보이는 「들인 돈」(산 돈 모두) — 보임
- 「총 보유 금액」(퐁 = 총) = 지금 들고 있는 회사의 지금 값을 모두 더한 것 — 안 보임 → 넣음
- 「몇 종목 보유」 = 지금 들고 있는 회사 수(같은 회사를 여러 번 산 것은 한 곳) — 안 보임 → 넣음
- 「날짜별 표기와 기타 등등」 = 에이전트 50개(한 번에 20개씩 — 지도 「일꾼: 한 번에 20」)가 무엇이 더 필요한지 찾아내고, 그것으로 더 채움
- 사이트 규칙: 빨간색 없음 · 「%」 대신 「프로」 · 글 17 넘게 · 누름 48 넘게 · 「매수」 · 「매도」는 화면에 쓰지 않음(「산」 · 「판」) · 가짜 돈 · 사고팔기를 권하지 않음 · 앞날을 맞히지 않음
