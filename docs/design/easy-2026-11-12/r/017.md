# 017 · 믿게 만드는 신호
## 사실 (출처 · 날짜 · 주소)
- 스탠퍼드 웹 신뢰 지침 10가지 중 1~3번: 맞는지 확인하기 쉽게 / 뒤에 진짜 기관이 있음을 보이기 / 전문성 보이기. 8번: 내용을 자주 고치기(적어도 최근에 살폈다는 표시). 9번: 광고·할인은 절제. 10번: 작은 오류도 피하기. https://credibility.stanford.edu/guidelines
- Fogg 외 스탠퍼드 연구(2002.10.29): 2,684명이 실제 사이트 두 곳의 믿음직함을 평가. 쓴 글의 46.1%가 「겉모양 디자인」을 언급해 가장 많았다. 그다음은 정보 짜임새와 정보 초점(수치는 확인 못 함). https://advocacy.consumerreports.org/research/how-do-people-evaluate-a-web-sites-credibility
- Nielsen Norman Group(Aurora Harley, 2016.5.8): 믿음 요인 넷 = 디자인 품질 · 미리 밝히기(요금·연락처·정책) · 빠짐없고 맞고 최신인 내용 · 바깥 웹과의 연결. 오타·깨진 링크는 신뢰를 깎는다. 로그인이나 개인정보를 먼저 요구하면 신뢰가 떨어진다. https://www.nngroup.com/articles/trustworthy-design/
- 같은 연구(싱가포르 사용성 조사): 참가자 모두 고르기 전에 후기를 읽겠다고 답했다. 회사 자체 사이트의 후기보다 바깥 사이트의 후기를 더 믿었다.
- 한국 논문(이태준·윤태웅, PR연구 18권 3호, 2014.8): 공시 정보를 넣은 금융 홍보 메시지의 효과를 실험. 소비자의 회의주의가 효과를 바꾸었고, 금융교육 수준은 뚜렷한 영향이 없었다. https://www.earticle.net/Article/A231721
- 한국 논문(남상욱, 융합정보논문지 8권 2호, 2018.4): 인터넷전문은행 신뢰 요인 = 거래 비용의 합리성 · 이용 편리성 · 보안성. https://www.earticle.net/Article/A326788
- KB경영연구소(방석훈, 2026.2.19): 금융위원회는 기업 공시와 믿을 만한 언론 보도를 먼저 보라고 안내. 광고 표시 의무화 등이 대책으로 거론됨. https://kbthink.com/investment/deepdive/research/260219-5.html

## 자료가 말하는 습관 · 성향
- 사람들은 글보다 첫눈의 모양으로 먼저 믿음을 정한다(46.1%).
- 사람들은 바깥 출처의 확인을 자기 편 설명보다 더 믿는다.
- 숨기는 느낌(연락처·요금 없음, 먼저 개인정보 요구)이 믿음을 깎는다.
- 오타·오류 같은 작은 흠이 믿음을 크게 깎는다.
- 한국 금융 소비자 사이에는 정보에 대한 의심이 큰 요인이다(위 2014 논문).

## 큐피트에 쓸 것 (화면 · 말 · 순서)
- 첫 화면 맨 위에 한 줄: 「지난 기록을 보여 드립니다. 사고팔라는 말이 아닙니다.」
- 칸마다 작은 글씨로 「출처: 한국거래소 · 오늘 15:30 기준」처럼 기관 이름과 날짜·시각을 한 줄로 붙인다.
- 화면 위에 「마지막으로 고친 때」 한 줄을 늘 보이게 한다. 하루 넘게 낡으면 눈에 띄게 알린다.
- 자세한 쪽에 「이 숫자는 어디서 왔나」 칸을 접어 두고, 누르면 원자료 주소로 가게 한다.
- 로그인과 개인정보 요구 없이 바로 보이게 둔다. 사이트 운영자 이름과 연락 방법을 아래에 둔다.
- 광고·할인·추천 말투는 넣지 않는다.
- 오타와 깨진 링크가 없는지 올리기 전에 훑는다. 칸마다 숫자는 하나만 둔다.
- 후기를 넣으려면 사이트 자체가 아닌 바깥 출처 것이 더 믿긴다. 지어낸 후기는 넣지 않는다.

## 못 찾은 것
- 스탠퍼드 연구에서 「날짜 표시」「출처 표시」 각각의 비율은 확인 못 함.
- 한국 여성 · 주식 초보가 날짜·출처 표시에 반응하는 크기를 잰 자료는 못 찾음(자료 없음).
- 한국소비자원 「핀플루언서 사기 위험 12배」는 KB 글에 인용된 것만 보았고 원문은 못 열어 쓰지 않음.
- 한국거래소·금융감독원의 출처·날짜 표시 지침 원문은 못 찾음.
