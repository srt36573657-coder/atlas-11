# 084 · 일상 비유로 금융 설명 — 이해가 오르나
## 사실 (출처 · 날짜 · 주소)
- 필리핀 · 태국 · 베트남 · 잠비아 무작위 휴대폰 조사(약 3,500명, 개념 18개). 비유 설명 64.3% · 직접 설명 66.1% · 행동 설명 64.9%. 전체 차이는 의미 없음(p=0.11). 금융포용센터 보고서, 2026. 7. https://www.centerforfinancialinclusion.org/wp-content/uploads/2026/07/What-Works-in-Financial-Education-Testing-What-Improves-Comprehension-in-Adult-Learning.pdf
- 같은 조사에서 「돈의 시간 가치」는 비유 55% 대 직접 설명 43%로 비유가 12점 높았다(같은 주소).
- 같은 조사에서 「대출 비용」은 비유 56.0% 대 직접 설명 71.0%로 비유가 15점 낮았다(p=0.026). 목표 세우기도 비유가 가장 낮았다 39.6%(같은 주소).
- 금융 지식이 낮은 응답자는 비유 덕을 더 봤다: 시간 가치 48% 대 37%, 기회비용 52% 대 43%(같은 주소).
- 저자들이 밝힌 한계: 비유는 사람마다 다르게 읽히고, 단순화로 세부를 가린다. 네 나라에 같은 비유를 써서 효과가 줄었을 수 있다(같은 주소).
- 날씨 비유의 함정: 「비 올 확률 30%」를 유럽 도시 시민 다수는 「하루 중 30% 시간 비가 온다」 또는 「지역의 30%에 온다」로 읽었다. 뉴욕만 다수가 맞게(비슷한 날 열 번 중 세 번) 읽었다. 암스테르담 · 아테네 · 베를린 · 밀라노 · 뉴욕 길거리 조사. Gigerenzer 외, Risk Analysis 25(3), 2005. https://econpapers.repec.org/RePEc:wly:riskan:v:25:y:2005:i:3:p:623-629
- 도시별 비율과 표본 수는 초록에 없어 적지 않는다.
## 자료가 말하는 습관 · 성향
- 비유는 「개념이 낯설고 직관과 이어질 때」(시간 가치) 효과가 크고, 「계산과 조건이 중요할 때」(대출 비용) 오히려 떨어졌다.
- 지식이 적은 사람일수록 비유 이득이 컸다. 다만 전체 평균 이득은 없었다.
- 사람들은 이미 아는 말(날씨 %)도 자기 식으로 읽는다. 익숙한 비유가 곧 정확한 이해는 아니다.
## 큐피트에 쓸 것 (화면 · 말 · 순서)
- 낯선 뜻 한 개에만 비유를 쓴다. 예: 「한 달 꺾은선」 옆에 「한 달 동안 오른 만큼」 한 줄. 숫자 계산이 필요한 곳(오른 폭)에는 비유 대신 직접 숫자와 단위를 쓴다.
- 날씨 % 비유는 쓰지 않는다. 「30% 확률」처럼 읽히는 숫자는 「최근 열 번 중 세 번」처럼 센 횟수로 적는다.
- 비유 아래에 바로 실제 숫자를 한 줄 붙인다(비유만 두지 않는다). 칸 하나에 비유 하나, 숫자 하나.
- 신호등 같은 색 비유는 사고팔라는 뜻으로 읽힐 수 있으니, 색마다 「지난 기록」이라는 말을 함께 둔다. [판단: 직접 자료 없음]
## 못 찾은 것
- 한국 성인 대상 금융 비유 실험(KCI 등): 검색 세 번 안에 못 찾음.
- 비유가 주식 투자 판단을 잘못 이끈 사례의 실험 자료: 못 찾음. 은유 틀짜기(Thibodeau 계열) 논문은 PMC 쪽이 열리지 않아 숫자를 쓰지 않는다.
- 신호등 · 장보기 비유의 개별 효과: 자료 없음.
