# 047 · 낱말 친숙도와 쉬운 낱말
## 사실 (출처 · 날짜 · 주소)
- 국립국어원 「현대 국어 사용 빈도 조사」는 문학·신문·잡지에서 표본을 뽑아 셌다. 일반 단어 1,484,463개 가운데 서로 다른 단어는 58,437개였다. (국립국어원 소식지 2003.2, https://www.korean.go.kr/nkview/nknews/200302/55_3.html)
- 이 조사는 한국어 교육에 쓸 낱말을 고르는 데 쓰인다고 한다. (같은 쪽)
- 이 쪽에는 「까닭」과 「이유」 같은 낱말 짝의 친숙도 비교가 없다. 한자어·고유어 비율도 이 쪽에서는 확인되지 않았다. (같은 쪽)
- 국립국어원 국민 국어능력 실태조사(2023~2025, 20~69세): 듣기 4단계 40.6%, 읽기 33.0%, 쓰기 11.2%. 쓰기·말하기는 각각 약 20%가 1단계였다. (서울신문 2026.2.6, https://m.seoul.co.kr/news/2026/02/06/20260206500303)
- 같은 조사에서 책·신문을 자주 읽는 사람이 읽기 점수가 높았다. 20대와 60대의 듣기 4단계 비율 차이는 53.8% 대 19.2%였다. (같은 쪽)
- 한국은행·금융감독원 2022 금융이해력 조사(18~79세 2,400명): 종합 66.5점, 금융지식 75.5점, 금융태도 52.4점, 디지털 금융이해력 42.9점. 금융상품을 고를 때 지인 추천에 기대는 사람은 58.4%였다. (SBS Biz 2023.3.29, https://biz.sbs.co.kr/amp/article/20000110568)
## 자료가 말하는 습관 · 성향
- 사람마다 말 이해 정도의 차이가 크고, 읽기·쓰기보다 듣기 쪽 점수가 높다. 소리 내어 읽어 주는 말이 글보다 쉽다는 뜻일 수 있으나 직접 비교 자료는 없다.
- 금융 쪽 점수는 지식보다 태도와 디지털 쪽이 낮다. 금융상품을 고를 때 남의 말에 기대는 사람이 많다.
- 낱말 하나하나(까닭/이유, 현재가/지금 값, 우량주/큰 회사)를 직접 비교한 수치 자료는 이번 조사에서 찾지 못했다.
## 큐피트에 쓸 것 (화면 · 말 · 순서)
- 뜻이 같은 낱말이 둘이면 일상 대화에서 흔히 쓰는 쪽을 쓴다. 예: 「현재가」 대신 「지금 값」, 「우량주」 대신 「큰 회사」. 근거는 약하니 사용자 반응으로 시험한다.
- 금융 용어는 한 번 풀이를 붙인다. 예: 「등락률」 대신 「한 달 동안 오른 만큼」.
- 낱말 두 개를 칸 이름으로 번갈아 쓰지 말고 한 낱말로 통일한다.
- 낱말 고르기는 설문으로 확인한다. 예: 첫 화면에 두 표현을 반반 보여 주고 어느 쪽에서 더 많이 누르는지 센다.
- 소리 내어 읽는 단추를 두면 듣기 쪽 이해가 높다는 자료와 맞는다.
## 못 찾은 것
- 「까닭」과 「이유」의 사용 빈도 · 친숙도 비교 수치.
- 「현재가」 「우량주」 같은 증권 낱말의 일반인 이해도 수치.
- 국립국어원 빈도 조사의 한자어 대 고유어 비율, 그리고 최근(2020년대) 빈도표 원문.
- 성별에 따른 낱말 이해 차이 자료 없음.
