# 090 · 노안과 글자 크기 · 색 대비
## 사실 (출처 · 날짜 · 주소)
- WCAG 2.1 성공기준 1.4.3(AA): 보통 글씨는 배경과 대비 4.5:1 이상, 큰 글씨는 3:1 이상 (W3C, 열람 2026-11-12, https://www.w3.org/WAI/WCAG21/Understanding/contrast-minimum)
- 큰 글씨 = 18pt(약 24px) 이상, 또는 굵은 14pt(약 18.5px) 이상 (같은 쪽)
- 4.499:1도 불합격. 반올림 없이 기준값으로 본다 (같은 쪽)
- 4.5:1 근거: 나이가 들며 떨어지는 대비 감도와 낮은 시력을 감안한 여유. 시력 20/40이면 3 x 1.5 = 4.5:1 필요 (같은 쪽)
- 20/40은 약 80세 노인의 흔한 시력으로 보고됨(Gittings·Fozard 1986 인용). 시력 20/80이면 약 7:1 필요(AAA 기준) (같은 쪽)
- 김안과병원 성인 1,000명 조사: 74%가 안구건조증 경험, 그중 69%가 스마트폰·태블릿·PC 쓸 때 증상 (경향신문 2022-03-25, https://www.khan.co.kr/article/202203252045005). 노안 수치는 아님
- 한국형 웹 콘텐츠 접근성 지침(KWCAG)은 정부가 장애인·고령자를 위해 권고하는 지침 (ditoday 기사에서 한 문장만 확인)

## 자료가 말하는 습관 · 성향
- 자료 없음: 휴대폰 글자 크기를 키워 쓰는 사람의 비율은 직접 열어 확인한 수치가 없다
- 자료가 말하는 것은 나이가 들수록 옅은 색과 작은 글씨를 읽는 데 더 큰 대비가 필요하다는 점뿐이다

## 큐피트에 쓸 것 (화면 · 말 · 순서)
- 본문과 칸 안 숫자의 글자색은 배경과 4.5:1 이상으로 맞춘다. 연한 회색 작은 글씨는 쓰지 않는다
- 작은 설명글은 진한 색(거의 검정)으로 하고, 연한 색은 24px 이상 큰 글씨에만 쓴다(3:1 허용)
- 회사 칸의 「고른 이유」와 날짜 같은 보조 글씨도 4.5:1을 지킨다. 크기만 줄이고 색을 옅게 하지 않는다
- 꺾은선 그래프 선도 배경과 3:1 이상 차이가 나게 한다
- 휴대폰 글자 크기 설정을 키워도 화면이 깨지지 않게 글씨 단위를 px 고정이 아닌 상대값으로 쓴다
- 배포 전 대비 검사기로 모든 글자색 쌍의 값을 재서 4.499 이하는 고친다

## 못 찾은 것
- KWCAG 2.2의 명도 대비 조항 원문(4.5:1)은 직접 열어 확인하지 못함. 검색 결과에 정부 원문이 없었다
- 휴대폰 글자 크기를 키워 쓰는 사람 비율과 40대 이후 노안 시작 비율의 한국 통계(통계청·방송통신위 등)는 찾지 못함
- 웹 검색 세 번을 다 썼고 아래 두 번째 검색 결과의 블로그류 쪽은 신뢰가 낮아 쓰지 않음
