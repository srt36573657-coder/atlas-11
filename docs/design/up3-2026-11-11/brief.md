## 할 일 (한 사람 = 생각 한 갈래)
1. 맡은 생각을 규칙 파일로 짠다: `$LAB/rules/a<번호>_v1.py`
2. 돌려 본다. 변형을 많아야 **세 개**까지(v2 · v3) — 결과를 보고 고친 까닭을 적는다(여러 번 맞춰 보는 것도 우연을 맞추는 일이라 셋까지)
3. 가장 나은 하나를 고른다 — 기준: h10 · h20 의 10곳 초과와 IC 가 0 보다 크고, 분기 넷 가운데 셋 이상이 0 보다 크며, 1·2·3등 오른 때가 50% 넘는가
4. `$LAB/agents/a<번호>.json` 에 적는다:
   {"agent": 번호, "idea": "맡은 생각", "best": "rules/a<번호>_vN.py", "name": "쉬운 이름", "tried": ["v1 ...", "v2 ...(바꾼 까닭)"],
