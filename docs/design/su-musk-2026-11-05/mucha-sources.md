# 무하 가이드 원전 확인표 (2026-11-05)

열어 본 쪽만 적었다. 확인 못 한 것은 「못 확인」이라 적고 짐작하지 않았다. 「보이는 요소」는 쪽 설명에 실제로 있는 말만 옮겼다.

## 2. 열 가지 요소 중 원전에서 확인한 것

- 후광 원반: 황도 12궁 · 보석(모자이크 후광) · 예술(둥근 바탕).
- 아치 틀: 하루의 때(아치 꼴 꽃 테두리 · 고딕 창 틀) · 지스몽다(아치 단).
- 꽃 덩굴 띠: 꽃 · 하루의 때 · 장식 자료집(꽃 응용 · 띠).
- 모자이크: 보석(모자이크 후광)만 확인.
- 글씨가 그림에 녹음: 장식 자료집 54번 도판 · 지스몽다는 못 확인.
- 세로로 긴 판: 지스몽다 · 꽃 · 하루의 때 · 사계 · 보석.
- 별과 달: 달과 별(별을 사람으로 그림). 초승달 · 오각 별 모양은 못 확인.
- 굵기가 변하는 윤곽 · 소용돌이 곡선 · 파스텔 색면과 금: 열어 본 쪽 설명에 말이 없어 못 확인.

## 3. 가이드와 다른 점

1. 가이드 「예술 · 하루의 때: 아치 창 안의 여인 · 창틀에 덩굴」 → 재단은 예술을 「둥근 바탕」, 하루의 때를 「고딕 창 같은 틀 · 아치 꼴 꽃 테두리」라 적음 → 고칠 말: 「예술 = 판마다 둥근 바탕 / 하루의 때 = 아치 창틀에 꽃 테두리」로 나눠 적는다.
2. 가이드 「황도 12궁: 원반 둘레에 열두 칸 띠 · 칸마다 기호」 → 재단은 「열두 별자리가 머리 뒤 후광 같은 원반을 이룬다」고만 적음 → 고칠 말: 「열두 별자리가 후광 원반을 이룸」으로 줄인다(「띠 · 칸」은 못 확인).
3. 가이드 「지스몽다 1894 ~ 1895」 → 재단은 1894, V&A는 1895 제작. 초연은 1894년 가을, 개막 1895-01-04 → 고칠 말: 「1894 ~ 1895」는 맞음. 「머리 뒤 반원 아치」는 쪽에 「아치 단 위에 선다」로 나와 있으니 「아치 모양 단」으로 바꾼다.
4. 가이드 「사계: 머리카락이 틀 밖으로 흐름」 → 열어 본 쪽에 없음 → 고칠 말: 「계절 여인 + 시골 풍경 뒤」로 쓰고 머리카락 말은 가이드 몫의 그림 규칙임을 밝히거나 뺀다. 판 비율은 1 : 1.9라서 「아주 긴 판」은 지스몽다(1 : 2.9)와 하루의 때(1 : 2.8)에만 쓴다.
5. 가이드 「달과 별: 밤하늘 남색 바탕 · 별과 초승달」 → 재단은 「우주에 떠 있고 안에서 빛을 받는다 · 명상하는 몸짓」 → 고칠 말: 「여인이 우주에 떠서 안쪽 빛을 받음」. 남색 · 초승달은 못 확인.
6. 가이드 「장식 자료집: 모자이크 테두리 · 여인 얼굴 선 굵기」 → V&A · 재단은 장식 판 · 꽃 응용 · 벽지 · 띠 · 색유리 · 금속공예 · 서체를 적음. 모자이크 · 얼굴 선 굵기 말은 없음 → 고칠 말: 「꽃 응용 · 띠 · 벽지 · 색유리 · 서체 본」으로 바꾼다.
7. 가이드 「장식 인물: 둥근 틀 · 반원 틀」 → 열어 본 쪽은 「둥근 틀」(큰 원 · 작은 원)만 보임 → 고칠 말: 「둥근 틀에 앉은 여인」. 반원 틀은 못 확인.
8. 가이드 「보석: 보석 빛깔 하나로 판 전체 색 · 토파즈 = 금」 → 재단은 「옷 · 머리장식 · 후광 · 눈까지 보석 색에 맞춤」 → 고칠 말: 「보석 색에 맞춰 옷 · 후광 · 눈 색을 정함 + 모자이크 후광」으로 쓴다. 토파즈가 금빛인지는 못 확인.
