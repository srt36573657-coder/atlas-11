# 아름다움 심사 1회 — 셋 모두 「아니오」(4 · 5 · 5점) → 다시 만든다(주문 1023 [1] 5 · 7)

심사 셋은 서로 모르게 따로 봄(같은 그림 열여섯 장 · 밝은 판 · 어두운 판). 셋이 겹친 지적만 모음.

## 셋 모두 같은 말
1. **여인에게 곡선과 풍만함이 없다** — 몸이 통 · 세모 · 종 모양이고 정면으로 꼿꼿함(차렷). 선 굵기가 처음부터 끝까지 같음.
   → 고개를 한쪽으로 기울이고 허리 · 골반은 반대쪽으로 틀어 **S자**로 세운다(무하의 콘트라포스토). 허리는 잘록하게, 둥근 몸선이 긴 옷 주름 위로 드러나게.
   → 주름은 몸을 감아 **비스듬히 여러 겹** 흐르고, 발끝에서 자락이 휘감긴다. 한 손은 머리카락이나 어깨 옷자락을 쥔다.
   → 머리카락은 **후광을 가로질러 크게 소용돌이**치며 판 끝까지 퍼진다.
   → 바깥 선은 굵게 시작해 가늘게 빠지게(채운 초승달 꼴 path) · 안쪽 결은 가늘게.
   → 옷은 지금처럼 목 · 손목 · 발목까지 덮는다(여고생도 보는 화면). 화면마다 자세를 다르게(「왜 사?」 · 매매일지가 같은 여인이면 안 됨).
2. **이름표 · 단추가 여인의 몸과 머리칼을 덮는다** — 흰 이름 상자가 단추판처럼 보임.
   → 몸 위에는 아무것도 올리지 않는다. 이름은 **금테 리본 위 글자**로 바꿔 그림 둘레 **띠**(위 아치 띠 · 양옆 세로 띠 · 아래 받침 글씨판 — 무하 포스터의 글자 띠 자리)에 둔다. 흰 상자 없음.
   → 같은 목록은 한곳에 모은다(「꽃이 될」 일곱을 위 다섯 · 아래 둘로 가르지 않음).
   → 「친구에게」 여섯 단추는 아치 둘레 **꽃 화환**으로.
3. **자료 화면은 표를 틀에 넣었을 뿐** — 가운데 흰 판 위 보통 그래프 · 얇은 꽃 테두리.
   → 흰 판을 걷고 그래프 자체를 그림으로(값 모양 · 차례 · 칸 수는 그대로 — [6] 6). 예: 기록의 100칸 격자 둘 = 둥근 문틀 안 금빛 테를 두른 **색유리 창** · 업종 막대 = **덩굴 띠**(막대 끝에 숫자 · 오름 · 내림 다른 색).
   → 위 아치 안에 **여인 얼굴 둥근 액자**(메달) 하나 · 제목은 아치를 따라 휘어 쓴 글씨 · 양옆은 굵게 휘는 **채찍 덩굴 띠** · 아래는 꽃 모자이크 띠.
4. **흐린 글씨** — 들어올 때 움직임이 끝나지 않아 반투명으로 찍힘(맨 아래 이름 · 「개인 +118,362」 · 「왜 사?」 7 · 8 · 10).
   → 글씨는 처음부터 진하게(opacity 1). 움직임은 리본 · 꽃 · 머리칼에만(transform). 0.6초 안에 끝남.
5. **어두운 판** — 가운데 여인의 흰 옷이 검게 뒤집혀 몸이 바탕에 묻힘.
   → 여인의 살 · 옷 · 꽃다발은 어두운 판에서도 크림 · 상아 · 파스텔 그대로(고정 색). 바탕만 어두워짐.
