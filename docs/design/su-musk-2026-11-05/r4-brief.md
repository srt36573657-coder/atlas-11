## 공용 부품 2판(지금 다른 일꾼 K2 가 고치는 중 — 이름 · 인자는 아래 그대로)
- 그대로 고쳐짐(네가 손댈 것 없음 — 부품을 쓰는 곳은 저절로 바뀜): `hair` · `strands` = 굵은 다발 넷 ~ 여섯(가는 선 수십 가닥 아님) · `medallion` = 목까지 옷 · 옷깃(맨살 없음) · `stemBar` = 나뭇결 줄 없음 · 굵기 변하는 윤곽 · `scroll` = 가는 금선 · 작은 말림.
- 새로 생김(K2 가 먼저 빈 꼴을 놓고 `…/scratchpad/s1238/kit2/STUBS` 파일을 둠 → **그 파일이 생긴 뒤에만** import 에 넣는다 · 그 전에 넣으면 쪽이 안 열림):
```js
leafBar({x, y, len, dir = 'right', w = 18, tone = 'gold', vein = true})  // 가로 막대를 잎 · 꽃잎 꼴로 — (x,y) 가 줄기 쪽 밑동(세로 가운데) · 길이 len 그대로 · 밑동이 넓고 끝이 뾰족 · 가운데 잎맥 · 가는 금 테 · dir 'right'|'left' · tone 'gold'|'rose'|'sage'|'red'
stemBar({…, tip = 'bud'})  // tip 에 'flower'(핀 꽃) · 'closed'(닫힌 붉은 봉오리) · 'bud'(잎 둘이 감싼 봉오리) · 'leaf' · 'none'
plaque({x, y, w, h, tone = 'cream', knots = true})  // 위가 둥근 아치 판(가는 금 겹선 · 위 두 귀퉁이에 작은 꽃 매듭) · 글 자리 = 반환 <g> 의 dataset.ix · iy · iw · ih
ribbon(pts, {w = 26, tone = 'cream'})  // 곡선을 따라 휘는 리본 띠(가는 금 가장자리 · 끝은 접혀 갈라짐) · 가운데 선 path 의 id = 반환 <g> 의 dataset.path(그 위에 <textPath href="#id"> 로 글을 휘어 씀)
```
- **두루마리(scroll)는 이제 꼭 필요한 곳 한두 곳만** — 이름표 · 값 칸은 `plaque`(아치 판) · 원 메달 · `ribbon` 으로(심사 셋 「열 쪽에 되풀이 · 보물 지도」).
- 아치 · 띠 위 큰 글씨는 흰 테(paint-order stroke) 없이 갈색 · 금빛으로 띠 안에 새긴다(띠 바탕이 고르니 테가 필요 없음). 그림 위에 얹힌 작은 이름표만 테를 둔다.
- 화면 맨 아래 8 단위(viewBox y 612 ~ 620)는 아래 막대에 가릴 수 있음 → 꾸밈만.
