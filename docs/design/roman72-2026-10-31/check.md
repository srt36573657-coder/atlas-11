# 로마 신화 일흔두 명 — 따로 맞대 본 기록(2026-10-31)

다른 일꾼(읽기만 · 웹 출처)이 72명을 한 명씩 맞댐 — 사실이 틀린 것 0 · 다듬은 곳 5 · 확인 못 한 사람 0 · 그리스에만 나오는 인물 0 · 이름 적기 틀림 0

## 고친 곳 다섯

- 베스타: 「화덕 불의 여신이에요. 나라의 불을 꺼뜨리지 않았어요.」 → 「화덕 불의 여신이에요. 여사제들이 나라의 불을 지켰어요.」 — 둘째 문장 주어가 여신으로 읽힘 — 불을 지킨 것은 여사제들
- 베르툼누스: 「계절이 바뀌는 신이에요. 모습을 바꿔요.」 → 「계절이 바뀌는 것을 맡은 신이에요. 모습을 마음대로 바꿔요.」 — 「계절이 바뀌는 신」이 흐림
- 로마 토박이 신: 「그리스 짝이 없거나 로마가 먼저 모신 신이에요.」 → 「그리스 짝이 없거나 원래부터 로마에 있던 신이에요.」 — 「로마가 먼저 모신」이 「그리스보다 먼저」로 읽힘 — 사투르누스 · 옵스 · 파우누스 · 벨로나 · 포르투누스는 그리스 짝이 있음
- 열두 큰 신: 「로마가 가장 높이 모신 열두 신이에요.」 → 「로마가 열두 큰 신으로 함께 모셨어요.」 — 「가장 높이」는 지나침 — 가장 높은 사제 셋을 둔 신은 유피테르 · 마르스 · 퀴리누스
- 좋은 마음을 모신 신: 「좋은 마음을 모신 신」 → 「좋은 것을 모신 신」 — 포르투나 · 빅토리아 · 살루스 · 팍스는 마음이 아니라 운 · 이김 · 건강 · 평화
- 좋은 것을 모신 신: 「로마는 좋은 마음에 신전을 지었어요.」 → 「로마는 믿음과 평화 같은 좋은 것에 신전을 지었어요.」 — 같은 까닭

## 일꾼이 확인한 것(출처 한 곳 이상)

- 팔레스 축제 4월 21일 = 로마의 생일 · 테르미누스가 카피톨리움에서 자리를 안 옮긴 이야기 = 리비우스 1권 55장 · 포르투누스의 표시 = 열쇠
- 리베르 = 자유의 신 · 페로니아 = 풀려난 종들의 여신 · 레무레스 = 5월 9 · 11 · 13일 콩 의식 · 보나 데아 = 여자들만 모신 여신(브리태니커)
- 멘스 신전 = 트라시메누스 패배 무렵 · 포르투나의 바퀴 = 키케로 · 오비디우스 · 아스카니우스와 알바 롱가 = 리비우스 1권 3장 · 에반데르와 팔라티누스 = 리비우스 1권 5장 · 누마 = 둘째 왕
- 비르투스는 남자로도 여자로도 그려져 「신」으로 둠 · 로비구스는 곡식병이자 그 병을 막는 신 · 퀴리누스 「시민의 신」은 이름 풀이에 기댄 학설
- 두 가지로 쓰는 표기: 티베르/테베레 · 팔라티누스/팔라티노 · 에반데르/에우안드로스 · 아이네아스/아이네이아스
