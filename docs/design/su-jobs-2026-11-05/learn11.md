# 시안 열하나 → 하나(주문 0054 [8] 5 ~ 8 · [10] 1)

시안은 빈 파일에서 따로 만든 판(작업 폴더 art3/b01 ~ b11 · 서로 보지 않고 같이 만듦) · 장점은 한 줄씩 · 진짜 판(site/su/)에 가져간 것은 ✓ · 못 가져간 것은 ✗
잣대는 잡스 잣대 — 첫 화면 한 장 · 누르면 까닭 먼저 · 일곱 번에 끝 · 빼면 안 되는 것만 남김

## 열하나 모두 같은 데서 막힌 것
- 수급 단위 · 업종 앞섬 단위가 자료에 없음 → 「확인 필요」
- 꽃 조건을 다 채운 곳 0곳 → 「가장 가까운 7곳」이라고 밝힘
- 「가짜 돈 자동 매수」 이름에 화면에 쓰지 않는 말 → 화면 이름만 바꿈(진짜 판: 「가짜 돈 자동 거래 연습」 · 명단 글자는 자료 2 그대로)
- 원효 · 아우렐리우스 말씀이 글자만 맞대면 쓰지 않는 말과 겹침 → 진짜 판은 말씀을 바꾸지 않음(사이트 말 거르기가 「사라지」를 보통 말로 둠 · 검사 0건)
- 옛 기능 가운데 자료가 없는 칸이 22 ~ 51 → 진짜 판은 옛 쪽을 그대로 열어(수르 틀) 빈 자리를 만들지 않음
