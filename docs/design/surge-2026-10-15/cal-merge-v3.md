# 달력 탭 결정표 v3 — 마지막 판(tr-v1) · 셈 · 따로 세기 · 화면이 함께 따르는 정의

v2(반대 1판 반영) + 사장님 2026-10-15 21:24(싱가포르) 「가 로 해」 = (가) 「지난 한 달도 되짚어 추적 파일을 열어요」.
숫자 · 낱말 · 차례는 여기 적은 그대로. 이 표 밖의 것을 셈에 넣지 않는다.

## 0. 넘는 규칙 한 줄(정직)
규칙 69 ⑥ 「그 뒤 기록 상자 없음」은 사장님 16:34 「몇일후 어떻게 됐는지도 확인」 · 20:00 「어떤 종목이 어떻게 됐는지 알수 있어야 해」 · 20:51 「추적하는 시스템」으로 이 탭에서만 넘는다. 넘는 것은 「지금 지켜보는 곳의 지금 상태」뿐 — 지난 기록 시험(「n번 중 m번 올랐다」 성적표) · 앞날 말 · 「만」 같은 판정 말은 없다. 같은 날들 모든 회사와 같은 단위로 늘 나란히.

## 1. 재료
- 일봉: surge.py 의 `load(now.json, ATLAS_T365_CLOSES)` 와 같은 것 — 회사 번호 allc(번호 차례) · 거래일 D(오름차순) · 종가 C[t][j] · 거래량 V[t][j](없으면 NaN). provisional = surge.py `provisional_of`(마지막 날 값을 그날 서울 20시 전에 받음). L = D 의 마지막 날. Ldone = provisional 이면 L 앞 거래일 · 아니면 L.
- Day(t): surge.py `Day(C, V, cnt, k)` 와 같은 셈(clean · liquid · ratio · 차례 E = ratio 큰 → liq 큰 → 번호 작은).
- 칸 BANDS: b10 [1.10, 1.20) · b20 [1.20, 1.30) · b30 [1.30, 1.40) · b40 [1.40, ∞). 칸 글자 b10='1' · b20='2' · b30='3' · b40='4'.
- 기록: `reports/atlas11/t365/surge/` 의 올라간 고르기(이름 차례) 가운데 payload.bands.version == 'sb-v1' 인 것 + 이번 업데이트에 새로 고른 판(있으면 맨 끝). 기록 하나 = {asOf, provisional, kst, slot, bands: {b10..b40: {members: [{c, n, r5}]}}}. asOf 가 D 에 없는 기록은 쓰지 않음.
- 되짚음(사장님 (가)): SEED = {from: '2026-09-15', to: '2026-10-14'} — D 가운데 from ≤ t ≤ to 인 날(씨앗 날). 기록이 있는 날은 씨앗 날이어도 기록을 씀(씨앗은 기록이 없는 날만).

## 2. 날마다 명단 M(t)
- 씨앗 날 t: 칸마다 Day(t).E 차례로 훑어 ratio 가 그 칸에 드는 곳을 앞에서부터 36곳까지(surge.py 네 칸 lists 와 같음). 명단 줄 = {c, b(칸), r5 = r2((ratio − 1) × 100), kst: null, re: true}.
- 기록 날 t(그 asOf 를 가진 기록이 하나 이상): 그날 기록들을 이름 차례로 훑어 네 칸 members 를 합침. 한 회사가 여러 번 나오면 처음 나온 기록 · 처음 나온 칸(b10 → b40 차례로 훑음)의 b · r5 · kst. re: false.
- 앞 명단: 첫 씨앗 날의 앞 거래일(D 에서 바로 앞)의 씨앗 셈 명단을 「앞 명단」으로만 씀(그날 파일은 열지 않음). 그 뒤로는 명단이 있는 앞날(씨앗 날 또는 기록 날)의 명단. 명단이 없는 날(기록도 씨앗도 없음)은 건너뜀.

## 3. 파일(종목 하나 = 파일 하나)
- 명단 있는 날을 차례로 훑어: c ∈ M(t) 이고 c ∉ 앞 명단이고 c 의 열린 파일이 없으면 → 파일 엶: d0 = t · b0 · r5 · kst · re.
- 열림 = idx(Ldone) − idx(d0) ≤ 60 (idx = D 안 차례). 61 이상이면 닫힘(공개에서 내림 · 그 뒤 다시 들면 새 파일). 닫힘은 「그날 t 에 열린 파일이 있나」를 볼 때 idx(t) − idx(d0) > 60 으로 셈.
- 공개 = 열린 파일 모두. 공개 파일 차례(cases) = d0 큰(새) 차례 → b0 큰(b40 먼저) → r5 큰 → c 작은.

## 4. 값(%)
- 기준 B = C[d0][j]. B 가 NaN 이면 그 파일의 % 는 모두 null.
- p[i] (i = 0 … idx(L) − idx(d0)): t = D[idx(d0)+i] · C[t] 있으면 r1((C[t] ÷ B − 1) × 100) 아니면 null. p[0] = 0 (B 있을 때).
- r1 = 가장 짧은 10진 글로 쓴 실수의 소수 첫째 반올림(0.05 는 0 에서 먼 쪽) — 파이썬 Decimal(repr(x)).quantize(0.1, ROUND_HALF_UP). r2 는 둘째 자리 같은 뜻. −0.0 은 0.
- v(지금 %) = p[마지막] (L 의 값 · 장 중이면 장 중 값). 단 d0 == L 이면 v = null(「오늘 선택」).

## 5. 날마다 제 칸(끝난 날만 · t = d0 … Ldone)
- q(t) = '?' (Day(t).clean 아님) · 'x' (liquid 아님 또는 ratio < 1.10) · 아니면 칸 글자 '1' ~ '4'. 36자리 다툼은 안 봄.
- 사건: t = d0+1 … Ldone 마다 q(t) 가 '?' 가 아니면, 앞 비교 값 p = d0 … t−1 가운데 가장 늦은 '?' 아닌 q. p 가 없으면 사건 없음.
  - p 칸 · q(t) 칸 · 다름 → 'mv'(이동 · 새 칸 q(t))
  - p 칸 · q(t) = 'x' → 'out'(탈락)
  - p = 'x' · q(t) 칸 → 're'(다시 선택 · 칸 q(t))
- d0 에서: q(d0) == 'x' 이면 d0 에 'out'.
- d0 > Ldone(오늘 선택 · 장 중)이면 칸 · 사건 없음.

## 6. 상태 · 금빛(끝난 종가로만 · d0 < Ldone 인 파일만)
- top(t) = C[d0 … t] 가운데 가장 큰 값(NaN 뺌). half(t) = C[t] 있고 C[t] × 2 ≤ top(t). halt(t) = C[t] 있고 V[t] == 0.
- jumpy = d0+1 … Ldone 가운데 C[u] · C[u−1] 둘 다 있고 |C[u] − C[u−1]| × 100 > C[u−1] × 35 인 날이 하루라도.
- 서 있는 표: f = half(Ldone) ? (jumpy ? 2 : 1) : 0 · h = halt(Ldone) ? 1 : 0 · x = (q(Ldone) == 'x') ? 1 : 0.
- 새로 생긴 금빛(첫 화면 줄): 반 토막 = half(Ldone) 이고 d0+1 … Ldone−1 에 half 가 하루도 없음 · 거래 멈춤 = halt(Ldone) 이고 (Ldone == d0+1 이거나 halt(Ldone 앞 거래일) 아님). 한 종목은 한 줄에만 — 둘 다면 거래 멈춤.
  - 줄: kind 'halt' 먼저 · 'half' 다음 · 줄마다 n(곳 수) · top = 그 가운데 v 가 가장 작은 곳(같으면 c 작은) {c, n(이름), v}. 금빛 '!' 는 f == 1 일 때만 · f == 2 면 '?' (값 고침 의심). cs = 그 줄 종목 번호 모두(v 작은 → 번호 · v 없음은 뒤) — 화면 「새로 생긴 일」 접은 칸(2026-10-15 고침).
- 조심(파일 단계에만): d0+1 … min(d0+25, Ldone) 가운데 처음으로 「C[t] 가 C[t−14 … t] 가운데 가장 크고(NaN 있으면 안 셈) · (C[t] × 10 ≥ C[t−5] × 16 또는 C[t] ≥ C[t−15] × 2)」 인 날 t → 단계 'warn'.
- 상태 글자 st: d0 == L → 'n'(오늘 선택) · v == null → 'q'(? 값 없음) · v > 0 → 'u'(올라 있음) · v < 0 → 'd'(내려 있음) · v == 0 → 'z'(제자리). 거래 멈춤 · 반 토막은 h · f 로 따로(둘째 줄 낱말).

## 7. 답 한 줄 · 같은 날들 모든 회사
- N = 공개 파일 가운데 st ≠ 'n'. a = st 'u' 수 · b = st 'd' 수. k = st 'n' 수(d0 == L).
- n10 = ⌊(20a + N) ÷ (2N)⌋ (N > 0 · 「10곳 중 n10곳이 뽑힌 날보다 올라 있어요」).
- 같은 날들 모든 회사: 파일마다(st ≠ 'n') S_f = allc 가운데 C[d0] · C[L] 둘 다 있는 곳 수 · U_f = 그 가운데 C[L] > C[d0] 인 곳 수. U = ΣU_f · T = ΣS_f · m10 = ⌊(20U + T) ÷ (2T)⌋ (T > 0).
- 파일 mk(종목 파일의 「같은 날들 모든 회사는 보통 ±x%」) = 그 S_f 곳의 (C[L] ÷ C[d0] − 1) × 100 가운데값(짝수면 가운데 둘의 평균) → r1. d0 == L 이면 null.

## 8. 날짜별 묶음 days(창 = 첫 씨앗 날(없으면 첫 기록 날) … L · 새 날이 앞)
- 날 t 마다: sel = 그날 연 공개 파일 번호(cases 차례) · mv = [[번호, 새 칸 글자]] · out = [번호] · re = [[번호, 칸 글자]] — 사건은 그날 일어난 공개 파일 것만(끝난 날만 · 번호 차례). seed: 그날 명단을 씨앗 셈으로 만들었으면(SEED 안 · 그날 기록 없음) true · 아니면 false(맞대 보고 고침 2026-10-15).
- seed(머리) = D 안에 SEED 날이 하루라도 있으면 {from, to} · 없으면 null. 같은 날 사건 차례 = 칸 사건(out · mv · re) 다음 warn. 이름 = mkt.json → 기록의 n → 번호.

## 9. 공개 파일 둘
- `surgetr.json` = {schema: 'atlas-new-surgetr-1', version: 'tr-v1', asOf: L, last: Ldone, provisional, kst(만든 때 서울 'YYYY-MM-DD HH:MM'), slot, seed: {from, to} 또는 null, first: 첫 기록 날(없으면 null), dates: 창 안 D(오름), N, a, b, k, n10, m10, U, T, alerts: [{kind, n, top: {c, n, v}, f(반 토막일 때 1 또는 2)}], days: [{d, seed, sel, mv, out, re}](새 날이 앞), cases: [[c, 이름, d0, b0 글자, r5, v, st, h, f, x, re(0|1), kst(연 기록 때 · 씨앗이면 null)]]}
- `surgetr-case.json` = {asOf, cases: {번호: {p: [...], q: '1x?…'(끝난 날 칸 글자 · d0 부터), z: [거래량 0 인 날의 i], ev: [[날, 'out'|'mv'|'re'|'warn', 칸 글자 또는 null]], mk}}}
- 이름: mkt.json companies[c].n · 없으면 기록의 n · 없으면 번호.
- 크기 문: surgetr.json ≤ 150,000 바이트 · surgetr-case.json ≤ 400,000 바이트(압축 전). 넘으면 셈 멈춤(앞 판 + 까닭).

## 11. 화면(달력 탭 `#/cal` · 종목 파일 `#/cal/<번호>`)
- 머리 「달력」 + 오른쪽 「지켜보는 N곳」 · 때 한 줄(마감 「10월 15일 종가예요.」 · 장 중 「10월 16일 12시 값이에요. 장 중이라 바뀌어요.」 · 못 받음은 금빛 「?」 한 줄).
- 답: 「10곳 중 n10곳이 뽑힌 날보다 올라 있어요」 + 막대 하나(빨강 a · 파랑 b · 회색 나머지) + 「위 a곳 · 아래 b곳」 + 「같은 날들 모든 회사는 10곳 중 m10곳이 올랐어요.」 · N = 0 이면 「오늘 처음 k곳이 뽑혔어요. 등락률은 다음 장날부터 쌓여요.」
- 금빛 줄(새로 생긴 것만 · 두 줄까지) · 고르기 칩(전체 · 10% · 20% · 30% · 40% = b0) · 날짜별 묶음(달력 날 판 + 「선택 k · 이동 m · 탈락 x」(+ 「· 다시 선택 r」) + 줄 넷 + 「나머지 n곳 보기」 + 「이동 · 탈락 보기」) · 5거래일씩 「지난주 보기」 · 되짚은 날은 날 판 밑 「되짚음」.
- 줄(52px) = 이름 · 오른쪽 % (빨강 · 파랑 · 0 은 먹색) · 둘째 줄은 「! 반 토막」 「? 거래 멈춤」만(금빛). 오늘 선택 줄 = % 대신 「오늘」 + 칸 알약.
- 맨 위 「★ 관심 n곳」 묶음(있을 때만) · 맨 밑 「숨긴 곳 n곳 보기」 · 「어떻게 골랐나요?」(접음) · 정직 두 문장.
- 종목 파일: 「‹ 달력」 · 이름 · 상태 낱말 · 「뽑힌 날부터 ±n%」 · 「같은 날들 모든 회사는 보통 ±x%였어요.」 · 선 그림(0 점선 · 거래 0 인 날 빈 점) · 칸 길 그림(40%대 · 30%대 · 20%대 · 10%대 · 빠짐 다섯 줄 · 계단) · 단계(새 것 위 · 넷 + 「더 보기」) · 「관심」 「관심 없음」 · 「회사 보기 ›」.
- 낱말: 선택 · 이동 · 탈락 · 다시 선택 · 되짚음 · 오늘 선택 · 반 토막 · 거래 멈춤. 「급등」 · 「더 오름」 · 「덜 오름」 · 「만」 판정 · 사라 · 팔라 · 앞날 말 없음.
