# s07 · 꽃 · 나무 · 풀 묘사 (공부 일꾼 7 / 10)

본 것: 보내 주신 그림(매화 부분 다섯 곳을 3~4배로 키워 봄) · before.png 식물 칸 여덟(g11 · g12 · g13 · g14 · g21 · g26 · g29 · g31) · su-sonja-ink.js 의 blossom · peony · pine · tree · bare · grass 정의(읽기만).
해 본 것: 우리 붓 함수(br · wash · dot)를 연습장에 옮겨 식물 시험판 일곱 장을 그리고, 크롬과 rsvg 로 3배 · 휴대폰 한 칸(170px) 크기에서 견줌. 색은 밝기 · 선명도 · 색상각과 색 거리(CIEDE2000)로 셈.

## 1. 백 가지 관찰과 배움 (무엇이 보이나 → 왜 깊이 · 자세함 · 색을 만드나)

가. 보내 주신 그림의 꽃
1. 꽃잎은 다섯 장, 끝이 동전처럼 둥글다 → 홈 진 벚꽃 · 길쭉한 복사꽃과 달리 한눈에 매화로 읽힌다.
2. 꽃잎마다 칠보다 짙은 가는 테가 있다 → 옅은 꽃이 종이 위에 떠오르고 꽃잎 수가 세어진다.
3. 꽃 가운데에 짙은 점과 짧은 꽃술 줄이 있다 → 작은 꽃에도 「얼굴」이 생겨 동그라미와 갈린다.
4. 활짝 핀 송이 지름은 그림 폭의 약 4~6%(키워서 잼) → 200 폭 그림이면 8~11.
5. 봉오리는 둥근 점 하나, 폭의 약 1.2% → 200 폭이면 2.4 안팎.
6. 봉오리 밑에 먹 꽃받침 점이 붙는다 → 봉오리가 가지에 매달린 무게가 보인다.
7. 앞모습 꽃 사이에 꽃잎 두셋만 보이는 옆모습(반쯤 핀 잔 모양)이 섞인다 → 도장 찍은 듯한 되풀이가 없다.
8. 꽃은 둘 · 셋 · 넷씩 겹쳐 무리를 이룬다 → 앞 꽃이 뒤 꽃을 가려 두께가 생긴다.
9. 꽃은 어린 가지 마디와 위쪽에 몰리고 굵은 줄기 몸통엔 거의 없다 → 실제 매화 성질 그대로라 믿음이 간다.
10. 가지 끝은 봉오리, 안쪽은 활짝 핀 꽃이다 → 「안에서 밖으로 핀다」 순서가 그림에 들어 있다.
11. 꽃 칠은 번짐 없는 한 색 + 테 → 작은 크기에서도 깨끗하다.
12. 꽃 칠 사이로 먹 가지가 비치지 않는다(불투명) → 꽃이 가지 앞이라는 앞뒤가 분명하다.

나. 보내 주신 그림의 줄기 · 가지
13. 늙은 줄기는 거의 가로로 눕고 굵기가 폭의 약 5~6% → 200 폭에 9~13.
14. 줄기 겉에 먹이 끊긴 흰 결과 비늘 같은 짙은 먹 덩이가 있다 → 거친 껍질 = 나이.
15. 짙은 줄기 둘레에 옅은 회색 먹이 퍼져 있다 → 둥근 부피와 젖은 먹 맛.
16. 줄기 가장자리에 짙은 이끼 점이 뭉쳐 붙는다 → 늙은 나무의 볼거리이자 테두리 강조.
17. 어린 가지는 늙은 줄기에서 화살처럼 곧게 위로 쏜다 → 늙음과 새것이 맞서는 이야기.
18. 어린 가지 굵기는 폭의 0.3~0.4%(200 폭에 0.6~0.9) → 휴대폰에선 사라지므로 우리는 굵혀야 한다.
19. 가지 옆에 짧고 뾰족한 검은 곁눈이 가시처럼 많다 → 매화 가지 신호이자 자세함.
20. 가지 끝이 쥐꼬리처럼 가늘게 빠진다 → 붓 맛과 끝의 긴장.
21. 가지가 엇갈려도 나란하거나 직각 십자로 겹치지 않는다 → 그물처럼 보이지 않는다.
22. 줄기 뒤로 옅은 먹 가지가 한 겹 더 있다 → 앞뒤 두 층의 깊이.

다. 보내 주신 그림의 깊이 · 짙기 · 색
23. 색은 셋뿐 — 회색 종이 · 먹 · 꽃 한 색 → 꽃 한 색이 주인공이 된다.
24. 꽃 칠은 그림 넓이의 약 3%, 먹은 약 6%(낱칸으로 셈) → 색은 적게 쓸수록 눈에 띈다.
25. 먹이 가장 짙은 곳은 가지가 갈라지는 곳과 줄기 아래 → 그림의 무게 중심.
26. 밝은 달 앞을 지나는 꽃 · 가지가 가장 또렷하다 → 밝은 바탕 앞 어두운 것(맞대비).
27. 꽃 색은 짙은 붉은 분홍(렌즈 화면이 어둡게 덮어 정확히 못 잼 · 어림 #E0475E, 색상각 19°) → 한국에선 오름 빨강에 가깝다.
28. 꽃은 가지를 그린 뒤 얹고, 뒤 꽃 몇은 가지 밑에 둔다 → 그리는 순서 둘로 깊이를 만든다.
29. 작은 꽃이 수십 개여도 무리는 예닐곱 → 눈은 낱 꽃이 아니라 무리로 읽는다.
30. 꽃 · 봉오리 · 가지 끝이 모두 위나 바깥을 향한다 → 그림 전체에 자라는 힘이 생긴다.

라. 옛 매화 그리는 법(공공 기법)
31. 매화 꽃은 다섯 얼굴(앞 · 옆 · 뒤 · 위로 · 아래로)로 그린다 → 섞어야 산 꽃이 된다.
32. 뒤로 돌아앉은 꽃은 꽃받침 다섯이 먹 별처럼 보인다 → 지름 14 넘을 때만 그릴 자세함.
33. 꽃받침은 짙은 먹 점으로 찍는다 → 분홍과 먹이 맞닿아 또렷하다.
34. 꽃술은 가는 줄 끝에 점, 가운데 하나는 길게 → 꽃의 중심이 선다.
35. 옛말 「매화는 성김 · 늙음 · 여윔 · 봉오리를 귀히 여긴다」 → 꽃을 빽빽이 채우지 않는다.
36. 가지를 그릴 때 꽃 자리를 비우고 꽃 뒤에서 먹을 끊는다 → 꽃이 가지 앞에 앉는다.
37. 위로 갈라지는 사슴뿔꼴 가지(매화 · 젊은 나무)와 아래로 굽는 게발꼴 가지(겨울 숲 · 늙은 나무) → bare 와 blossom 나무의 성격을 가른다.
38. 세 가지가 한 점에서 비켜 지나는 엇갈림은 좋고, 직각 십자와 우물꼴(나란한 두 쌍)은 피한다.
39. 같은 높이에서 양쪽으로 마주 난 가지는 피한다 → 어긋나야 자연스럽다.
40. 늙은 줄기는 먹이 덜 묻은 마른 붓으로 흰 결을 남긴다 → 거칢과 나이.
41. 이끼 점은 셋 · 다섯씩 모아 찍는다 → 흩뿌린 깨처럼 보이지 않는다.
42. 조선 어몽룡의 월매도(5만 원권 뒷면): 늙은 줄기는 꺾이고 어린 가지는 하늘로 곧다 → 한국 사람에게 익숙한 매화의 뼈대(원리만 쓰고 짜임은 따르지 않는다).
43. 매화는 붉은 홍매와 흰 백매 두 갈래 → 우리는 백매에 분홍 기를 더한 연분홍(빨강 없음).
44. 먹으로 동그라미 테만 두르는 먹 매화도 정통 → 먼 꽃 · 뒤 꽃은 테만 옅게 해도 된다.
45. 벚꽃은 긴 꽃자루에 매달리고 매화는 가지에 바짝 붙는다 → 꽃자루를 그리지 않아야 매화.

마. 소나무
46. 옛말 「소나무 껍질은 비늘, 측백은 노끈」 → 비늘 결 하나로 소나무가 된다.
47. 솔잎은 한 점에서 반바퀴로 퍼지는 부채꼴 → 바늘 7~9 줄이면 충분하다.
48. 솔잎 덩이는 납작한 접시처럼 층층이 쌓인다 → 동그란 덩이는 막대사탕처럼 보였다(시험판 1판).
49. 가지는 줄기에서 가로로 뻗고 끝이 처진다 → 늙은 소나무의 무게.
50. 줄기는 비틀려 오르고 꼭대기는 평평하다 → 오래 산 나무.
51. 앞 솔잎은 짙게(먹 0.85), 뒤 솔잎은 옅게(0.4) → 접시 사이 깊이.
52. 솔잎 덩이는 초록 번짐 위에 먹 바늘 → 먹이 꼴을, 색이 부피를 맡는다.
53. 옛 담채 그림은 솔잎에 쪽빛 물감(화청)을 섞는다 → 우리 남빛 데이터와 겹치므로 노랑 기 초록으로 바꾼다.
54. 우리 소나무는 위 줄기가 붉은 갈색, 아래는 잿빛 비늘 → 빨강 대신 황토를 위로 갈수록 넓게.
55. 작은 소나무는 바늘 없이 접시 + 먹 점 하나로도 읽혔다(시험판) → 키 50 아래는 줄인다.

바. 잎 나무 · 점 잎
56. 옛 화보는 잎 찍는 법을 수십 가지(ㅅ 꼴 점 · 화살촉 꼴 점 · 후추 점 등)로 나눈다 → 나무 종류 = 점 모양.
57. 두 그루는 주인과 손님 — 크기 · 모양을 다르게 → g26 두 나무(뽕나무 · 회화나무)를 갈라야 이야기가 선다.
58. 나무는 네 방향으로 가지를 낸다 → 납작한 Y 자 나무를 피한다.
59. 잎 덩이는 위가 밝고 아래가 어둡다 → 해가 위에 있다는 부피.
60. 잎은 세 겹 — 옅은 바탕 · 짙은 그늘 · 점 → 요소 셋으로 깊이와 자세함.
61. 먹 점은 그늘 쪽과 가지 둘레에만 → 다 찍으면 탁해진다.
62. 점끼리 반쯤 겹쳐 덩이가 돼야 한다 → 떨어지면 물방울 무늬가 된다(시험판 1판).
63. 뽕나무 = 넓은 렌즈꼴 잎(길이 5) 옆으로 퍼짐 / 회화나무 = 작은 점 둥근 지붕 → 휴대폰 170px 에서도 달라 보였다.
64. 줄기 윗부분은 잎 덩이 속으로 들어가 가려진다 → 잎이 앞에 있다는 깊이.
65. 뿌리 둘레 이끼 점 셋 → 나무가 땅에 선다.
66. 옛 산수론 「먼 나무는 가지가 없다」 → 먼 나무는 덩이 하나.
67. 옛 산수론 「산은 열 자, 나무는 한 자」(산 : 나무 = 10 : 1) → 형세 그림 능선 나무는 산 높이의 10분의 1.

사. 풀 · 이끼
68. 난초 첫 세 획 원칙 — 길게 · 짧게 · 세 번째가 엇갈려 「봉황 눈」 → 풀잎을 빗살처럼 나란히 두지 않는다.
69. 풀잎은 밑동이 굵고 끝은 쥐꼬리 → 붓 맛.
70. 앞 포기 먹 · 뒤 포기 초록 · 맨 뒤 옅은 초록 → 풀숲의 깊이.
71. 포기 밑 이끼 점 → 풀이 땅에 붙는다.
72. 한 장면의 풀은 한 방향으로 함께 휜다 → 바람이 하나다.
73. g13(풀 쳐서 뱀 놀래기)의 풀은 뱀보다 옅어야 한다 → 뱀이 주인공.
74. 밑동부터 굵은 잎(굵기 2.2)은 불꽃처럼 보였다(시험판 1판) → 1.0~1.4 로 가늘게.

아. 모란
75. 모란은 꽃잎이 여러 겹(바깥 크고 · 안 작고 · 가운데 잔 모양) → 다섯 장 꽃은 모란이 아니다(지금 g31 은 들국화처럼 보임).
76. 꽃잎 끝은 셋으로 물결진다 → 모란 신호.
77. 꽃잎 뿌리 쪽이 짙고 끝이 옅다 → 꽃 속이 깊어 보인다.
78. 위에서 비스듬히 본 꽃(세로로 납작)이 정면 동그라미보다 입체다.
79. 꽃술은 금빛 점 무리 → 분홍 한가운데 따뜻한 점.
80. 잎은 셋으로 갈라지고 갈래마다 다시 셋(세 갈래 아홉 끝) → 모란 잎 신호.
81. 잎맥은 짙은 초록 줄 → 먹 줄보다 부드럽다.
82. 민화 모란도에서 모란은 부귀와 아름다움의 꽃 → g31 미인 꾀와 뜻이 맞는다.
83. 큰 꽃 하나가 주인 → 한 장면에 여러 송이를 늘어놓지 않는다.

자. 빨강 없이 색 정하기
84. 꽃잎 #EFBFCA(밝기 81.8 · 선명도 18.9 · 색상각 3°) → 한지 #F1E3D3 과 색 거리 19 로 보인다.
85. 그러나 한지와 밝기 차는 1.28 : 1 뿐 → 테(먹 0.5)가 없으면 휴대폰에서 꽃이 녹는다.
86. 꽃 가운데 #CF8198 → 꽃잎보다 색 거리 16 짙어 「가운데가 깊은」 꽃.
87. 봉오리 #DD97AA → 핀 꽃보다 짙다(색 거리 10) — 실제 봉오리가 더 짙은 것과 같다.
88. 뒤 꽃 #F3D3DA → 한지와 색 거리 14 — 보이되 물러난다.
89. 오름 빨강(#E5302A, 색상각 36°)과 우리 분홍들의 색 거리 24~38 → 분홍 색상각을 0~8°(푸른 기)로 둔 까닭.
90. 남빛 #1F2A44 와 분홍은 색 거리 46 이상, 초록은 38 이상 → 데이터 색과 섞이지 않는다.
91. 석록 셋 — 짙은 #5F7D5B · 가운데 #7D9A72 · 옅은 #A8BC97(노랑 기) → 푸른 석록보다 밤색 먹 · 한지와 어울린다.
92. 황토 #C29A6B 는 강조 밤색 #8A5A44 와 색 거리 24 → 더 붉은 황토(#A87A52, 거리 13.6)는 깃발과 헷갈린다.

차. 작게 그리기 · 부품 수 · 우리 그림 진단

## 2. 우리 SVG에 대입할 규칙 열

1. **blossom 색** — 꽃잎 #EFBFCA(fill-opacity 1, 뒤 가지를 가림) · 가운데 #CF8198 · 봉오리 #DD97AA · 뒤 꽃 #F3D3DA(가운데 #EFBFCA) · 테 먹 #3B1A14 stroke-opacity 0.5(뒤 꽃 0.22), stroke-width = max(0.8, 지름 × 0.11), paint-order="stroke"(속성으로, 보이는 테 0.4~0.55). 분홍은 모두 밝기 62 이상 · 선명도 34 이하 · 색상각 355~10°.

## 3. 하지 말 것 다섯

1. **베끼기** — 보내 주신 그림의 짜임(왼쪽에서 들어오는 굵은 가로 줄기 · 왼쪽 위 큰 달과 그 앞을 지나는 꽃가지 · 오른쪽 아래 도장 둘 · 위 세로 글 칸)과 붉은 칠 + 짙은 테 꽃을 그대로 옮기지 않는다. 우리 꽃나무는 땅에 선 한 그루(꾀 이야기의 소품)이고, 5만 원권 월매도의 짜임(곧은 세로 가지 + 둥근 달)도 따르지 않는다.
2. **빨강** — 꽃 · 봉오리 · 꽃 가운데 · 모란 안 꽃잎에 붉은 분홍(색상각 15~40° · 선명도 40 넘음, 보내 주신 그림의 #E0475E 안팎)을 쓰지 않는다. 단풍 · 붉은 열매 · 붉은 소나무 껍질도 그리지 않고 황토 #C29A6B 로 대신한다.
3. **한자 · 글** — 매화 그림에 흔한 세로 글씨 칸 · 낙관 글씨 · 꽃 이름을 넣지 않고, 엇갈림 · 잎 점의 이름이 된 글자 꼴도 그림에 쓰지 않는다. 꽃 · 나무에는 이름표를 붙이지 않는다(그림만으로 통해야 한다).
4. **뜻 깨짐** — g29 에 잎 · 초록을 넣지 않는다(꽃을 단 마른 나무) · g11 쓰러진 나무에 꽃을 달지 않는다 · g26 두 나무를 같은 꼴로 두지 않는다 · g13 뱀을 초록으로 칠하거나 풀보다 옅게 하지 않는다 · g14 새싹을 밤색으로 두지 않는다(초록 = 다시 산 목숨) · 식물에 남빛 #1F2A44 나 푸른 석청(남빛과 색 거리 24)을 쓰지 않는다.
5. **느려짐** — 꽃잎마다 circle 을 따로(송이당 6~7개) 14송이에 쓰지 않는다(장면 하나 100개 넘음) · 솔잎 · 풀잎을 획마다 따로 두지 않는다 · 그러데이션 · 흐림 필터 · 종이 결 필터를 식물마다 쓰지 않는다(서른여섯 장이 한 쪽에 뜬다) · 짧은 획에 n = 22 를 그대로 두지 않는다 · 바깥 그림 파일(껍질 사진 등)은 0.

## 4. 두 줄 결론

가장 크게 바꿀 것: blossom 을 「밤색 점 다섯」에서 「연분홍 꽃잎 다섯 + 바깥 먹 테 + 짙은 가운데」로 바꾸고, 늙은 줄기(황토 · 흰 결 · 이끼 점)에서 곧게 뻗은 어린 가지 마디에 봉오리 · 옆모습과 섞은 무리로 단다.
까닭: 꽃 · 나무 꾀 그림 여덟 장의 이야기가 식물에 실리는데 지금 꽃은 깃발 · 도장과 같은 밤색이라 꽃으로 안 읽히고, 이 방법은 빨강 없이(빨강과 색 거리 24 이상) 꽃만의 색을 주면서 부품 수는 늘리지 않는다(g29 식물 부품 34 → 16).
