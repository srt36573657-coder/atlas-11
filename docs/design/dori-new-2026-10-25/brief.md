## 무엇을 만드나
사장님(신대근 · 한국어만 · 코딩 모름 · 휴대폰으로 봄)의 주식 공부 사이트 「돌이」(aaa7377.com)를 처음부터 새로 만들기 전에,
휴대폰 첫 화면 샘플 11개를 만들어 사장님이 하나를 고른다. 사장님 말씀(2026-10-25 20:35~20:39):
「이 색들로 돌이를 완전 새롭게 만들어 · 앤디 워홀(뉴욕 화가)이 만들었다는 전제에서 · 잡스가 만들었다면 어떻게 만들었겠냐 · 만들기 전 샘플 11개」

- 앤디 워홀 = 기법만 빌린다: 같은 모양을 색만 바꿔 되풀이하기(격자) · 납작한 색 면 · 실크스크린처럼 색 판이 살짝 어긋난 겹침(오프셋) · 굵은 검은 윤곽 · 망점(하프톤) · 큰 대중 글씨.
  워홀의 특정 작품은 그리지 않는다: 수프 깡통 · 마릴린 · 바나나 · 마오 · 상자 · 꽃 연작 구도 · 은빛 풍선 같은 것 금지. 워홀 이름 · 서명 · 유명인 얼굴도 화면에 넣지 않는다.
  되풀이할 모양은 돌이만의 것: 「싹 난 조약돌」(둥근 돌에 작은 잎 두 장) — 인라인 SVG 로 직접 그린다.
- 잡스 = 생각만 빌린다: 한 화면에 중심 하나 · 큰 글씨 · 고를 것이 적다 · 세 번에서 다섯 번 누르면 누구나 안다 · 군더더기 없음 · 작은 즐거움 하나. 잡스 얼굴 · 이름 · 사과 모양 금지.

## 화면 글 규칙(검사가 막음)
- 한국어만. 소리 나는 영어 낱말 금지(숫자 · 「9:41」은 됨). 「%」 금지 — 「네 번에 한 번」처럼 말로.
- 금지 말: 추천 · 매수 · 매도 · 팔라 · 사세요 · 파세요 · 예측 · 확률 · 유망 · 기회 · 신호 · 저평가 · 1위 · TOP · 사라 · 팔아라 · 대박 · 폭죽 · 랭킹 · 수익률 · 목표가 · 원금 보장.
  (붙어 쓴 글이 우연히 「기회」 「사라」가 되지 않게 조심: 「받기 회사」 → 「받기 · 회사」처럼 사이를 띄우거나 바꿈)
- 쉬운 말: 어린이도 아는 말. 짧게.

## 만드는 꼴(꼭 지킴)
- 샘플마다 파일 하나: sNN.html (예: s01.html). 파일 안은 아래 꼴의 조각 하나뿐(doctype · html · head · body 없음):
```
<section class="sample" id="s01">
  <style>/* 모든 선택자 앞에 #s01 */ #s01 .phone .x{…}</style>
  <div class="head">
    <span class="no"><b>1</b>반복의 벽</span>
    <p class="why"><em>워홀 방식</em> 한 줄</p>
    <p class="why"><em>잡스 방식</em> 한 줄</p>
    <p class="why"><em>누르는 곳</em> 한 줄 — 무엇을 누르면 어디로</p>
  </div>
  <div class="phone">
    <div class="island"></div>
    <div class="status"><span>9:41</span><span>…</span></div>
    … 샘플 화면 …
    <div class="homebar"></div>
  </div>
</section>
```
- 틀(.phone · .island · .status · .homebar)과 머리 글 꼴은 base.css 가 정함 — 다시 꾸미지 않는다. .phone 안은 화면만 꾸민다.
- .phone 안의 길이는 모두 cqw(틀 너비의 100분의 1 · 390 폭에서 1cqw = 3.9px)로: 글씨 · 여백 · 테두리 · 크기 모두. px 금지(1px 선만 됨).
  글씨는 4cqw(≈16px) 이상 · 본문 4.6~5.2cqw · 큰 제목 9cqw 이상. 휴대폰 화면 비율 390:844 안에 다 들어가게(넘치면 잘림).
- 바깥 것 금지: 글꼴 · 그림 · 스크립트를 인터넷에서 받지 않는다. 그림은 인라인 SVG 또는 CSS. 스크립트는 쓰지 않는다(움직임은 CSS 로 아주 살짝만 · 없어도 됨).
- 글꼴: 틀이 정한 시스템 글꼴. 굵기 700~900 으로 대중 포스터 느낌.
