## 2. 지표 정의(산식 calc-1)

모든 값은 % 단위 숫자이고, 셈 중간에 반올림하지 않는다(화면에 보일 때만 소수 한 자리). 셀 수 없으면 0 이 아니라 「계산 불가」.

| 이름 | 산식 | 대상 · 메모 |
| --- | --- | --- |
| N거래일 가격수익률(%) | (끝 종가 ÷ N거래일 전 종가 − 1) × 100 | 끝 = 판 기준일 종가 · N거래일 전 = 거래일 달력(`public/data/rolling-calendar.json`)에서 N번째 앞 거래일 · 종가 N+1 개 필요(20거래일 = 21개) · 배당 빼고(가격수익률) |
| 평균 | 값이 있는 종목 수익률 합 ÷ 종목 수 | 빠진 종목은 뺀 수와 사유를 함께(지연 · 오래된 종가 · 기업행사 확인 필요 · 종가 없음) |
| 중앙값 | 가운데 값(짝수면 가운데 둘의 평균) | 값이 있는 종목 |
| 상승 비율(%) | 0 보다 큰 종목 수 ÷ 종목 수 × 100 | 보합 = 정확히 0(종가가 같음) |
| 1위 제외 평균 · 상위 2개 제외 평균 | 큰 값부터 1 · 2개를 뺀 평균 | 남는 값이 없으면 계산 불가 |
| 자기 제외 평균 | 같은 업종 다른 종목 평균 | 비교 「같은 업종 다른 곳 평균 대비」 |
| 시장 대비 격차(%p) | 종목(업종) 수익률 − 같은 기간 지수 수익률 | 지수 = 한국 코스피 · 미국 S&P 500(저장소 지수 종가) · 지수 날짜가 판 기준일과 다르면 계산 불가 |
| 상대 가격비(%) | ((1 + 종목/100) ÷ (1 + 지수/100) − 1) × 100 | %p 격차와 다른 값(섞지 않음) · 위험조정 성과는 정의가 검증되지 않아 계산하지 않음 |
| 변동성 | 지수 지난 20거래일 하루 변화(%)의 표준편차(n − 1) | 종가 21개 |
| 최대 낙폭 · 최저 수익률 | 구간 안 가장 높던 종가 대비 가장 큰 하락 폭 · 기준가 대비 가장 낮던 수익률 | 검증 탭(둘은 다른 값) |
| 기업행사 확인 필요 | 지난 20거래일 안 하루 변화가 ±30% 를 넘은 날이 있음(한국 가격 제한폭) | 수정되지 않은 분할 · 병합 · 권리락으로 보고 계산에서 뺌 · 미국은 제한폭이 없어 하지 않음 · 공시의 분할 · 병합 · 무상증자 · 권리락 · 감자 · 합병 · 거래정지 · 상장폐지는 「기업행사 공시 — 가격 기준 확인 필요」로 표시만 |
| 지연 · 오래된 종가 | 마지막 종가가 기준일보다 1 · 2거래일 늦음 / 2거래일 넘게 늦음 | 오래된 종가 = 거래정지 여부 확인 필요 |

### 업종 상태(실험 규칙 lens-rules-1 · 검증 전 · 20거래일 · 값이 있는 종목 3곳 이상)

- 동반 강세 = 평균 > 0 · 중앙값 > 0 · 1위 제외 평균 > 0 · 상승 비율 ≥ 60%
- 일부 종목 주도 = 평균 > 0 인데 중앙값 ≤ 0 또는 1위 제외 평균 ≤ 0 또는 상승 비율 < 50%
- 엇갈림 = 평균 > 0 · 위 둘이 아님 / 약세 = 평균 ≤ 0 / 판단 보류 = 값이 있는 종목 3곳 미만
- 강세 확산 = 20거래일 평균 > 0 · 5거래일 평균 > 0 · 5거래일 상승 비율 > 20거래일 상승 비율
- 강세 약화 = 20거래일 평균 > 0 · 5거래일 평균 < 0 · 5거래일 상승 비율 < 50%
- 첫 화면 ③ 은 공식 업종(네이버 증권 업종 · 한국 64개 · 미국 73개 — 업종마다 한 번 셈)을 먼저, ATLAS 업종(73개 · 5곳씩)을 그다음에 — 잘게 나눈 산업(예: 반도체 다섯 갈래)이 개수 때문에 무게가 커지지 않게.

### 종목 묶음(실험 규칙 · 앞 저녁 기록과 견줌)

- 목록 = 그 기록의 오름 상위 22곳 · 예비 7곳 · 불장 업종의 회사.
- 새로 발견 = 앞 기록 목록에 없다가 이번 기록 목록에 든 곳(원인: 가격 변화 · 자료 지연 해소 — 앞 기록을 남길 때 그 날 종가가 아직 없었음 · 자료 지연 · 구성 종목 변경), 또는 앞 기록 뒤 ★★★ 공시가 새로 나온 곳(새 정보 — 조건 반복과 나눔).
- 근거 강화 = 두 기록 모두 목록에 있고, 앞 기록 뒤 업종 평균보다 더 오르고(가격), 외국인+기관 순매수 주식 수 합이 0 보다 큼(수급).
- 근거 약화 = 앞 기록 목록에서 빠짐, 또는 두 기록 모두 있는데 업종 평균보다 덜 오르고 외국인+기관이 순매도.
- 근거 영역은 가격 · 수급 · 실적 · 사건 넷을 따로 보인다. 불장 · 출목표 · 태양 · 포모는 모두 같은 종가에서 나와 「가격」 하나로 센다. 종합점수 · 가중치 · 상승 확률은 만들지 않는다.

### 투자자 매매(한국)

- 공식 값 = 외국인 · 기관(연기금 포함) · 개인 순매수 「주식 수」(네이버 증권 종목 투자자 동향 · 지난 10거래일 · 당일 값은 잠정).
- 추정액 = 날마다 순매수 주식 수 × 그날 종가의 합 — 공식 금액이 아니다. 그날 종가가 없는 종목은 빼고 수를 적는다.
- 1 · 5 · 10거래일 합 · 20거래일 = 계산 불가(10거래일치만 모음) · 거래대금 대비 순매수 비율 = 계산 불가(거래대금을 모으지 않음).
- 순매수 날 수 · 끝에서부터 이어진 날 · 외국인과 기관 5거래일 방향이 같은지 · 업종(5곳 합)의 외국인+기관 추정액과 5거래일 업종 평균 수익률의 부호가 같은지(「같은 돈이 옮겨 갔다」는 뜻이 아님).
- 미국 판: 투자자별 매매를 날마다 공개하지 않아 만들어 넣지 않는다.

### 업종 순환(옛 「돈 흐름」 그림)

- 금액 = 시장 대비 시가총액 변화(업종 시가총액 변화 − 시장 전체와 같은 비율로 움직였을 때의 변화 · 업종 73개를 더하면 0 · `lib/atlas11/rotation.mjs`) — 실제 투자금 유입액이 아니다. 이름도 「줄어든 곳 · 늘어난 곳 · 강세 파장」(옛 「빠지는 곳 · 들어가는 곳 · 돈의 파장」).
- 날짜 셋: 추정 시작일(두 업종 지수 비의 마지막 바닥 — 나중에 확인한 날) · 최초 포착(업종 순환은 아직 고정 기록에 남기지 않음) · 마지막 확인(판 만든 때).

### 검증(선정 결과)

## 4. 기록 규약

- 저녁 기록은 고치지 않는다(규칙 8). 판 읽기(`lens.json`)는 기록이 아니라 사이트를 쌀 때마다 저장소 자료로 다시 세는 사본이다 — 판 이름(boardId)이 다르면 화면이 쓰지 않는다.
- 실험 규칙을 바꾸면 새 이름(`lens-rules-2` …) · 이 문서 · 「검증」 탭 운영 기록 한 줄. 옛 규칙의 결과와 섞지 않는다.
- 관심종목은 이 기기에만(브라우저 저장 `atlas11:watch` · 미국 판 `atlas11:us:watch`) — 다른 기기 · 계정과 맞춰지지 않는다. 관심 등록은 공식 순위 · 기록을 바꾸지 않는다.
