# ATLAS 11 기준값 · 후향

4시간 엔진의 재현 시험(T12)에서 견줄 「ATLAS 11」 기준값입니다.

## 무엇인가
- 2026-04-06 ~ 2026-09-30 의 거래일 120일마다, 그날 종가까지의 자료만으로 ATLAS 11 v1 방법(모형 A)을 다시 돌렸습니다.
- 52종목마다 「다음 거래일 종가」를 냅니다. 목표일은 2026-04-07 ~ 2026-10-01 입니다.
- 한 줄에 분위수 7개(p05·p10·p25·p50·p75·p90·p95, 원 단위)와 오름·보합·내림 확률이 있습니다. 보합은 출발 종가 대비 ±0.10% 안입니다.
- 결과 파일: `atlas11-v1-retro.json` (6,240줄 = 120일 × 52종목)

## 「후향」이란
- 그때 실제로 나온 발행본이 아닙니다. 지나간 뒤에 같은 방법·같은 난수로 다시 만든 값입니다.
- 그래서 파일에 `"label": "후향"` 을 적었습니다.
- CRPS 는 「없음」입니다. 판정 기준은 분위수 19개를 요구하는데, ATLAS 11 은 7개만 냅니다.

## 다시 돌리는 법
```
node atlas4h/baselines/atlas11-v1-retro.mjs
node --test 'atlas4h/baselines/test/*.test.mjs'
```
- 실행은 약 13분 걸립니다(옛 입력 7분 + 지금 입력 6분).
- ATLAS 11 코드(`lib/`·`config/`)는 읽기만 합니다. 이 폴더 밖에는 아무것도 쓰지 않습니다.

## 같은 방법인지 확인한 결과
- 옛 입력(`input.json@30dcfb2`)으로 돌려, 저장된 후향 칸(`reports/atlas11/overhaul/part1-retro-A-cells.json`)과 견줬습니다.
- 견준 것: 출발일 120개 × 52종목 = 6,240칸 (그중 이 결과와 겹치는 출발일은 98개)
- `p50_1`·`up1`·`flat1`·`down1` 의 가장 큰 차이: 모두 0
- 나머지 칸(고른 방향·20일 값·실제값·출발값·전날 종가·무게 0 표시), 블록 6개의 맞춤 요약(첫날·학습 끝·고른 모형 수), 누수 기록도 모두 같았습니다.
- 분위수 7개는 발행용 계산(`simulateAtlas11`)에서 가져왔습니다. v1 계산(`simulateJointFactor36`)과 p10·p50·p90·방향 횟수가 1~20일 모두 한 칸도 다르지 않을 때만 씁니다(7,280칸 + 6,240칸 확인, 다른 칸 0).

## 블록(다시 맞추는 묶음)
- 출발일 20개가 한 블록입니다. 블록 1은 2026-03-05 에 시작합니다(원래 후향 판과 같음).
- 블록 첫날에 다시 맞추고, 블록 안에서는 계수를 바꾸지 않습니다.
- 원래 블록 1~6 뒤에 같은 규칙으로 블록 7(2026-08-28~09-28)과 블록 8(2026-09-29~09-30)을 이었습니다.
- 블록 8의 학습 끝은 2026-09-16 입니다. v1 정책이 2026-09-17 전 자료만 학습하기 때문입니다.

## 지금 입력과 옛 입력의 차이
- 출력은 지금 입력(`public/data/input.json`, 커밋 b8074cc)의 값입니다.
- 두 입력에서 같은 출발일 118개를 견줬습니다. 달라진 출발일은 4개(2026-09-21·22·23·28, 칸 110개)뿐입니다.
- 까닭: 9/21~9/23 종가 24개(12종목)가 나중에 고쳐졌습니다(`reports/atlas11/overhaul/data-correction-01.md`). 그 날짜를 관측 자료에 품은 출발일만 바뀝니다.
- 두 입력이 함께 맞춘 블록 2~7 의 계수는 모두 같았습니다.

## 누수 점검
- 출발일 120개 모두: 학습 끝 ≤ 출발일, 쓴 자료의 마지막 날 ≤ 출발일 (`leak[].noFuture` 모두 true)
- 2~20일째 날짜는 거래소 달력에서 이름만 가져옵니다. 그날 값은 쓰지 않습니다.

## 숫자 설명 (서술일 뿐, 판정 아님)
- p10~p90 폭의 평균: 출발 종가의 8.26%
- 실제 다음 날 종가가 p10~p90 안에 든 비율: 4,583 / 6,240 = 73.4% (아래로 벗어남 870, 위로 벗어남 787)
