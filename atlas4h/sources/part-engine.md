## 코드에 넣을 식

모든 점수는 **낮을수록 좋음(벌점)** 으로 저장합니다. Gneiting & Raftery는 '높을수록 좋음'으로 적기 때문에 부호를 뒤집어 씁니다.

### 1. CRPS — 분포 채점 (E01, 원문 식 (20)·(21))
```
CRPS(F, y) = ∫ (F(z) − 1{z ≥ y})² dz = E|X − y| − ½·E|X − X′|
표본 m개(x_1..x_m)로 셈:
CRPS ≈ (1/m)·Σ_i |x_i − y| − (1/(2m²))·Σ_i Σ_j |x_i − x_j|     ← 식 (21)에 표본을 넣은 셈법
값 하나만 내면 |x − y| (절대 오차)와 같다 — 원문 p.367
```

### 2. 구간 점수 — 범위 채점 (E01, 원문 식 (43))
```
IS_α(l, u; y) = (u − l) + (2/α)·(l − y)·1{y < l} + (2/α)·(y − u)·1{y > u}
80% 범위면 α = 0.2 → 범위 밖으로 벗어난 거리 1당 벌점 10
```

### 3. 브라이어 — 확률 채점 (E01, 원문 Example 1)
```
두 갈래 사건(좋게/나쁘게): BS = (p − o)²,  o ∈ {0, 1}
원문 이차 점수 S = 2p_i − Σ p_j² − 1 은 두 갈래에서 −2·BS 와 같다    ← 내가 한 셈
```

### 4. 실력 (09:6)
```
실력 = 1 − 평균벌점(엔진) ÷ 평균벌점(기준)      ← 화면용
원문 2.3절: 이런 실력 점수는 대개 바른 점수가 아니다 → 이겼는지는 5번(DM)으로 정한다
```

### 5. DM — 이겼는지 (E03; 1995 원문 E02는 보류)
```
d_t = 벌점(기준 판)_t − 벌점(엔진 판)_t        (같은 시각 판끼리)
d̄  = (1/T)·Σ d_t
DM = d̄ / σ̂_d̄,   σ̂_d̄ = √(ĝ(0)/T)              (Diebold 2015 식 (2)·p.2)
ĝ(0) = γ̂(0) + 2·Σ_{τ=1..L} w_τ·γ̂(τ)            (영 주파수 장기 분산, lag-window)
L(자를 길이)·w_τ(창 모양): [확인 필요] — 1995 원문·HLN 1997을 못 읽음. 설정값으로 두고 봉인 기록에 적는다
판정: DM > 0 이고 N(0,1) 기준 유의 → 엔진이 기준보다 낫다
```

### 6. GW — 언제 이기나 (E05, 원문 p.10~14)
```
ΔL_{t+τ} = 벌점(f)_{t+τ} − 벌점(g)_{t+τ}
Z_{t+τ}  = h_t · ΔL_{t+τ}          (h_t: 그 시각에 아는 조건 q칸 — 예: 1, 국면 확률, 발표일 표시)
T = n · Z̄′ · Ω̂⁻¹ · Z̄  →  χ²_q
τ = 1: Ω̂ = (1/n)·Σ Z Z′
τ > 1: Ω̃ = (1/n)·Σ Z_{t+τ}Z′_{t+τ} + (1/n)·Σ_j w_{n,j}·Σ_t [Z_{t+τ}Z′_{t+τ−j} + Z_{t+τ−j}Z′_{t+τ}]
       (j의 끝은 추출 글자가 깨져 [확인 필요] — 원문 p.14)
고르기: ΔL을 h_t에 회귀해 α̂ → h_t′α̂ > c 이면 g, < c 이면 f
전제: 추정 창은 고정 길이로 굴린다(옛 자료를 버림)
```

### 7. MCS — 남길 방법 (E06, 원문 3.1.2절)
```
d_{ij,t} = L_{i,t} − L_{j,t}
d̄_ij = (1/n)·Σ_t d_{ij,t},   d̄_i· = (1/m)·Σ_{j∈M} d̄_ij
t_ij = d̄_ij / √var̂(d̄_ij),   t_i· = d̄_i· / √var̂(d̄_i·)
T_R = max |t_ij|,  T_max = max t_i·;   뺄 것 e_max = argmax_i t_i·
'같다'가 기각되면 하나 빼고 되풀이 → 남은 것 M̂*_{1−α};  i ∈ M̂* ⇔ p̂_i ≥ α
분산·임계값: 블록 붓스트랩(원문 모의실험 B = 1000·블록 2, 실제 자료 예 블록 12)
```

### 8. SPA — 우연 거르기 (E07, 학술지판과 대조 뒤 봉인)
```
d_{k,t} = L(기준 0번)_t − L(대안 k)_t           (양수면 대안이 나음; H0: μ ≤ 0)
T^SPA = max[ max_k n^{1/2}·d̄_k / ω̂_k , 0 ]
ω̂²_k = γ̂_{0,k} + 2·Σ_i κ(n, i)·γ̂_{i,k}
μ̂^c_k = d̄_k · 1{ n^{1/2}·d̄_k/ω̂_k ≤ −√(2·log log n) };  μ̂^l_k = min(d̄_k, 0);  μ̂^u_k = 0
붓스트랩: Politis & Romano(1994) stationary bootstrap
```

### 9. HAR — 폭의 기준 (E08·E09)
```
RV_t = β0 + β1·RV_{t−1} + β2·RV_{t−1|t−5} + β3·RV_{t−1|t−22} + u_t   (Christensen 외 식 (5))
같은 뜻 Corsi 식 (13): RV_{t+1} = c + β_d·RV_t + β_w·RV^{(w)}_t + β_m·RV^{(m)}_t + ω_{t+1}
  RV^{(w)} = 지난 5일 평균, RV^{(m)} = 지난 22일 평균
추정: OLS, 표준오차는 Newey–West(Corsi는 늦춤 20)
나무 모형 후보: 랜덤 포레스트만(부스팅은 뺌). 같은 입력·같은 손실(MSE)로 DM·MCS 비교
```

### 10. DtACI — 움직이는 범위 (E10, 원문 식 (3)·(4)·알고리즘 1)
```
Ĉ_t(β) = { y : S_t^y ≤ Quantile(1 − β, D_t^y) }
err_t  = 1{ Y_t ∉ Ĉ_t(α_t) }
ACI:   α_{t+1} = α_t + γ·(α − err_t)                      (80% 범위면 α = 0.2)
DtACI: γ_i ∈ {0.001, 0.002, 0.004, 0.008, 0.016, 0.032, 0.064, 0.128}
       β_t = sup{ β : Y_t ∈ Ĉ_t(β) }
       ℓ(β_t, θ) = α·(β_t − θ) − min{0, β_t − θ}
       w̄_t^i = w_t^i·exp(−η·ℓ(β_t, α_t^i)),  W̄_t = Σ_i w̄_t^i
       w_{t+1}^i = (1 − σ)·w̄_t^i + W̄_t·σ/k
       p_t^i = w_t^i / Σ_j w_t^j  → 내놓는 α_t = α_t^i (확률 p_t^i)
       α_{t+1}^i = α_t^i + γ_i·(α − err_t^i),  err_t^i = 1{Y_t ∉ Ĉ_t(α_t^i)}
       σ = 1/(2·|I|),  |I| = 500
       η: [확인 필요] — 두 번 읽은 식이 서로 달랐다. 원문 3.1절을 보고 넣는다
```

### 13. 사건 확률 — 합치기와 펴기 (E17, 원문 3.2·7.1~7.3절)
