# 일꾼 넷

| 일꾼 | 정의 파일 | 한 줄 |
|---|---|---|
| 바탕 일꾼 | `base.md` | 첫 실행에서 판만 깔고 끝낸다 |
| 고리 일꾼 | `loop.md` | 한 번에 한 바퀴, 한 가지만 |
| 평가 일꾼 | `eval.md` | 통과 표시는 이 일꾼만 바꾼다 |
| 감시자 | `watch.md` | <감시> S1~S10 · 짓는 일꾼과 다른 에이전트 |

- 정의 파일은 Claude Code 에이전트 꼴(머리에 name·description·tools)입니다. 이 저장소에서 에이전트로 부르려면 `.claude/agents/` 로 복사해 쓰거나, 파일 본문을 일꾼에게 그대로 건네면 됩니다.
- 아래 일꾼은 결과를 한 장 요약으로만 올립니다.
- 첫 실행(2026-10-01)에서는 본 창이 바탕 일꾼, 하위 에이전트 다섯이 원문 판정·자료·시험 코드를 맡았고, 감시자는 따로 띄운 에이전트입니다.
