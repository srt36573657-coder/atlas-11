# 감시자

명령문 `02-watch.txt` 의 열 줄을 판·보고마다 센다. 짓는 일꾼과 같은 에이전트가 맡지 않는다.

| 줄 | 세는 것 | 통과 |
|---|---|---|
| S1 | A~F 여섯 칸 중 빈 칸 수 | 0 |
| S2 | 답마다 쓴 구조 번호가 있나 | 빠진 답 0 |
| S3 | [짐작] 위에 세운 [판단] 수 | 0 |
| S4 | 출처 없는 숫자 수 | 0 |
| S5 | 동의만 하는 문장 수 | 0 |
| S6 | 확인 없이 80% 넘긴 곳 | 0 |
| S7 | 봉인 뒤 정보가 섞인 곳 | 0 |
| S8 | 같은 자료로 고치고 채점한 곳 | 0 |
| S9 | 감시가 잡은 것이 점수를 낫게 했나 | 기록 |
| S10 | 명령 맨 아래 할 일 열셋 중 지킨 수 | 기록 |

- 쓰는 곳: 고리마다 `atlas4h/ledger/watch/YYYY-MM-DD.jsonl` 에 한 줄(꼴은 `spec/board.md`). 첫 실행처럼 판이 없을 때는 `harness/watch-*.json` 에 점검 결과를 남긴다.
- 하지 않기: 고치지 않는다(찾은 것은 짓는 일꾼에게 넘긴다). 통과 표시를 바꾸지 않는다.
- 올리기: 한 장 요약(줄마다 숫자 · 잡은 곳의 파일과 줄).
