## FOMO의 의미와 18개 원식

FOMO는 심리를 직접 측정한 값이 아닌 시장 행동의 연구용 대용 지표입니다. 이 명칭의 공인된 단일 주식별 산식을 구현했다고 주장하지 않습니다. C=종가, O/H/L=시가/고가/저가, V=거래량, r=log(C/C이전), 금액 단위는 원. 최근10은 실제 거래일 10개이며 수익률 계산에는 직전 종가까지 11개가 필요합니다. MA20·직전60·비교 창은 기준선용 추가 과거 자료입니다.

| 번호 | 묶음 | 항목 | 원식 |
|---|---|---|---|
| 1 | 추세 | 10일 상승률 | Σ₁₀ log(Cₜ/Cₜ₋₁) |
| 2 | 추세 | 상승 가속 | Σ최근5 r − Σ이전5 r |
| 3 | 추세 | 상승일 비중 | Σ₁₀ 1(r>0) / 10 |
| 4 | 가격 위치 | 20일 평균 이격 | C / mean(C 최근20) − 1 |
| 5 | 가격 위치 | 직전 60일 고점 돌파 | C / max(C 직전60) − 1 |
| 6 | 가격 위치 | 상승 변동 집중 | Σ₁₀ max(r,0)² / Σ₁₀ r² |
| 7 | 거래 참여 | 거래량 증가 | mean(V 최근10) / mean(V 이전60) − 1 |
| 8 | 거래 참여 | 거래규모 증가 대용값 | mean(CV 최근10) / mean(CV 이전60) − 1 |
| 9 | 거래 참여 | 상승일 거래량 비중 | Σ₁₀ V·1(r>0) / Σ₁₀ V |
| 10 | 장중 추격 | 갭 상승 압력 | mean₁₀ max(log(O/C₋₁),0) |
| 11 | 장중 추격 | 고가 부근 마감 | mean₁₀ (C−L)/(H−L) |
| 12 | 장중 추격 | 장중 매수 압력 | mean₁₀ log(C/O) |
| 13 | 개인 참여 | 개인 순매수 강도 | Σ₁₀ 개인 순매수금액 / Σ₁₀ 실제 거래대금 |
| 14 | 개인 참여 | 개인 거래 참여율 | Σ₁₀ (개인 매수금액+매도금액) / (2Σ₁₀ 실제 거래대금) |
| 15 | 개인 참여 | 신용잔고 증가 | 신용잔고ₜ / 신용잔고ₜ₋₁₀ − 1 |
| 16 | 관심 확산 | 기업 기사 증가 | mean(고유 사건 기사 최근10) / mean(이전60) − 1 |
| 17 | 관심 확산 | 검색 관심 증가 | mean(검색지수 최근10) / mean(이전60) − 1 |
| 18 | 관심 확산 | 게시 작성자 증가 | mean(고유 작성자 최근10) / mean(이전60) − 1 |

C×V는 거래규모 대용값이며 실제 거래대금으로 부르지 않습니다. 개인 매수·매도는 양쪽 합계여서 전체 거래대금의 두 배로 나눕니다. 종가만 보유하면 장중 움직임이나 개인 수급을 추정해 채우지 않습니다. 신용잔고의 기준 단위는 동일 시계열 안에서 유지해야 합니다. 기사 수는 기업 대상 고유 경제 사건으로 중복 제거한 입력이며, 검색·게시자는 같은 methodId(검색 조건·단위·중복 제거 규칙)를 유지합니다.

## 점수 정규화와 중복 할인

기준일 t의 최근10거래일보다 앞서 끝난 최대252개 과거 창을 비교합니다. 항목별 유효 비교 창이 최소60개 있어야 계산합니다. 이 창들은 서로 겹칠 수 있으므로 독립 표본 60회나 교차검증 60회라는 뜻이 아닙니다.

```text
q_j,t = 100 × [Σ 1(x_j,u < x_j,t) + 0.5 Σ 1(x_j,u = x_j,t)] / N_j
ρ_jk = Spearman(과거 항목 j, 과거 항목 k)
w_j = 1 / (1 + Σ_{k≠j, 같은 묶음} |ρ_jk|)
G_g = Σ_{j∈g}(w_j q_j) / Σ_{j∈g}w_j
FOMO = (G_1 + G_2 + G_3 + G_4 + G_5 + G_6) / 6
가격 열기 = (G_추세 + G_가격위치) / 2
```

18항목 전체가 유효할 때만 FOMO 종합값을 제공합니다. 결측은 null이며 0점 또는 평균으로 대체하지 않습니다. 묶음의 일부 값만 있으면 그 묶음도 미완성으로 표시합니다. 모든 가격이 같은 경우 동률 백분위는 50입니다. 분모가 0인 거래량·거래대금·관심 증가율은 계산 유보합니다.

현재 6묶음 동일 비중·역상관 밀도 가중치는 고정된 연구 설계이며 예측 성과로 최적화된 가중치가 아닙니다. 묶음 안의 중복 할인은 항목 간 모든 의존성을 제거하거나 잠재적 FOMO를 식별하는 증명이 아닙니다. 18항목을 많이 넣었다는 사실 자체가 정밀도 보장이 아닙니다.

## 예측에 들어가기 전 검증식

실제로 실행되는 후보 평가 코드는 lib/fomo-validation.mjs입니다. 회사별로 자신의 완전한 18항목·당시 원본 검증·기업행위 조정 검증·저장된 기준 전망이 있어야 합니다. 9/17 이후 결과를 계수 선택에 넣지 않습니다. 평가 대상은 10거래일이고 이를 10/30 전체 기간 검증으로 확대 해석하지 않습니다.

```text
x_t = (FOMO_t - 50) / 50
y_t = log(P_{t+10}/P_t) - 기본모형의 10거래일 로그변화
β = Σ_train(x_t y_t) / (1 + Σ_train x_t²)
후보 로그변화 = 기본모형 로그변화 + β x_t
MAE = mean_test |후보 로그변화 - 실제 로그변화|
```

기간이 겹치지 않는 최소30개 학습 구간과 뒤의10개 시험 구간을 분리합니다. 학습의 목표일은 첫 시험 출발일보다 이전이어야 합니다. 과거 시험에서 개선돼도 라이브 가중치는 0으로 남으며, 별도로 미리 고정한 향후 검증·승인이 필요합니다. 현재 적격 실제 자료 0, 독립 향후 검증 0, 가격 조정 0입니다. 임의로 β를 넣거나 기존 뉴스의 0 계수를 0이 아닌 값으로 강제하지 않습니다.

## 날짜·원자료·수정 이력

종목별 선택 날짜의 끝과 확보된 정보 시각 중 이른 때를 정보 기준으로 사용합니다. 가격은 선택 날짜와 실제 보유 종가일 중 이른 날까지만 사용합니다. 미래 날짜에는 마지막 관측일을 명시하고 실제 FOMO가 새로 관측된 것으로 표시하지 않습니다. 휴장일은 직전 거래일을 참고합니다. 중간 거래일 누락을 더 오래된 가격으로 메우지 않습니다. 기록된 수정은 pricesAsOf로 되돌리며 미기록 빈티지를 복원했다고 하지 않습니다.

NAVER 파서는 검증된 OHLC·거래량을 보존하고 refresh는 같은 종가의 보조 필드도 갱신합니다. 과거 종가가 다르면 보조 수집기는 충돌로 보류합니다. 소급 확보한 자료의 관측 시각을 과거로 위조하지 않습니다.

추가 수급·관심 자료는 종목 확대보기의 ‘이 종목 FOMO 원자료 JSON 추가’를 사용합니다. 형식은 다음과 같고 빈 rows는 실제 값이 아닙니다.

```json
{"schema":"atlas-fomo-input-1","rows":[]}
```

각 행 필수: code, date, sourceUrl(HTTPS), observedAt(시간대 포함 ISO). 선택 숫자: retailNetBuy, retailBuy, retailSell, turnover, marginBalance, uniqueCompanyEvents, searchIndex, uniqueAuthors. 관심 지표는 methodId 필수. 같은 종목·날짜 중복과 기존 입력 충돌은 거부하며 운영 종가를 덮어쓰지 않습니다. 이 파일의 주장을 출처 원문 검증으로 자동 인정하지 않습니다.
