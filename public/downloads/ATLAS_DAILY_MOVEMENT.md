# 일별 등락 연구 — 방향뿐 아니라 매일의 움직임

기존 5·20·60일 평균을 다시 평균으로 이어 가는 계산은 단기 등락 반응을 약하게 만들 수 있습니다. 직전 1·2일 수익률을 추가한 종목별 조건부 회귀를 별도 연구판으로 구현했습니다. 계수 선택은 9/17 이전 자료만 사용하며, 최신 보관 종가 9/23의 상태에서 10/30까지 계산합니다. 미래 뉴스 결과나 파동을 그려 넣지 않습니다.

r의 조건부 평균 = 절편 + β1×직전1일 + β2×직전2일평균 + β5×5일평균 + β20×20일평균 + β60×60일평균.

종목별 시간순 내부 검증으로 기존 후보들을 비교·가중하고, 안정성 조건을 통과한 계수만 사용합니다. 하루 변동 분포는 해당 종목의 일반일 또는 유효 뉴스 사건 표본에 조건부 평균을 결합합니다. 뉴스 효과를 중복 가산하지 않습니다. 모형 내 일별 상승·하락 비중과 P10~P90 범위를 별도로 계산합니다. 이 비중은 실제 적중 확률이 아닙니다. 로그평균 기준 중심 변화와 누적 가격 중앙값의 차이는 서로 다른 통계입니다.

## 실제 산출

52종목, 출발점 포함 1,248개 가격행을 계산했습니다. 33종목에서 일일 로그평균 중심 방향의 전환이 나타났습니다. 이 숫자는 실제 전환을 맞힌 종목 수가 아닙니다. 모든 종목을 억지로 오르내리게 만들지 않습니다. 자료가 가리키는 방향이 계속 같으면 선은 계속 같은 방향일 수 있습니다.

## 화면 사용

상단 ‘일별 등락 연구 보기’를 누르면 중앙 그래프 하나가 새 연구 전망으로 바뀝니다. 날짜를 누르면 오른쪽에 하루 중심 변화·변동 범위·분포상 상승/하락 비중과 계산 이유가 나옵니다. ‘저장 전망으로 돌아가기’로 원래 발행본을 다시 볼 수 있습니다. 두 예측선을 한 그래프에 겹쳐 혼동시키지 않습니다. 재생 세션 중에는 전환을 막습니다.

## 보존과 한계

기존 17개 전망과 원래 52종목 가격은 수정하지 않았습니다. 새 연구판은 별도 파일과 발행 기록으로 보존합니다. 같은 의미의 입력은 기존 연구 발행본을 재사용합니다. 당시 원본·기업행위 조정과 독립 실전 우위는 미검증이며 새 연구판의 사후 성적은 아직 없습니다. 이번 변경이 어느 날의 실제 상승·하락을 정확히 알아냈다는 뜻은 아닙니다. FOMO 핵심 자료가 부족하므로 이 연구 경로에 가짜 FOMO 값은 넣지 않았습니다.

전체 수집 후 새 연구판을 계산하려면 node scripts/research_daily_movement.mjs를 실행합니다. 원래 발행본을 덮어쓰지 않습니다.
