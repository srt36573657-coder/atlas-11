# ATLAS 8.9: 학습을 화면 동작으로 옮긴 기록

## 원문에서 확인한 기준
- Steve Jobs Archive, Make Something Wonderful: 잡스는 사용자가 제품군을 이해하지 못하는 문제를 지적하고 제품을 줄여 핵심에 집중했던 과정을 설명한다. 1980년대 인터뷰에서도 단순함을 강조했다. https://book.stevejobsarchive.com/
- Apple WWDC 2018, Intentional Design: 사용자의 의도에 초점을 맞추고 작동 방식을 쉽게 이해하도록 만드는 접근. https://developer.apple.com/videos/play/wwdc2018/802/

이는 잡스가 ATLAS를 검토했다는 뜻이 아니다. 아래 선택은 자료를 읽고 ATLAS에 맞게 적용한 설계 판단이다.

## 실제 적용
1. 세 가지 빠른 행동: 최근 실제 확인 / 10월 30일 전망 / 다음 뉴스.
2. 선택 날짜의 저장 예측·실제 종가·차이를 함께 표시. 미래 종가를 만들지 않는다.
3. 출발 기준값은 적중 시험에서 제외. 오차율을 신뢰 확률로 부르지 않는다.
4. 날짜 선택을 그래프 아래로 옮겨 그래프와 날짜의 관계를 유지.
5. 설명은 ‘왜 이렇게 봤나’와 ‘근거·계산값’으로 나눈다. 중요 뉴스 대기 때는 이유 화면으로 돌아간다.
6. 재생은 바로 사용하고, 속도·띠·눈금·연구 상태는 그래프 설정에서 펼친다.
7. 52종목 전체 보기와 종목별 독립 재생·원본 전망은 보존한다.

## 비교 표시의 식
D(t) = 실제 종가(t) − 저장된 모형 중앙값(t)
r(t) = 실제 종가(t) / 저장된 모형 중앙값(t) − 1

같은 종목·같은 날짜의 유효값이 있을 때만 표시한다. 출발일·휴장일·미확보·상충 값은 차이를 채점하지 않는다. 이 표시 계층은 예측을 다시 계산하거나 뉴스의 인과 효과를 주장하지 않는다.

## 검수 한계
자동 기능 검사와 데이터 보존 검사는 해당 릴리스 reports/tests.tap 및 validation.json 기준이다. 실제 브라우저 픽셀/실기 휴대폰 검수는 미완료다. 실배포·가격 자동수집 설치·구글 인증 설치를 뜻하지 않는다.
