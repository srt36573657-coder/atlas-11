## 1. 결정할 핵심

52종목마다 9월 17일 종가를 고정한 A와, 그 시점까지 공개된 뉴스의 추가 정보를 반영한 B를 별도 시험으로 저장한다. A/B에는 종목·날짜별로 같은 폭의 대칭 띠를 사용한다. 실제 가격은 세 번째 관측선이다. 이 시험으로 묻는 것은 “같은 위험 범위를 주었을 때, 뉴스로 중심을 이동한 B가 A보다 나았는가”다.

현재 운영 전망, 원본 재구성 전망, 진화 전망, 돌발 뉴스 이후 전망을 이 두 줄로 덮어쓰지 않는다. 성적 페이지 안에 ‘봉인 시험’을 두고 다른 시험의 결과와 분리한다. 화면에는 가격 예측의 방향·오차, 띠의 담김·폭 점수, 시장 대비 성과를 각각 보여준다.

## 4. 두 줄과 같은 띠의 수학적 정의

종목 i의 9/17 종가를 P_i0, 날짜 t의 실제 종가를 P_it, 기준 시각을 τ0로 둔다. 같은 가격 조정 기준을 써야 하며 기업행위 조정 근거가 없으면 해당 비교를 보류한다.

```text
실제 누적 수익률       y_i,t = P_i,t / P_i,0 − 1
A의 중심             a_i,t = 0
A의 가격             A_i,t = P_i,0
B의 중심             b_i,t = Σ_e δ_i,e · K_i,e(t)
B의 가격             B_i,t = P_i,0 · (1 + b_i,t)
```

δ는 같은 종목·경제 사건·단계의 자격 있는 과거 자료에서 추정한 ‘추가 반응’이다. K는 사전 자료로 결정한 시간별 반영 함수이며 사건 이전 0, 반영 이후 누적 효과를 표현한다. 임의 날짜·파동·기울기로 만들지 않는다. 이 덧셈 모형은 제한된 시험 가정이며 실제 시장 법칙이 아니다. 비선형 효과·중복 사건·상관을 무시한 합산은 허용하지 않는다.

기사 여러 개를 독립 사건으로 세지 않는다. 사건 중첩·상충·가격 선반영·종목 범위 오류·원문 빈티지 부족을 검사한다. 미래 발표 결과를 모르면 결과별 조건부 반응을 사전 정보로 통합할 수 있어야 하며, 발표 결과나 예상 대비 차이를 지어내지 않는다.

δ를 추정할 수 없으면 해당 항은 ‘미산정’이다. 화면에서 B가 A와 겹치는 중립 대체 표시를 하더라도 observedEffect=0으로 저장하지 않는다. `B.status=UNESTIMABLE`인 기록은 뉴스 예측 적중률과 A/B 유효 비교의 분모에 넣지 않고 미산정 수를 별도로 표시한다. 104개 레코드와 104개 유효 수치 예측을 구분한다. B의 점수가 좋아져도 뉴스의 인과효과가 입증된 것은 아니며 이 특정 계산 정책의 예측 성적이다.

```text
공통 반폭             w_i,t ≥ 0
A의 띠               [a_i,t − w_i,t, a_i,t + w_i,t]
B의 띠               [b_i,t − w_i,t, b_i,t + w_i,t]
```

‘같은 띠’는 A/B의 폭과 생성 규칙이 같다는 뜻이다. 중심이 다른데 경계 위치까지 같게 만드는 것은 아니다. 서로 다른 종목까지 같은 폭을 강제하지 않는다. 단순수익률 하한이 −100% 미만이면 하단만 잘라 대칭인 척하지 않는다. 해당 대칭 띠의 가격 해석 부적합을 표시하고 수치 평가 자격을 보류한다. 로그 대칭은 원화 축에서 대칭이 아니므로 몰래 대체하지 않는다.

공통 폭의 기본 산정안은 사전 자료로 만든 중심 제거 누적 잔여반응의 |잔차|에 대해 목표 포함률의 분위수를 사용하는 것이다. 80%는 시험용 명목 목표로 제안하며, 경험적 실제 포함률 80%가 입증됐다는 뜻은 아니다. 사전 시계열 검증으로 교정하고 미래 성적을 보고 폭을 넓히지 않는다. 두 줄에 같은 중심 제거 잔여분포를 사용한다.

일별 위험의 설명용 구조는 다음과 같다. 실제 구현은 공동 잔여경로 또는 공분산 항을 포함해 사전에 고정한다.

```text
ε_i,s = 일반 위험 + 사전 확인 사건 창의 추가 위험
Var(Σ_s ε_i,s) = Σ_s Var(ε_i,s) + 2 Σ_(s<u) Cov(ε_i,s, ε_i,u)
```

일별 독립을 선택하면 Cov=0이라는 가정을 공개한다. 그 가정이 맞는 것으로 간주하지 않는다. 사건 창의 추가 변동이 뒤 날짜의 누적 경로에 남는 것이 정상이며, 알려진 가격 확정·관측 조건이 없는 임의 축소는 금지한다.

## 5. 코스피 대비 평가의 정확한 위치

K_t를 코스피, m_t=K_t/K_0−1을 같은 출발일·목표일의 실제 수익률로 둔다. 종목 누적 수익률에서 코스피 하루 등락을 빼는 등 기간을 섞지 않는다.

```text
실제 시장 대비        excess_i,t = y_i,t − m_t
사후 공통 이동        adjustedForecast = forecast_i,t − m_t
                      adjustedActual   = y_i,t − m_t
오차                  adjustedForecast − adjustedActual
                      = forecast_i,t − y_i,t
```

이 공통 이동에서는 오차·구간 포함·폭 점수가 원래와 같다. 또한 사후 실제 코스피로 변환한 예측 부호는 9/17에 알 수 없었던 값이므로 사전 초과수익 방향 예측이라고 채점하지 않는다.

진짜 사전 시장 대비 예측을 시험하려면 다음 중 하나를 미리 고정해야 한다.

1. 별도로 봉인한 코스피 전망 mhat_t로 xhat_i,t = b_i,t − mhat_t를 계산한다. 실제 excess와 비교하되 시장 예측 오차도 포함된 결과라고 명시한다. 구간은 종목과 코스피의 공동 오차·공분산을 반영해 별도 산정해야 한다.
2. 처음부터 기업의 시장 대비 추가 수익률 xhat를 직접 추정한다. 이 모형은 원화 A/B 시험과 다른 목표를 가진 별도 시험이다.

권장 배치: 첫 화면에는 원화 방향·오차와 ‘실제 코스피 대비 수익률’을 나란히 둔다. 사전 코스피 전망 또는 직접 초과수익 모형을 확보하기 전에는 ‘시장 대비 예측 적중률’을 미산정으로 표시한다. 코스피 수익률 단순 차감은 β=1 비교 기준이며 모든 종목의 위험을 완전히 조정한 알파가 아니다. 종목별 β는 과거 자료로 고정한 별도 진단으로만 제공한다. 코스닥 종목의 시장 적합성 진단을 추가하더라도 요청한 코스피 비교를 바꾸지 않는다.

## 6. 방향·크기·띠를 분리한 채점

방향은 해당 시험의 출발가격 대비 상승·보합·하락을 비교한다. 하루 방향은 별도 표에서 예측의 전일 대비 변화와 실제의 전일 대비 변화를 비교한다. 고정 A의 방향은 ‘보합 가정’이며 매수·매도 추천이 아니다. tiny 값과 반올림 때문에 방향이 바뀌지 않도록 계산 원본과 표시 반올림을 분리한다. 보합 경계 정책을 사전에 고정한다.

```text
중심 오차(%p)  = 100 · (예측 수익률 − 실제 수익률)
절대 오차(%p)  = 100 · |예측 수익률 − 실제 수익률|
크기 적중      = 1[절대 오차 ≤ 사전 고정 허용 오차]
방향 적중률    = 방향 일치 수 / 방향 평가 가능 수
```

크기 적중의 허용 오차는 목표 기간별 정책에 명시한다. 현재 최적 허용 오차가 검증됐다는 자료는 없으므로 수치 미정 상태를 숨기지 않는다. 확정 전에는 연속 오차를 제공하고 크기 적중률은 미산정으로 둔다. 방향·크기 둘 다 적중, 방향만, 크기만, 둘 다 실패의 목록과 미산정 목록을 분리한다.

띠의 담김 C=1[L≤y≤U]와 함께 다음 interval score를 사용한다. α=0.2이면 명목 80% 구간이다.

```text
IS_α(L,U;y) = (U−L)
            + (2/α)(L−y)·1[y<L]
            + (2/α)(y−U)·1[y>U]
```

작을수록 좋다. 폭을 넓힌 대가와 띠 밖으로 벗어난 정도를 함께 계산한다. 출처: Gneiting & Raftery(2007), 식43. 일반적으로 중앙 구간의 분위수 예측에 쓰는 점수이며 임의 대칭 띠에 적용했다고 실제 포함률이 교정됐다는 뜻은 아니다.

같은 폭의 A/B는 폭 항이 서로 같다. 두 띠 모두 실제값을 포함하면 interval score도 같을 수 있으므로 중심 절대오차를 반드시 함께 본다. 동일 폭 시험은 중심 이동의 효과를 비교할 수 있으나 B의 ‘더 좋은 폭 산정’을 증명하지 못한다. 폭 산정 개선은 별도 사전 고정 시험에서 평가한다.

## 7. 종목 52개를 날짜별 하나의 묶음으로 집계

각 날짜에 A/B 모두 평가 가능한 동일 종목 집합 V_t를 쓰고 등가중 평균을 계산한다. A에 유리한 목록과 B에 유리한 목록을 따로 고르지 않는다.

```text
중심 개선 D_t = mean_i∈V_t(|a_i,t−y_i,t| − |b_i,t−y_i,t|)
띠 개선   J_t = mean_i∈V_t(IS_A,i,t − IS_B,i,t)
```

양수는 그 날짜에 B가 나았다는 뜻이다. 날짜별 승·무·패와 개선 크기를 함께 기록한다. 작은 승리 여러 번으로 큰 손실을 숨기지 않도록 누적·평균 개선, 최악 날짜, 최대 종목 오차도 공개한다. 같은 출발일의 누적 점수를 매일 더한 값을 실제 투자 수익이나 독립 거래 손익으로 표시하지 않는다.

보고할 표본수는 달력 경과일, 고유 거래일, 결과 전에 봉인된 전향 평가일, 전체 52종목 평가일, 부분 집계일을 구분한다. 부분 실패를 지우지 않는다. V_t의 크기와 누락 이유를 매일 남기고 전종목 결과와 부분집계 결과를 섞지 않는다.

‘함께 움직인 정도’의 쉬운 지표는 당일 상승·하락·보합 비율과 다수 방향 비율이다. 예: max(n_up,n_down,n_flat)/N. 이것은 그날 방향 집중도이지 상관계수나 독립 표본수 추정이 아니다. 상관은 충분한 과거 기간을 고정해 계산하는 별도 값이다.

날짜 간 의존은 날짜별 전체 종목 묶음을 함께 재표집하는 연속 블록 방식 등으로 검토한다. 블록 길이·주평가 지표·비교 횟수를 새 결과 전에 정한다. 자료가 짧으면 불확실성 추정을 유보한다. 52종목이 각각 독립이거나 날짜 수가 그대로 유효 표본수라고 주장하지 않는다.

## 8. 봉인의 대상과 외부 증거

기준 시각·실제 생성 시각·외부 인증 시각을 각각 저장한다. 봉인 묶음에는 52개 코드, 가격 기준/기업행위 정책, 뉴스 원문 식별자와 공개·관측 시각, 입력 빈티지, 포함/제외 이유, 계수, 사건 창, 공통 폭, 104개 경로, 평가 정책, 코드/환경 버전, 난수 설정을 포함한다. 파일 순서와 숫자 직렬화 규칙을 고정한 manifest와 각 원본 바이트의 SHA256을 저장한다.

외부 증거는 RFC3161 등 검증 가능한 제3자 시각 인증을 설계 대상으로 한다. 외부에는 원문 전체가 아니라 해시를 제출하는 구성이 가능하다. 응답 토큰·서명·인증서·시각·해시 일치 검증 결과를 보관한다. 공급자 연결·정책·비용·검증이 준비되지 않으면 `EXTERNAL_TIMESTAMP_PENDING`이다. 이번 기획에서는 제출하거나 연결하지 않았다.

해시는 내용 변화 검출 수단이며 생성 날짜를 홀로 증명하지 않는다. 제3자 시각 인증도 해당 내용이 그 시각 이전에 존재했다는 증거이지 뉴스·가격의 진실성이나 예측 우위를 인증하지 않는다. 현재 토큰으로 9/17 발행을 소급 인증할 수 없다.

기존 봉인 변경은 새 실험 ID와 이전 manifest의 해시를 연결해 추가한다. 수정 전 파일과 토큰을 유지한다. 기록된 뉴스·가격 수정은 원래 저널 절차로 시점별 복원하되 기록되지 않은 당시 원문과 기업행위 조정을 복원했다고 주장하지 않는다. 원본 진실성 검사를 통과하지 않으면 계산 결과를 완료 배지로 표시하지 않는다.

## 9. 화면과 일일 운영

기존 네 메뉴 종목·뉴스·성적·진화를 유지한다. 성적 안의 ‘봉인 시험’ 첫 화면 순서:

1. 기준일 9/17 · 정보 기준 시각 · 실제 생성 시각 · 외부 인증 상태.
2. 내용 지문과 ‘봉인 증거 보기’. 긴 해시는 접고 복사/전체보기 제공.
3. ‘전향 평가 n거래일 / 장기 관측 목표250일 · 10/30 1차 기록 마감 · 우위 미입증’.
4. 오늘 방향 성적 / 중심 오차 / 띠 포함·폭 점수 / 코스피 대비. 수치를 누르면 동일 조건의 종목 목록.
5. 종목 클릭 선택. A는 얇은 기준선, B는 뉴스 중심 점선, 실제는 실선. 두 시험 띠는 같은 폭·다른 중심이며 겹침을 명확히 보여준다. 모바일은 A/B 띠 비교 전환도 제공하고 수치를 숨기지 않는다.
6. 날짜를 누르면 해당 종목의 A/B/실제, 방향 판정, 크기 오차, 담김, interval score, 뉴스 근거, 유보 이유.
7. 날짜별 보고서와 봉인 버전 목록.

A 옆 문구는 ‘이 줄은 예측이 아니라 비교 기준점: 9/17 종가 고정’으로 한다. B는 ‘9/17 정보로 만든 뉴스 중심 시험값’이며 근거 부족이면 미산정 표시. 현재 운영 모형 중앙값 전체를 기준점이라고 바꾸지 않는다. 카드당 재생·독립 상태·하루1초·중요 뉴스마다 정지·전체 기간 표시와 집중 보기 배치를 유지한다.

거래일16시 수집 시작 → 52종목/코스피 가격 검증 → A/B 봉인 일치 검사 → 동일 가격 빈티지로 채점 → 날짜별 보고서 추가 → 누락·정정·조사 이력 저장. 휴장일은 새 평가일을 늘리지 않는다. 늦은 수집은 부분 보고서와 후속 revision을 남긴다. 구독/계정/서버가 연결되지 않은 정적 ZIP에서 실제 사이트가 자동 갱신된다고 주장하지 않는다.

기간은 2026-09-17~2026-10-30 고정. 250일 문구 때문에 예약이나 그래프 기간을 늘리지 않는다. 10/30 이후 장기 시험은 별도 범위 합의가 필요한 후속 과제로 남긴다.

## 10. 원인 추적과 진화의 연결

원본 A/B에 봉인 이후 뉴스를 추가하지 않는다. 돌발 뉴스는 별도 전망과 발행 시각을 갖고 발행 후 목표일만 평가한다. 조사에는 뉴스 누락·반영 시점·중복 반영·영향 크기·시장 동반 움직임·가격 조정 문제를 기록하되 각 결론을 사실/가설/미확인으로 구분한다.

진화안은 무엇을 바꿨는지, 어느 데이터로 정했는지, 어떤 미래 지표가 좋아져야 채택할지를 사전에 저장한다. 기존 A/B·운영 모형·가격 유지 기준과 동일한 이후 날짜에서 비교한다. 새 결과를 보고 과거 정책·계수를 소급 최적화하지 않는다. 연구 중에 적중한 설명을 골라 붙이는 행위를 실전 개선으로 세지 않는다.

## 11. 코드 구성안

핵심 처리 계약:

```text
audit existing saved forecasts and source vintages
construct as-of input without altering original data
label September reconstruction as retrospective
for each of exactly 52 original unique codes:
    create A with September 17 close fixed
    estimate eligible news-only B or record UNESTIMABLE
    create one shared width policy for A and B
validate all usable paths, horizons, boundaries and source cutoffs
serialize manifest and compute SHA256
request external timestamp only after service setup
verify returned proof before marking externally sealed
on actual-price arrival:
    verify seals; append vintage-aware paired scores and report
never overwrite historical paths or earlier reports
```

## 13. 우선순위

1. 현재 중앙값의 의미·최초 재구성 여부·자료 기준을 화면에 정확히 표시.
2. 고정 A와 뉴스만의 B를 별도 시험으로 설계하고 자격 미달을 공개.
3. 공통 폭·채점 정책·시장 대비 목표·일일 보고서 정의를 확정.
4. 봉인 파일과 검증기를 만든 뒤 외부 시각 인증을 연결.
5. 실제 봉인 이후 가격으로 기록을 쌓고 진화안은 별도 비교.
