# ATLAS 9.3 · 52종목 동시 비교 기획과 방정식

## 목표와 화면
9/17에 각 종목을 10,000원으로 맞춘다. 하나의 큰 그래프 안에 52개 전체 경로를 동시에 표시한다. 실제 종가 구간은 실선, 이후 새 뉴스 파장 전망은 점선이다. 선택 종목과 현재 상위 5개를 강조하며 나머지도 계속 표시한다. 세로 눈금은 전 기간 고정이다. 재생은 거래일마다 1초, 전체 경로는 처음부터 끝까지 보이며 커서·52개 점·현재 순위가 함께 움직인다.

왼쪽 그래프, 오른쪽 순위표, 그래프 아래 재생 버튼, 아래 선택 종목 설명. 휴대폰에서는 그래프→조작→순위→설명 순으로 배치한다. 순위표만 자체 스크롤한다. 모든 종목의 선은 휴대폰에도 함께 유지한다. 320px/390px 화면에서 가로 넘침을 검사한다.

## 같은 기준으로 환산
B_i = 2026-09-17 실제 종가
X_i(t) = 해당 날짜 실제 종가(실제 자료 범위) 또는 새 전망의 가격 중앙값(그 이후)
V_i(t) = 10,000 × X_i(t) / B_i
R_i(t) = V_i(t) / 10,000 − 1

뉴스와 FOMO 보너스를 V에 다시 더하지 않는다. 이미 가격 계산에 포함된 효과의 이중 가산을 금지한다. 실제 구간과 새 전망을 연결한 경로이며 9/17 당시 발행 성적이라는 주장을 하지 않는다. 기준 가격이 없거나 상충하면 환산값은 null이고 순위 대상에서 제외한다.

## 날짜별 순위와 동률
rank_i(t) = 1 + Σ_(j≠i) 1[V_j(t) > V_i(t)]
Δrank_i(t) = rank_i(t−1) − rank_i(t)

같은 값은 공동 순위다(동률 비교의 부동소수점 허용오차 1e−8원). 공동 선두를 임의의 단독 1위로 표기하지 않는다. 오른쪽 표는 현재 날짜 순위가 기본이다. 10/30 최종 예상 순위는 제목을 명시한 별도 선택이며 재생 시작 시 현재 날짜 순위로 돌아간다.

## 자기 값 변화와 상대 값 변화의 분해
어떤 종목이 순위가 올랐다고 가격도 올랐다고 설명하면 안 된다. 아래는 수치 분해이며 인과효과가 아니다.

두 날짜 t−1,t 모두 유효한 상대 j에 대해
f00 = 1[V_j(t−1) > V_i(t−1)]
f10 = 1[V_j(t−1) > V_i(t)]
f01 = 1[V_j(t) > V_i(t−1)]
f11 = 1[V_j(t) > V_i(t)]

자기 변화 몫 C_own = 1/2 Σ_j [(f00−f10)+(f01−f11)]
상대 변화 몫 C_other = 1/2 Σ_j [(f00−f01)+(f10−f11)]

완전 자료에서는 C_own + C_other = Δrank다. 결측 진입/이탈에 따른 잔여 차이는 따로 계산한다. 반 계단이 나오는 이유는 자기 먼저/상대 먼저 두 순서의 평균을 쓰기 때문이다. 영향의 단위를 주가 %로 혼동하지 않는다.

## 접전과 추월 차이
G_i(t) = 바로 위 종목 환산값 − 내 환산값
접전 표시 = 가장 가까운 이웃과 |V_j/V_i−1| ≤ 0.001

0.1%는 공개한 고정 화면 기준이며 검증된 통계적 유의성 기준이 아니다. 같은 값이면 공동 순위다. 이 표시를 1위 확률 또는 순위 안정성으로 바꾸지 않는다.

## 핵심 장면과 재생
핵심 장면 후보는 다음의 합집합이다.
- 동률을 제외한 단독 선두 교체
- 선택 종목의 전 거래일 대비 순위 5계단 이상 이동
- 선택 종목에 연결된 뉴스 날짜

5계단은 표시용 기준이며 최적 예측 계수가 아니다. '핵심 장면' 버튼은 다음 후보로 이동한다. '중요 장면에서 멈춤' 선택 시 해당 날짜에 멈추고 '설명 확인·계속' 전까지 진행하지 않는다. 종목을 바꾸면 그 종목 기준으로 후보를 다시 계산한다. 탭 이동·문서 숨김 시 정지한다. 한 번에 하나의 타이머만 존재한다.

## 설명 구성
판단: 그 날짜 환산값, 순위, 일일 모형 방향 선택.
근거: 자기/상대 변화 몫, 해당 종목 뉴스 파장, 자체 표본, 원문.
다음 확인: 바로 위 종목과 금액 차이, 다음 연결 뉴스.
뉴스 창은 선택 종목에 한해 표시한다. 3거래일 관측 반응 창이며 실제 뉴스 효과가 정확히 3일에 끝난다는 주장이 아니다.

## 휴대폰 '새 전망 준비' 막힘 수정
기존 문제 조건: 기기에 보관된 active ID 또는 실제 종가일과 새 뉴스 파장 파일의 sourceForecastId/actualAsOf가 다르면 앱 전체를 차단했다. 새 화면 자료가 정상이어도 오래된 상태가 들어오면 차단될 수 있었다.

수정: 뉴스 파장 파일에 그 전망을 계산한 가격·달력·뉴스 맥락을 함께 넣는다. UI는 한 묶음의 52코드, 9/17~10/30 기간, 출발 종가를 검사한 뒤 그 자료로 표시한다. 기기/서버의 다른 버전은 새 화면의 가격과 섞지 않는다. gzip 파일은 cache:no-store로 요청한다. 새 자료 자체가 잘못된 경우에는 오류를 숨기지 않는다. 이전 전망을 대신 띄우거나 사용자 저장자료를 삭제하는 복구 방식은 사용하지 않는다.

## 구현 범위와 미완료 근거
- 구현: 52개 동시 선, 52개 현재 위치, 거래일 재생, 일일 순위, 동률, 자기/상대 변화 분해, 접전, 추월 차이, 뉴스 파장 창, 선택 종목 설명, 핵심 장면, 모바일 상태 충돌 복구.
- 새 뉴스 파장 수치 전망 자체는 9.2 값 그대로다. UI 개선 때문에 경로나 확률을 임의로 바꾸지 않는다.
- 아직 제공하지 않음: 공동 시장 충격까지 반영한 1위 확률, 검증된 순위 안정성, FOMO 실자료 가산, 자동으로 원인을 확정하는 오답 진단. 자료와 공동 잔차 모형이 없는 상태에서 숫자를 만들지 않는다.
- 작성 후 실제 성적은 새 전망 전용 성적표에서 확인한다. 현재 보관 종가는 9/23이며 이번 작업은 종가/뉴스 신규 수집이 아니다.
