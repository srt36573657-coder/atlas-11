01 · 학습의 결론

아틀라스의 중심은 “내가 선택한 종목을 어떻게 예상했고, 실제로 얼마나 달랐으며, 그 판단의 근거가 무엇인지”를 한 흐름으로 이해하는 것입니다.

제품 사고·탐색·차트·모바일 접근성·운영 상태·시각 디자인으로 역할을 나눈 6개 에이전트가 공식 자료를 조사했습니다. 역사적 Jobs 발언, 현재 Apple 지침, ATLAS에 대한 우리의 설계 판단을 구분했습니다. Jobs가 실제로 ATLAS를 설계했다면 무엇을 했을지는 단정할 수 없습니다.

Apple의 사례에서 배운 핵심은 기능을 사용자의 과업으로 설명하고, 원하는 정보로 직접 이동하며, 중요한 내용을 먼저 보이게 하는 것입니다. 이를 바탕으로 보여줄 정보의 우선순위와 끝까지 작동하는 사용 흐름부터 개선합니다.

05 · 그래프와 성적의 약속

항목설계 규칙
선유효한 선택 예측 점선 하나 + 실제 종가 실선 하나. 이전 전망·기준선은 자동 중첩하지 않음
기간과 재생44일 전체 경로는 그대로. 사용자가 시작하면 기본 달력 하루 1초로 커서·수치·이유만 이동. 중요 뉴스마다 확인 후 계속
가격과 날짜원 또는 % 단위를 명시. 마지막 실제 종가 뒤에 실제점을 만들지 않음. 휴장·누락·실패·미래를 구분
축재생 중 같은 자료의 축은 고정. 종목별 축은 명시하고 폭 비교는 공통 % 기준 또는 정확한 숫자로 제공
불확실성범위는 동일 전망의 선택 표시. 자료가 없으면 미산정. 꾸민 기울기·파동으로 빈 근거를 감추지 않음
성적방향과 폭을 별도 평가. 적중 수/평가 가능 수와 미평가 수를 함께 표시. 휴장일은 새 평가 날짜로 세지 않음
확률 표현관측된 적중률은 실적 비율. 모의 상승 비율이나 경로 수를 실제 적중 확률로 표시하지 않음
이유종목·날짜·전망에 저장된 계산 근거를 읽음. 확인 사실/검증할 가설/미확인을 구분하고 뉴스와 움직임의 인과를 단정하지 않음
원본 보존기존 전망·봉인 연구·실패 기록은 보존. 봉인 A/B 연구는 보관 상세에서 확인하고 운영 그래프를 복잡하게 만들지 않음

07 · ATLAS의 시각 언어

아이보리·깊은 브라운을 유지하고 강조색은 행동과 상태에만 사용합니다. Apple 제품 외형이나 로고를 복제하는 방식으로 고급스러움을 만들지 않습니다. 한국어 글자의 가독성, 숫자 정렬, 여백, 버튼의 일관성부터 맞춥니다.

차트와 숫자 뒤에는 투명 유리 효과를 쓰지 않습니다. 얇은 글씨를 줄이고 숫자는 자릿수를 맞춥니다. 아이콘에는 짧은 이름을 붙입니다. 상승·하락, 실제·예측은 색 외에도 부호·선 모양·문구로 구분합니다.

10 · 이번 작업의 완료 범위

완료: 6개 역할의 자료 학습, 현행 코드 구조와 자료 크기 확인, 이를 결합한 설계와 검수 기획.

이번에 하지 않은 것: 앱 코드·예측식·가격·뉴스·배포 ZIP 변경, 실제 서비스 배포, 실제 휴대폰 사용자 검사. 아래 조사 부록의 목표값은 향후 검수 기준이며 달성 결과가 아닙니다.

디자인 개선과 예측 정확도 검증은 별도입니다. 정보가 잘 읽히도록 바꾸어도 모형의 실전 우위가 입증되지는 않습니다. 이번 기획에서는 계산을 임의로 바꾸지 않습니다.

한 화면 배치 제안 데스크톱은 위에 종목 선택과 자료 날짜를 작게 놓고, 그 아래 그래프 왼쪽 약 2/3·날짜 설명 오른쪽 약 1/3로 구성한다. 그래프와 설명 사이에는 선택한 날짜라는 공통 문맥이 유지된다. 재생·이전 날짜·다음 날짜·속도는 그래프 아래 같은 자리에 둔다. 모바일은 종목 선택 → 핵심 수치 → 그래프 → 날짜 조작 → 날짜 설명 순서다. 그래프 위의 긴 설명을 없애고, ‘이날 이유’는 짧은 요약부터 보인다. 표 전체를 밀어서 읽게 하기보다 한 종목의 예상·실제·오차를 같은 카드에서 확인한다. 모바일 그래프 안의 날짜 선택 영역은 선의 정확한 픽셀을 누르지 않아도 작동하게 한다. 선택 날짜의 핵심 수치는 세 칸으로 제한한다: **예상 가격 / 실제 가격 / 차이**. 실제 미확보 날짜에는 마지막 두 칸이 ‘아직 미확보’가 되며, 0으로 채우지 않는다. ‘방향 일치’와 ‘폭 오차’는 이 아래 작은 두 항목으로 분리한다. ‘이날 이유’의 첫 세 줄은 다음 형식을 사용한다. 1. **계산에 들어간 것:** 해당 종목의 저장된 수익률 항·실제로 사용한 사건·선택 계수의 설명. 2. **아직 모르는 것:** 미확보 뉴스 결과·유보한 사건·자료 한계. 없으면 사실대로 없음 또는 미확보. 3. **실제와 달랐다면:** 확인된 차이와 조사 상태. 원인은 `확인 사실 / 검증할 가설 / 미확인`으로 표시. 여기서 더 보기를 누르면 뉴스 원문·공개 시각·표본·계산값·전망 버전이 나온다. 날짜별 설명은 해당 종목의 저장 자료에서 생성하며 다른 종목의 설명을 일반 문장으로 복제하지 않는다. ‘관련 뉴스가 있었다’와 ‘그 뉴스 때문에 가격이 움직였다’를 구분한다. ‘성적’의 첫 줄은 방향 적중 수/평가 수, 폭 오차, 미평가 수로 단순화한다. 숫자를 누르면 그 조건의 종목 목록으로 이동한다. 원본·진화·돌발 수정 기록은 같은 차트에 자동으로 여러 선을 겹치지 않고 명시적으로 버전을 선택하도록 한다. 이전 비교 시험·봉인·정책 원문은 설정·자료의 보관 기록에 둔다. ## 수용 검사 5개 1. **단일 예측과 보존:** 유효 예측이 있는 종목에서 예측선은 정확히 한 개, 실제선도 한 개다. 기준가·이전 전망선이 나타나지 않는다. 버전을 바꾸어도 저장된 원본 데이터·해시는 바뀌지 않는다. 2. **시간 의미:** 재생 중 전체 9/17~10/30 경로와 축은 고정되고 날짜 커서만 이동한다. 마지막 실제 종가 뒤에는 실제 점이 없다. 휴장일은 평가 일수에 추가되지 않는다. 3. **결측과 실패:** 실제 누락·부분 수집·전부 실패·미산정 예측을 각각 넣는다. 0 또는 평평한 대체 선으로 위장하지 않고 상태와 실제 자료 날짜가 첫 화면에 보인다. 4. **수치·설명 일치:** 날짜를 그래프/키보드/날짜 버튼으로 선택했을 때 동일 종목·동일 날짜·동일 전망 버전의 예상, 실제, 오차와 근거가 나타난다. 원/% 전환 후에도 오차 방향과 값이 맞고, 없는 기업 근거를 만들어내지 않는다. 5. **기기와 접근성:** 390px 모바일·1280px 데스크톱·키보드만 사용·색을 구분하지 못하는 조건에서 예측/실제/선택 날짜/자료 상태를 판별할 수 있다. 긴 뉴스는 그래프를 밀어내지 않는다. 애니메이션을 줄여도 선택 변경과 중요 뉴스 정지는 이해할 수 있다. 검사 결과는 이후 구현에서 실제 실행해야 한다. 이 문서는 검사 계획이지 통과 보고서가 아니다.
