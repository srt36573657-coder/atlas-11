# ATLAS 9.1.2 — 거래일별 분리 기둥

종목 그래프 기본 화면에서 연결선을 제거했습니다. 거래일만 같은 간격으로 배치하며, 기둥은 직전 거래일 저장 중앙값에서 당일 저장 중앙값까지의 가격 변화를 나타냅니다. 실제 OHLC 캔들이 아닙니다.

상승: 빨강 ↑ +등락률. 하락: 파랑 ↓ −등락률. 보합: 회색 —. 색은 시작일 대비 누적 수익률이 아닌 전 거래일 대비로 판정합니다. 높이는 원 단위 가격 변화이며 임의로 늘리지 않습니다. 작은 움직임도 화살표와 정확한 숫자로 읽습니다.

선택 날짜에 전날 가격 → 당일 가격과 금액 차이를 표시합니다. 종목 날짜 칸은 휴장일을 제외하고, 재생은 기본1000ms에 다음 거래일로 이동합니다. 중요 뉴스에서 확인 대기는 유지합니다. 1만원 별도 페이지의 기존44일 비교 재생과 원래 전체 가격 보기는 보존합니다.

폭이 작은 화면은 그래프 내부를 좌우로 이동하며 선택 날짜를 자동으로 보여줍니다. 가격 입력·뉴스·예측 가격·이전17개 전망·별도 일별 연구 전망은 불변입니다. 수학 대상5개와 실제 브라우저의 거래일 간격·방향·날짜 연동·휴장일 건너뛰기·작은 화면 선택 칸 표시를 검사했습니다. 기존 전체 검사 기록은 이번 변경의 전체 회귀 인증이 아닙니다.
