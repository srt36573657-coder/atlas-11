# ATLAS 갱신 방식: 11개 선택 기준

선택: 제한시간이 있는 병렬 수집 → 검토된 변경만 반영 → 원본 보존 검사 → 전체 기능 검사 → ZIP 무결성 확인.

1. 공식 출처: 발행사·거래소·정부·공식 주최자 우선.
2. 원문 확인: 검색 발췌를 승인 사건으로 바꾸지 않음.
3. 날짜 정확성: 2026년 및 9/17~10/30, 공개시각과 적용일 분리.
4. 대상 정확성: 다른 기업·자회사·업종 공통 일정의 혼동 차단.
5. 중복 제거: 같은 경제 사건과 단계를 구분하고 재게시로 표본 수를 늘리지 않음.
6. 시간 제한: 호스트별 재시도와 회로 차단을 적용해 한 주소에 작업 전체가 매달리지 않음.
7. 병렬 처리: 회사 수집·거시 수집·별도 공식자료 조사·검증 수정 작업을 분리.
8. 실패 투명성: 접속 실패·본문 미노출·미공개를 나누고 종료 코드 2 유지.
9. 기록 보존: 최초 원본과 기존 16개 전망·평가·실패 및 수정 저널을 해시/앞부분 일치로 검사.
10. 검증 범위: 설치 당시 검사는 고정 원본에, 일일 검사는 오늘 자료에 적용. 계산 정확도와 실전 예측력을 구분.
11. 전달 무결성: 최종 TAP 통과 후 빌드하고 외부 ZIP과 내부 소스 ZIP의 CRC를 모두 확인. 기존 파일 버전을 조건으로 교체.

이 방식을 선택한 이유는 막힌 수집이 전체 작업을 무한히 지연시키지 않으면서, 확인되지 않은 정보를 채워 넣거나 이전 결과를 손상시키지 않기 때문이다. 공개되지 않은 확정일 확보나 예측 적중을 보장하는 방식은 아니다.
