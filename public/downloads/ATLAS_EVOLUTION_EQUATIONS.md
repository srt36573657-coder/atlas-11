# ATLAS 별도 진화 연구 — 방정식과 사용 제한

기존 발행 전망, 최초 재구성본, 원래 뉴스 엔진을 수정하지 않는다. 진화는 `state.evolution`에 보관하는 별도 비교 실험이다. 원래 예측선과 일치해도 자료 부족을 숨기려고 선을 꾸미지 않는다.

## 1. 무엇을 학습하는가

종목 i의 **실제로 목표일 전에 발행된 다음 거래일 예측**과, 나중에 관측한 실제 종가 사이의 로그 오차만 사용한다.

`e(i,t) = log(actual(i,t)) − log(predicted(i,t))`

현재 정책 `next-session-ridge-residual-1`은 다음 거래일만 사용하므로 `h = 1`이다. 같은 종목·같은 목표 날짜에 여러 발행본이 있으면 목표일 전에 발행된 것 중 가장 최근 발행본을 먼저 고른다. 동시 발행은 ID 순서로 결정한다. 결과가 잘 맞았는지를 보고 발행본을 고르지 않는다. 최근 최대 20개 고유 목표 날짜를 보관하고, 최소 5개가 있어야 보정한다.

최초 재구성본은 ID로 제외하고 `isRetrospectiveReconstruction` 발행본도 제외한다. 단순히 기존 평가 장부에 PROSPECTIVE라고 쓰여 있다는 이유만으로 자격을 주지 않는다. 실제 발행·정보 시각이 모두 목표일 한국시간 00:00보다 앞서야 한다. 당일 장중 발행을 제외하는 보수적인 기준이다. 출처의 시간대가 없는 날짜·시각은 관측 증거로 쓰지 않는다.

종가의 유효 관측 시각은 행의 observedAt/retrievedAt/featureObservedAt 또는 현재 가격과 일치하는 최신 수정 저널의 at이다. 행 값과 최신 수정 저널이 다르면 유보한다. 미래 수정 이력이 있으면 당시 가격을 임의 복원하지 않고 유보한다. 해당 거래일 장 마감보다 이르거나 계산 시각보다 늦은 관측도 제외한다. 같은 날짜 중복 가격, 충돌, null, 0 이하 가격은 사용할 수 없다. 공통 종가일보다 나중의 일부 종목 자료는 그 종목의 확실한 관측 시각이 있을 때만 쓸 수 있다.

## 2. 고정된 축소 방정식

`c(i) = Σ[h × e(i,t)] / (λ + Σ[h²])`, `λ = 5`

이는 `Σ(e − h c)² + λ c²`를 최소화하는 1계수 축소 해다. 현재 h=1이다. 최소 날짜 수를 충족하지 않으면 `c=0`, 상태는 `INSUFFICIENT`이다. 계산된 실측 평균 0이라고 부르지 않는다.

λ=5, 최소 5일, 최대 20일은 **사전에 정한 연구 설정**이며 적중률 또는 충분한 통계적 신뢰의 검증 기준이 아니다. 향후 성적을 본 뒤 유리한 값을 골라 기존 기록을 덮어쓰지 않는다. 극단 손실을 잘랐거나 탈락시킨 뒤 계수를 계산하지 않는다.

## 3. 별도 미래 경로

새 연구 발행 시각 `issuedAt`은 실제 계산 시각이다. 기준 전망의 9/23 같은 출발일로 발행 시각을 소급하지 않는다. 새 연구 기준점은 발행 시각까지 장 마감이 끝난 최근 거래일이다. 그 기준점부터 미래 목표일까지의 거래일 수를 h라고 한다.

`P_shadow(i,t) = P_base(i,t) × exp[c(i) h]`

발행 시각 이후의 목표 행에만 적용한다. 과거 행은 기준 전망의 참고값으로만 보관하며, 화면에서는 발행 전 진화 예측선을 표시하지 않는다. 범위도 같은 배율로 옮기지만 이는 **검증되지 않은 실험용 이동 범위**다. 불확실성이 보정되었다거나 적중률 80%라고 주장하지 않는다. 이전 분포의 상승 확률·Brier·직접 적률을 새 분포 값인 것처럼 복사하지 않는다. `probUp`, `rawProbUp`, `trustProbability`, 평균·분산 필드는 새 연구 행에 만들지 않는다.

배율 계산은 `exp(log(P_base) + c h)`를 쓴다. 최종 값이 표현 범위를 넘으면 해당 값은 null, `numericStatus=numeric_range_limit`로 남긴다. 극단 학습 표본을 삭제하지 않는다. 비어 있는 기준 값은 비어 있는 상태를 유지한다.

미학습 상태의 선은 기존 선과 동일하다. 자료를 확보했다는 이유만으로 뉴스의 인과 영향을 판정하거나 사건 가중치를 자동 조정하지 않는다.

## 4. 이후 실제 평가

새 진화 발행본과 그 발행 당시의 동일 기준 전망 값을 같은 실제 종가에 쌍으로 비교한다.

`errorWon = actual − predicted`

`APE = |actual − predicted| / actual`

기준 전망 오차도 동일 날짜·동일 실제 빈티지로 보관한다. 발행이 목표일 시작보다 늦으면 별도 진화의 사전 예측 성적으로 쓰지 않는다. 미래·미관측 값에는 성적을 만들지 않는다. 실제 가격이 정정되면 새 빈티지의 평가 행을 추가하며 과거 평가 행은 보존한다. 진화의 자체 출력은 이번 단순 보정의 학습 입력으로 다시 섞지 않는다.

52종목의 같은 날짜를 52개의 독립 검증 날짜로 세지 않는다. `independentValidationCount`는 0이며 모의·구현 검사 횟수를 시장 검증 횟수로 바꾸지 않는다. 가격 오차의 원인은 `UNKNOWN`이다. 사용자의 설명은 별도 notes의 HYPOTHESIS이며 자동 적용하지 않는다.

## 5. 저장과 충돌

스키마 1: `versions`, `evaluations`, `proposals`, `runs`, `notes`는 추가만 하는 기록이다. `activeId`는 현재 수용된 입력에 대응하는 연구 발행본을 가리킨다. 합쳐진 다른 분기의 발행본은 보관하되 마지막 배열 원소라는 이유로 활성화하지 않는다. 같은 ID에 다른 내용이 오면 병합 충돌로 남긴다.

`inputFingerprint`는 기존 브라우저 호환 해시를 이용한 동일 의미 입력 식별자이며 암호학적 SHA나 원본 진위 보증이 아니다. 같은 관측의 수집 시각만 바뀌면 새 연구 발행본을 만들지 않는다. 기준 전망·실제 오차·유효 가격 정정이 달라졌을 때 새 발행본을 추가한다. 원본 SHA는 호출자가 제공한 값을 별도 보존하며 모듈이 원본 SHA를 계산했다고 주장하지 않는다.

종료일은 2026-10-30을 넘지 않는다. 한국 날짜가 종료일 다음날이면 새 학습·평가·발행을 수행하지 않는다.
