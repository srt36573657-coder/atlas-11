# ATLAS 8.0 추가 수식 — 종목별 조건부 평균

기존 뉴스 반응·범위 검사를 유지하면서 일반일 기대수익률을 따로 추정합니다. 아래 수식은 `lib/conditional-return.mjs`, `lib/forecast-engine.mjs`에서 실제 실행됩니다. 검증된 시장 법칙이라는 뜻은 아닙니다.

1. 로그수익률: rᵢ,t = ln(Pᵢ,t/Pᵢ,t−1). 해당 종목의 연속 거래일 가격만 씁니다. 큰 상승·하락을 크기만으로 제거하지 않습니다.
2. 특징: zᵢ,t = (평균 rᵢ,t−5:t−1, 평균 rᵢ,t−20:t−1, 평균 rᵢ,t−60:t−1). 출발 전 60거래일이 끊기면 미산정(null)입니다.
3. 후보: 영(0) 평균, 축소 평균, 릿지 λ∈{0.1,1,10}. 최대 504개 학습 예제, 최소 126개, 절편 a=Σr/(n+252). 특징을 RMS로 정규화한 Z에서 β_scaled=(ZᵀZ+λnI)⁻¹Zᵀ(r−a)를 피벗 소거로 풀고 원단위 계수로 복원합니다. 복원 계수의 Σ|β|≥1인 불안정 후보는 제외합니다. 가격 손실 경로를 제거하는 규칙은 아닙니다.
4. 선택: 9/17 이전의 시간순 20거래일 검증 구간 최대 6개, 최소 3개. 예측거리 h∈{1,5,20}에 대해 L=평균 |Σ실제 r−Σ예상 m|/√h. wₖ ∝ exp[−(Lₖ−min L)/L₀]. 0 평균 후보의 손실 L₀을 척도로 사용합니다. 후보 선택에 쓴 손실은 독립 정확도 감사가 아닙니다.
5. 하루 평균: mᵢ,t=Σₖ wₖ(aₖ+βₖᵀzᵢ,t). 계수·혼합비는 고정하고 이후 특징 이력에는 예상 m을 재귀적으로 추가합니다. 관측 가격이 갱신되면 새 전망의 출발 특징을 갱신하며 이전 전망은 바꾸지 않습니다.
6. 모의 로그수익률: Rᵇᵢ,t=mᵢ,t+εᵇᵢ,t. 유효 단일 뉴스일에는 ε를 그 종목 뉴스 표본의 중심화 잔여반응+선택 뉴스 중심효과로 교체합니다. 뉴스 전체 일별 반응과 일반일 충격을 중복 합산하지 않습니다. 뉴스 방향이 유보되어도 m을 0으로 바꾸지 않습니다.
일반일 공동 추출 날짜는 고정 거래일표와 시장 사건표에서 정합니다. 개별 종목의 결측은 자기 종목에서만 재추출하므로 다른 종목의 가격 분포·뉴스 영향값을 바꾸지 않습니다.

7. 가격: Pᵇᵢ,t=Pᵇᵢ,t−1 exp(Rᵇᵢ,t). 모형 평균·분산은 하루 분포 적률로 직접 계산, 첫 거래일 분위수는 경험분포를 정확히 합산, 이후 분위수는 20,000경로와 DKW 모의 오차 한계를 기록합니다. 현재 μ 경로는 결정론적이고 시간별 혁신은 독립이라는 모형 가정입니다. 수익률 자기상관·국면 변화의 잔여 오차를 해결했다는 뜻은 아닙니다.
8. 뉴스 영향순: 같은 난수 경로에서 한 사건만 반영/해제한 10/30 가격 분포의 W₁=평균ⱼ|정렬(P_with)ⱼ−정렬(P_without)ⱼ|/P_origin×100 (%p). 중앙값 차이도 별도 표시합니다. 인과효과나 실제 적중 확률이 아닙니다. 계산을 유보한 사건은 null로 두고 0으로 정렬하지 않습니다.
9. 결과 비교: 오차원=실제−동결예측, 절대오차율=|오차원|/실제, 수익률 오차=오차원/전망출발가격. 방향은 출발가격 대비 부호, 범위는 저장 P10~P90 포함 여부입니다. 임의 허용오차를 만들어 가격 적중으로 판정하지 않습니다.
10. 보존키: 종목+날짜+전망ID+실제가격원본ID+평가규칙해시. 같은 기록은 재추가하지 않고 가격 정정은 새 빈티지 기록으로 추가합니다. 정정 전 기록은 남깁니다. 최초 전망은 사후 재구성임을 유지합니다.

미확보 요소를 0 관측값으로 만들지 않습니다. FOMO 전체·공식 10년 지수/업종·발표 직전 예상치/실제 결과는 입력과 별도 검증 전까지 가격 보정으로 쓰지 않습니다. 수식 개선안 36개가 모두 실증 검증·승인됐다는 뜻이 아닙니다.

# ATLAS 7: 뉴스 근거와 계산 방정식

대상은 기존 52종목, 기간은 2026-09-17~2026-10-30이다. 이 문서는 실행 중인 atlas-news-7.0.0의 식을 설명한다. 숫자의 계산 정밀도와 실제 주가 예측 정확도는 서로 다른 성질이다. 방향 판단은 `abstain`, 실제 신뢰 확률은 `null`이다.

## 1. 뉴스는 몇 개 필요한가

종목마다 10건·20건을 채우는 방식은 쓰지 않는다. 같은 공시를 전한 기사 10개는 경제 사건 1개다. 하나의 유상증자의 기준일과 권리 상장일도 하나의 경제 사건의 서로 다른 단계다. 공통 발표가 52종목에 연결되어도 독립 사건 52개가 되지 않는다.

일정 확인, 경제적 관련성, 수치 추정 가능성, 실제 예측 우위의 네 단계를 구분한다. IR·전시·주주명부 기준일·재공시 예고는 날짜가 정확해도 수익이나 현금흐름 변화가 확인된 것이 아니다. 실적·자금조달·중요 계약·규제 결정도 발표 내용, 시장 예상과의 차이, 기업행위 조정, 비교 가능한 과거 표본이 필요하다.

과거 사건을 동일 기업·사건 종류·기간·정보 기준으로 선별하고 같은 날짜 및 중첩 반응 구간을 묶는다. 가중치 w가 있을 때 유효 표본수는 다음과 같다.

```
N_effective = (Σ w_j)² / Σ w_j²
```

독립성·동일분포를 가정한 과거 양의 반응 빈도 p의 Wilson 구간 반폭은 다음과 같다.

```
H = z / (1 + z²/n) × sqrt[p(1-p)/n + z²/(4n²)]
z = 1.959963984540054
```

p=0.5일 때 독립 100표본의 반폭은 약 9.6%p, 400표본은 약 4.9%p다. 이것도 실제 다음 주가 적중 확률이 아니다. Kish 유효 표본수를 대입하는 경우 가중 근사일 뿐 정확한 구간 보장이 아니다. 기업별 중요한 사건은 이만큼 독립 표본을 얻기 어려워 유보가 정당한 결과가 된다. 목표 오차·독립성 점검·결과를 보기 전 고정한 검증 규칙이 없으면 통계적 추정 가능으로 통과시키지 않는다.

**현재 5표본 기준은 연구용 경험분포를 구성하는 최소 조건이다. 신뢰·정확도 합격선이 아니다.** 기본 경로 20,000개는 뉴스 20,000개나 독립 검증 20,000번이 아니다.

## 2. 당시 알 수 있었던 정보와 대상

```
I_i(e,t) = 1{knownAt(e) ≤ t} × 1{source verified}
           × 1{scope includes i} × 1{valid exact event/session date}
```

회사 사건은 해당 코드에만, 업종 사건은 명시 대상에만 연결한다. 지수 구성 사건에는 명시 코드·공개된 구성 출처·적용 기간이 필요하다. 전체 적용 범위를 추측하지 않는다. 공개 날짜와 조회 시각을 나눠 보존한다. 공개 시각이 미확보면 조회 시각을 과거 공개 시각으로 소급하지 않는다.

수정 전후를 깊은 복사로 기록하고, 기준 시각 뒤의 변경을 역순으로 되돌린다. 기록된 신규 삽입도 되돌린다. 동일 시각 여러 수정은 저널 순서를 뒤집는다. 상충 동일 ID는 지우거나 임의 선택하지 않고 유보한다. 기록되지 않은 과거 빈티지를 복원했다고 주장하지 않는다.

## 3. 연구용 수익률과 소거법

```
r_i,t = log(P_i,t / P_i,t-1)
x_i,e = r_i,event - mean(r_i,직전 연속 20거래일)
μ_raw = mean(x_i,e)
μ_shrunk = [n / (n + 8)] × μ_raw
μ_effect = λ × μ_shrunk
```

직전 20거래일이 끊기면 표본을 유보한다. 절대 수익률이 크다는 이유로 상승·하락·손실 경로를 제거하지 않는다. 동일 기업의 같은 날 여러 중요 사건은 결합 반응 근거가 없으면 개별 충격을 넣지 않는다. 설명용 일정은 가격 충격으로 세지 않으며 공통 발표를 자동 차단하지 않는다. 동시 발생은 미측정 교란 경고로 남는다.

λ 후보는 사전에 고정한 {0, 0.25, 0.5, 1}. 과거 표본을 시간순으로 나누어 MAE·CRPS·Brier가 모두 λ=0보다 나쁘지 않은 후보만 남긴다. 손실 경로를 소거하는 것이 아니라 근거 없는 영향 계수를 배제하는 것이다. 혼합 결과도 세 지표를 다시 검사한다. 이것은 같은 과거 자료로 하는 내부 선택이며 새로운 독립 성능 인증이 아니다. 기존 v5 보정 α는 이식하지 않는다.

## 4. 몬테카를로 경로

```
일반일: R_i,t ~ 해당 종목 일반일 수익률 - 해당 표본 평균
사건일: R_i,t ~ x_i,e - μ_raw + μ_effect
P_i,t+1^(b) = P_i,t^(b) × exp(R_i,t+1^(b))
```

사건일에는 일반일 충격에 사건일 전체 수익률을 더하지 않고 교체한다. 일반 날짜는 종목 간 공유하되 각 종목의 수익률을 사용한다. 회사 A의 사건 표본이 무관한 B에 들어가지 않는다. 사건의 공통 날짜 집합에 그 종목의 유효 표본이 없으면 그 종목 표본에서 다시 뽑는다.

공통 날짜 수 K, 유효 기업 표본 수 n, 공통 날짜와 일치하는 표본 날짜 수 M일 때 사건 표본 j의 실제 선택 가중치는 다음과 같다.

```
K > 0: w_j = 1{date_j ∈ sharedDates}/K + (K-M)/(K×n)
K = 0: w_j = 1/n
```

따라서 사건 표본을 무조건 균등 가중해 평균·분산을 계산하면 안 된다. v7은 실제 선택 방식과 같은 가중치를 직접 적률 계산에 전달한다.

## 5. 평균·분산을 난수 없이 직접 계산

모형 안에서 일별 증분을 독립 추출한다는 가정 아래 다음을 계산한다.

```
a_t = Σ_j w_t,j exp(R_t,j)
b_t = Σ_j w_t,j exp(2 R_t,j)
E[P_h] = P_0 × ∏_(t=1..h) a_t
E[P_h²] = P_0² × ∏_(t=1..h) b_t
Var(P_h) = E[P_h²] - E[P_h]²
SE(표본평균) = sqrt[Var(P_h)/B]
```

보상 합산, log-sum-exp, expm1, 로그 상대분산을 사용해 작은 차이의 소실·극단 가중치·오버플로를 처리한다. 표시 가능한 범위를 넘으면 null과 오류 표시를 남기고 꼬리 표본을 삭제하지 않는다. 직접 적률은 난수 시드에 흔들리지 않는다. `mean`은 직접 평균, `monteCarloMean`은 경로 표본평균이다. 직접 평균의 몬테카를로 오차는 0이나 모형 오류·자료 오류는 0이 아니다.

7.6부터 첫 거래일의 중앙값·P10·P90·출발가 초과 비중은 가중 경험분포를 직접 합산한다. 이후 날짜는 몬테카를로 근사이며 고정 표본 DKW 오차 구간을 함께 기록한다. 상세 계산식은 ATLAS_PRECISION_7_6.md에 있다. 경로 상승 비율 q의 계산 표준오차 sqrt[q(1-q)/B]는 투자 성공 확률의 신뢰구간이 아니다. 종목 간 순위는 공동분포 가정에도 의존하므로 기본 추천 순위는 유보한다. 실제 시장의 자기상관·구조 변화·갑작스러운 뉴스는 이 단순 모형의 밖에 있다.

## 6. 검증

`scripts/validate_numerics_10000.mjs`는 고정 입력·시드로 실제 10,000개 작은 유한분포를 만들고 모든 조합을 전수 열거한 기준과 직접 계산을 비교한다. 결과는 `reports/numerics-10000.json`에 있다. 이는 수학 구현 검사이며 실제 시장 교차검증 횟수는 0이다. 같은 사례를 다시 실행해 독립 검사 횟수를 늘리지 않는다.

기존 v6 시장 사후 감사는 원본 코드와 기록으로 보존한다. 현재 v7의 새로운 독립 예측 성적은 아직 없다. 검증은 시간순의 과거만 훈련에 쓰고 이후 구간을 평가해야 한다. 9/17 이후 성적으로 이번 계수·시드를 선택하지 않았다.

## 7. ATLAS 7.1 표시·설명 방정식

주가 엔진은 동일한 atlas-news-7.0.0이다. 저장된 전망을 바꾸지 않고 전체 기간 표시와 날짜별 근거 설명을 추가한다.

- 날짜별 증감: ΔP=P_t−P_(t−1), r=P_t/P_(t−1)−1. 실제·중앙값·평균을 각각 비교한다.
- 모형 평균 분포 비교: ΔM=M_(t−1)×[exp(ℓ_today)−exp(ℓ_ordinary)], ℓ=log E[exp(R)]. 실제 뉴스의 인과효과가 아니다.
- 전체 경로는 항상 표시하고 커서만 기본1000ms마다 다음 달력 날짜로 움직인다. 휴장일은 직전 거래일 참고값이며 새로운 가격 행이 아니다.
- 날짜별 설명은 해당 종목의 저장 가격·사건·자체 표본·선택계수·출처·유보 사유만 사용한다. 0개 표본의 기본값을 실제 관측 0으로 제시하지 않는다.

상세 기획·방정식·실제 코드 연결: ATLAS_DAILY_PLAN.md.


## ATLAS 7.2: FOMO 18항목과 그래프 좌표

FOMO 항목별 원식·백분위·중복 할인·가중치·시간순 후보 평가의 실행 코드와 식은 public/downloads/ATLAS_FOMO_EQUATIONS.md에 있습니다. 가격 열기와 완전한 FOMO 종합 점수는 구분합니다. 현재 가격 반영 가중치 0, 기존 가격 엔진과 모든 전망은 보존합니다.

전망 확대의 세로값은 Y=(P/P_origin−1), 픽셀 위치는 y=top+(hi−Y)/(hi−lo)×height입니다. 날짜 위치는 x=left+(date−9/17)/(10/30−9/17)×width입니다. 확대는 축만 바꾸며 가격을 바꾸지 않습니다. 전체 흐름 작은 그래프는 9/17 종가를 기준으로 표시합니다.

## ATLAS 7.4: 신문 역사 자료 대조

기사 수치를 같은 종목·같은 기간의 보관가격과 대조합니다. r=100×(P_end/P_start−1), 차이=보관 계산값−보도값(%p), 허용 반올림 차이=0.5×10^(−표시 자릿수). 종가는 원 단위 직접 비교입니다. 일간·연간·반기를 분리하며 연간 수익률을 일간으로 변환하지 않습니다.

후일 자료·수정값은 기준 시각의 보관 릴리스를 먼저 복원하고 공개·관측 시각 검사 뒤 사용합니다. 같은 사실의 재인용을 독립 표본으로 세지 않습니다. 현재 기사값은 방향 보정 자격 미충족으로 추가 가격 보정 0, 신뢰 확률 null입니다. 실제 연결 결과·식·충돌값은 public/downloads/ATLAS_PRESS_INTEGRATION.md와 press_history_report.json에 있습니다.
