# ATLAS 8.0.1 — 감사 수정 배포

2026-09-27. 검증된 구현·방어 결함 12개와 명시적 완전 레코드 교체 모드를 운영 소스에 통합했습니다.

- 과거 검증의 연속 60거래일 조건, 중간 지수 연산의 범위 초과, 동일 뉴스 ID의 중요 필드 상충, 사건 단계 및 동시 별도 사건 표본 검사를 수정했습니다.
- 수동 자료 변경 전후 저널과 revision 증가, 뉴스 공개 시각 정정, 결측 예측 채점, 최신 평가 관측시각 선택을 수정했습니다.
- 주기 감사에서 상충 중복과 겹치는 수익률 구간을 거부합니다. 경계만 공유하는 구간은 허용합니다.
- 과거 자료와 계수·시드를 임의로 조정하지 않았습니다. 같은 보관 가격(2026-09-23)과 뉴스로 새 엔진 전망을 추가하며 최초 및 이전 전망은 보존합니다. 이번 작업은 새 종가·뉴스 수집이 아닙니다.
- 미해결: 검토 시각 없는 과거 뉴스 인증(N01), 과거 원문·상태 자격 부족(N04), 의미가 같은 입력의 순서에 따른 해시 변경(T06). 해당 문제를 해결 완료라고 표시하지 않습니다.
- 최초 통합 검사 실패, 감사 보고서 및 과거 검사 기록은 reports/audit-8.0.1에 보존합니다. 현재 전체 검사 결과는 reports/tests.tap과 reports/audit-release-8.0.1/validation.json을 확인하세요.
- 기능 통과는 독립 예측 적중률 인증이 아닙니다. 기존 v6/v8 감사는 새 엔진의 인증으로 재사용하지 않습니다. research_only 및 trustProbability:null을 유지합니다.
- Netlify Drop ZIP은 정적 화면·브라우저 계산용입니다. 서버 자동 수집·구글 로그인은 전체 소스와 별도 계정 설정이 필요합니다. 실제 사이트 배포는 수행하지 않았습니다.
