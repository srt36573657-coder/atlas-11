# ATLAS · 명확함을 위한 화면 개편

2026-09-28. 애플의 디자인 원칙과 Steve Jobs Archive를 읽고 ATLAS에 적용한 설계 기록입니다. 애플의 제품이나 잡스 본인이 설계한 결과가 아닙니다.

참고: https://developer.apple.com/design/human-interface-guidelines/design-principles · https://developer.apple.com/design/human-interface-guidelines/layout · https://book.stevejobsarchive.com/

## 적용
- 집중: 현재 종목과 실제 종가를 가장 강하게, 미래 수치와 오차를 다음 순서로 배치.
- 계층: 회색 배경 위 흰 정보 영역, 큰 가격, 파란 전망과 조작. 장식색 축소.
- 이해: 실제/전망의 기존 선 규격과 기준일을 유지. 글씨만 크게 해 확정성으로 오해시키지 않음.
- 단순한 첫 화면: 긴 원자료 상태 설명은 펼침으로 이동. 연구용·정확도 미검증 표시는 항상 노출.
- 일관성: 종목 선택, 날짜 선택, 재생, 52종목 비교의 동작과 위치를 유지.
- 접근성: 모바일 검색 16px, 주요 버튼 최소44px, 키보드 선택창 Escape와 닫기 후 초점 복귀.
- 품질: PC와 모바일 실제 브라우저에서 종목 전환·뉴스 정지·다운로드·가로 넘침을 확인.

## 범위
이번 변경은 표시 및 조작 변경입니다. 입력·52종목 전망·채점 JSON의 SHA256을 전후 비교합니다. 예측 정확도가 높아졌다는 의미가 아니며 과거 가격 기준, 33요인, 전체 FOMO의 미완료 상태를 유지합니다.

## 이번 실행 결과
- 관련 기능 검사35개 통과, 실패0.
- Chromium PC/모바일 검사29개 통과. 실제 아이폰 기기 검사는 미실행.
- 가격·전망·채점 입력 해시 동일. 금융 모델은 변경하지 않았습니다.
- 이전656개 전체 검사는 이전 자료 수정 릴리스의 결과이며 이번 디자인 변경을 포함한 재실행 횟수가 아닙니다.
