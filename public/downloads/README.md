각 종목은 날짜·속도·재생·정지가 독립입니다. 기본 달력 하루 1초이고 중요한 뉴스에서는 ‘설명 확인 · 계속’까지 멈춥니다. 보기를 닫거나 다른 종목으로 전환해도 개별 상태는 보존됩니다. 탭 이동은 재생을 정지합니다. 종목당 타이머는 하나입니다.

## Netlify에 올리기

배포 ZIP을 푼 뒤 Windows는 DEPLOY_NETLIFY.cmd를 실행합니다. Mac/Linux는 같은 폴더에서 node DEPLOY_NETLIFY.mjs를 실행합니다. Node.js 24.15 이상이 필요합니다. 실행기가 동봉 소스를 풀고 로그인·프로젝트 선택·함수 포함 배포를 안내합니다.

Netlify Drop에 정적 파일만 올려도 화면과 기기 내 계산은 작동합니다. 매일 자동 수집에는 함수를 포함한 배포가 필요합니다. 자세한 설명은 downloads/DEPLOY.md입니다. 사용자의 Netlify 계정 배포가 완료되었다고 확인한 것은 아닙니다.

배포가 실패하면 CHECK_ATLAS.cmd로 검사하고 ATLAS_RUN_LOG.jsonl을 확인합니다. 같은 실행기 재시도 시 기존 자료·관리자 키를 보존합니다. 배포 파일에는 개인 관리자 키를 넣지 않습니다.

한국시간 매일 16:00~17:45에 수집을 재시도합니다. 휴장일은 보관 종가를 재사용했다고 표시하고 뉴스는 확인합니다. 일부 실패는 마지막 정상 자료와 실패 로그를 보존합니다. 공통 종가가 없는 경우 52종목 출발일을 억지로 전진시키지 않습니다. 10/30 종가가 모두 확보되면 최종 채점으로 종료합니다.

실제 브라우저의 픽셀·줌별 배치는 브라우저 실행파일 부재로 검증하지 못했습니다. 실제 빌드 UI는 jsdom과 Worker로 동작을 검사합니다. 사용자 브라우저의 다운로드·실제 배포와 소프트웨어 검사 통과는 구분합니다.

현재 근거별 수량은 `VALIDATION.md` 및 `NEWS_RESEARCH_52.md`에서 실제 입력으로 생성합니다. 13종목 추적기는 앞선 조사 이력이며 현재 52종목 개편 보고서는 `reports/rebuild52-research-a.json`과 `-b.json`입니다. 업종 행사와 기업 참가, 예정일과 발표 결과, 유상증자의 여러 단계는 서로 구분합니다.
