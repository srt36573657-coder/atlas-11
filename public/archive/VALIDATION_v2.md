## 화면 검사 범위

빌드된 React 프로그램을 jsdom 환경에서 실행하고, 버튼을 눌러 Worker 계산·IndexedDB 저장까지 검사했습니다. 2,000 경로의 새 후보를 생성하고 승인 이력 1건을 읽어 확인했습니다. 웹 Worker의 계산 파일은 Node worker_threads 연결로 실행했습니다.

실제 브라우저의 로컬 미리보기 연결은 차단되어 **픽셀 렌더링·모바일 배치·실제 브라우저 다운로드는 검증하지 못했습니다**. 이를 브라우저 시각 검증 통과라고 표시하지 않습니다.

## 서버 검사 범위

독립 Node 서버는 실제 HTTP 요청·인증·동시 요청·파일 저장·종료·재시작으로 검증했습니다. Netlify API 코드는 공식 SDK와 조건부 저장 HTTP 계약을 구현한 로컬 검사용 서버로 검사했습니다. Netlify의 로컬 BlobsServer 11.1.1은 GET ETag 헤더를 반환하지 않아 해당 시뮬레이터를 동시 저장 검사 근거로 쓰지 않았습니다.

**사용자의 Netlify 계정에 실제 배포하거나 예약 작업을 실행한 상태는 아닙니다.** 전체 소스에 서버 함수·백그라운드 수집·예약 설정을 포함했고, 운영 배포와 관리자 키 설정 후 사용할 수 있습니다. Netlify 수동 업로드는 정적 화면·계산·이 기기 저장 모드입니다.
