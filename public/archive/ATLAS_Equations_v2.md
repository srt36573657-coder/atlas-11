# ATLAS 2.0.1 — 몬테카를로·소거법 방정식

## 목적과 기준

2026-09-17 종가를 출발값으로, 사용자 지정 52종목의 2026-10-30까지 **27개 미래 거래일**을 계산한다. 출발일을 합쳐 1,456행이다. 실제 당시 발행된 전망이 아니라 현재 확보된 과거 가격으로 재구성한 전망이다. 기업행사 조정 자료의 당시 버전과 당시 업종 시가총액 1위 여부는 검증되지 않았다.

여기서 소거법은 방정식의 미지수를 없애는 가우스 소거법이 아니다. **미래 정보·유효하지 않은 자료·중복 사건을 제외하고, 과거 순차검증에서 기준모형보다 오차가 큰 모형을 제외하는 선택 규칙**이다. 나쁜 결과나 하락 경로를 삭제하지 않는다.

## 1. 관측값과 자료 소거

종목 i의 거래일 t 종가를 P(i,t), 정보 기준일을 τ, 마지막 예측일을 T라고 한다.

```
D*(τ) = { (i,t,P) : t ≤ τ, t는 거래일, P > 0, P는 유한수,
                    출처 충돌 없음, 같은 날짜 중복 없음 }
r(i,t) = ln[P(i,t) / P(i,t-1)]
```

두 가격이 연속 거래일에 모두 있을 때만 수익률을 만든다. 결측 거래일을 건너뛴 여러 날 수익률을 하루 수익률처럼 사용하지 않는다. 학습창은 최대 최근 60개 유효 수익률이다. 기본 자료는 종목당 약 45개 이내이며, 20개 미만 또는 출발 종가 누락이면 계산을 차단한다. 9/18 이후 실제 가격은 9/17 원본 예측의 계산과 모형 선택에 사용하지 않는다.

## 2. 다섯 가지 후보 모형

```
r̄ = (1/n) Σ r(t)
μm = λm r̄
λRW=0, λD25=0.25, λD50=0.5, λD100=1, λAR=0.25

φAR = clip[ Σ(t=2..n)(r(t)-r̄)(r(t-1)-r̄) / Σ(t=1..n)(r(t)-r̄)²,
            -0.8, 0.8 ]
φRW=φD25=φD50=φD100=0
μm(h) = λm r̄ + φm^h [r(n)-r̄]
ĝm(h) = Σ(j=1..h) μm(j)
```

분산이 0이면 φ=0이다. AR 후보는 마지막 수익률의 영향이 감쇠하는 결정적 추세 항이며, 완전한 AR-GARCH 모형이 아니다. 잔차의 시간 의존성은 뒤의 블록 재표집으로 근사한다.

## 3. 모형 소거와 가중치

과거의 각 가상 기준점 k에서 **그 시점 이전 수익률만** 학습한다. 학습표본 최소 20개, 예측 길이 h∈{1,5,10}을 사용한다. 검증 대상 h개가 실제 연속 거래일인 경우만 포함한다.

```
e(m,k,h) = | Σ(j=1..h) r(k+j) - ĝm,k(h) |
Lm = (1/|F|) Σ((k,h)∈F) e(m,k,h)
S = {RW} ∪ {m : |F| ≥ 10 그리고 Lm ≤ LRW}
a = max(LRW, 0.000001)
wm = exp[-4(Lm - min(j∈S)Lj)/a] / Σ(j∈S) exp[-4(Lj-min(L))/a]
```

검증 조합이 10개 미만이면 RW만 사용한다. 모든 모형에서 **로그수익률의 절대오차**로 비교한다. 여러 시점·기간의 검증 구간은 겹칠 수 있으며 서로 독립적인 실험이 아니다. 이 검증은 후보 선택용이지, 27거래일 예측 성능을 독립적으로 입증한 검증이 아니다. 숫자 4, 창 길이 60, 블록 길이 5는 초기 설계값이다. 현재 비교기간에 맞춰 최적화하지 않았다.

## 4. 몬테카를로 경로

경로 b마다 모형 m을 wm의 확률로 선택한다. 기본 B=10,000이며 화면에서 2,000·10,000·20,000을 선택할 수 있다.

과거 공통 날짜를 무작위로 고르고, 그 날짜부터 5거래일 연속 블록을 순환 방식으로 재표집한다. 모든 종목이 같은 날짜 블록을 공유하여 종목 간 동시 충격을 근사한다. 해당 종목의 날짜 수익률이 없으면 그 종목의 유효 학습수익률에서 재표집하며, 이 비율은 `commonBlockFallbackRate`에 남긴다. 결측 시 공분산 보존은 불완전하다.

```
ε(i,b,h) = r(i,표집날짜(b,h)) - r̄i
P(i,b,0) = 실제 기준일 종가
P(i,b,h) = P(i,b,h-1) × exp[ μm,i(h) + ε(i,b,h) + J(i,b,h) ]
```

지수식을 쓰므로 수학적으로 가격이 양수다. 수치 overflow·0·NaN이 나오면 계산을 중단하고 오류를 표시한다. 음수 수익률과 하락 경로를 유지한다. 난수 시드를 고정하면 같은 입력으로 동일한 결과가 나온다.

## 5. 사건 영향의 소거

기준일 16:00 한국시간까지 공개된 시각이 확인되고, 미래 목표 거래일·발생확률·중복 없는 식별자가 있으며, 기본모형과 중복을 제거한 부호 있는 잔여 영향 표본이 최소 5개인 사건만 허용한다.

```
J(i,b,h) = Σe [ 1(이 종목·날짜에 적용) × Bernoulli(pe,b) × ln(1+δe,b) ]
δe,b ∈ 검증된 잔여 영향 표본, δe,b > -1
```

같은 사건의 부정적 영향도 그대로 적용한다. 현재 패키지에 있는 일정 후보 10개는 잔여 영향 근거가 부족하여 모두 제외한다. 따라서 현재 실행은 J=0인 가격 기반 모형이다. 확인하지 않은 뉴스·수급·심리·거래량 수치를 만들거나 0점 자료로 위장하여 가중하지 않는다.

## 6. 출력

```
중심 예상가격 = Q0.5({P(i,b,h)})
예상 범위 = [ Q0.1({P(i,b,h)}), Q0.9({P(i,b,h)}) ]
상승확률 = (1/B) Σb 1[P(i,b,h) > P(i,b,0)]
예상수익률(i,h) = P50(i,h)/P(i,0) - 1
10/30 순위 = 예상수익률(i,T) 내림차순; 동률은 종목코드 오름차순
상위10 확률 = (1/B) Σb 1[경로 b의 종목간 최종 수익률 순위 ≤ 10]
```

분위수는 정렬 표본의 (B-1)q 위치를 선형 보간한다. 원 단위 표시값은 소수 둘째 자리로 반올림하며 순위 수익률은 이 P50을 사용한다. 출발일의 상승확률은 예측 성과가 아니므로 null이다. P10~P90은 **모형상 목표 80% 구간**이며, 실제 미래값이 80% 확률로 포함된다는 검증된 보장이 아니다.

## 7. 실제값과의 비교

```
e(i,t) = [실제가격(i,t)-P50(i,t)] / 기준일 실제가격(i)
MAE = 평균 |e(i,t)|
기준모형 MAE = 평균 |실제가격(i,t)-기준일가격(i)| / 기준일가격(i)
포함률 = 평균 1[P10(i,t) ≤ 실제가격(i,t) ≤ P90(i,t)]
```

출발일·실제값 누락·출처 충돌은 평가에서 제외한다. %p 표시는 위 비율에 100을 곱한다. 9/23까지 원본에 대한 유효 비교는 200행이며, MAE 약 2.9657%p, 종가 유지 기준 약 2.9282%p이다. 현재 모형이 기준보다 우수하지 않다. 짧은 구간의 사후 재구성 비교를 실전 적중률로 홍보하지 않는다.

## 8. 원본 보존

9/17 원본의 수치를 실제값에 맞춰 이동시키지 않는다. 새 기준일·경로 수·자료에 따른 계산은 별도 버전으로 저장한다. 승인하면 활성 버전만 바뀐다. 같은 승인 요청 번호는 한 번만 기록한다. 브라우저 배포는 IndexedDB, 서버 운영은 파일 원자 교체 또는 Netlify Blobs 조건부 저장을 쓴다. 프로그램의 버전 식별용 해시는 암호학적 전자서명이 아니다. 패키지의 원본 데이터 SHA-256은 검증 보고서에 별도로 기록한다.
